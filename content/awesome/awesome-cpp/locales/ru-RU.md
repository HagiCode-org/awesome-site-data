## Стандартные библиотеки
*Стандартная библиотека C++ — включая контейнеры, алгоритмы, функциональные средства STL и т. д.*

* [C++ Standard Library](https://en.wikipedia.org/wiki/C%2B%2B_Standard_Library) - Набор классов и функций, написанных на основном языке и входящих в сам стандарт ISO C++.
* [Standard Template Library](https://en.wikipedia.org/wiki/Standard_Template_Library) - Стандартная библиотека шаблонов (STL).
* [C POSIX library](https://en.wikipedia.org/wiki/C_POSIX_library) - Спецификация стандартной библиотеки C для POSIX-систем.
* [ISO C++ Standards Committee](https://github.com/cplusplus) - ISO/IEC JTC1/SC22/WG21 — комитет по стандарту C++. [website](https://www.open-std.org/JTC1/SC22/WG21/)
* [The GNU C Library](https://www.gnu.org/software/libc/manual) - Это руководство рассказывает, как пользоваться средствами библиотеки GNU C.
