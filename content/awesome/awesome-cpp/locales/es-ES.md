## Standard Libraries
*Biblioteca estándar de C++, incluidos los contenedores, algoritmos y funciones de STL, entre otros.*

* [C++ Standard Library](https://en.wikipedia.org/wiki/C%2B%2B_Standard_Library) - Una colección de clases y funciones escritas en el lenguaje base y que forman parte de la propia norma ISO de C++.
* [Standard Template Library](https://en.wikipedia.org/wiki/Standard_Template_Library) - La Standard Template Library (STL).
* [C POSIX library](https://en.wikipedia.org/wiki/C_POSIX_library) - Una especificación de una biblioteca estándar de C para sistemas POSIX.
* [ISO C++ Standards Committee](https://github.com/cplusplus) - ISO/IEC JTC1/SC22/WG21: el comité de estándares de C++. [website](https://www.open-std.org/JTC1/SC22/WG21/)
* [The GNU C Library](https://www.gnu.org/software/libc/manual) - El propósito de este manual es explicar cómo utilizar las funciones de la biblioteca C de GNU.
