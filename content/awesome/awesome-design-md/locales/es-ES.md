# Selección de DESIGN.md

Copie un DESIGN.md en su proyecto, dígale a su agente de IA que me compruebe una página que se parezca a esto y genere IU de alta calidad que se mantenga visualmente coherente con el lenguaje de diseño.

Construido con profundidad de diseño real —incluyendo patrones analizados, fichas y reglas— para la generación de IU de alta calidad, no salidas de nivel superficial.


## ¿Qué es DESIGN.md?

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) es un nuevo concepto introducido por Google Stitch. Un documento del sistema de diseño de texto claro que los agentes de IA leen para generar IU consistente.

Es sólo un archivo de marcado. Sin exportaciones Figma, sin esquemas JSON, sin herramientas especiales. Suéltala en su raíz de proyecto y cualquier agente de codificación AI o Google Stitch entiende instantáneamente cómo debería mirar su interfaz de usuario. Markdown es el formato LLMs mejor leído, así que no hay nada que analizar o configurar.

| Archivo | Quien lo lee | Lo que define |
|------|-------------|-----------------|
| `AGENTS.md` | Agentes de codificación | Cómo construir el proyecto |
| `DESIGN.md` | Agentes de diseño | Cómo debe mirar y sentir el proyecto |

**Este repo proporciona archivos DESIGN.md listos para usar**extraído de sitios web reales.

## Solicitar un archivo DESIGN.md

Puedes[solicitar un DESIGN.md](https://getdesign.md/request) para un sitio web específico, incluyendo solicitudes privadas entregadas exclusivamente a usted.

### Web retro · nostalgia de DESIGN.md

Una serie de sábados — Archivos DESIGN.md extraídos de la web de la década de 1990. Deja una y dile a tu agente de IA que construya una interfaz de usuario de época exacta.

- [**Dell (1996)**](https://getdesign.md/dell-1996/design-md) - Catálogo-era empresa web. Literal black page frame, plano color-block "tarjetas de ribbon", chunky Helvetica-Black titles over Times Roman body, and hand-cut GIF stickers (NEW! ráfagas, sellos de premios, fotos de productos biseladas).
- [**Nintendo.com (2001)**](https://getdesign.md/nintendo-2001/design-md) - Y2K "console chrome" web. Paneles de metal de terciopelo, un nav de carbono de mediana tonelada que brilla en ámbar, esbozó marcadores de arte de caja Arial-Black sobre campos de héroe de circuito, y una burbuja pixel Mario bienvenida.


## Qué incluye cada DESIGN.md

Cada archivo sigue el[formato de Stitch para DESIGN.md](https://stitch.withgoogle.com/docs/design-md/specification/) con secciones ampliadas:

| # | Sección | Lo que captura |
|---|---------|-----------------|
| 1 | Tema visual &amp; Atmósfera | Mood, densidad, filosofía de diseño |
| 2 | Paleta de color &amp; Roles | Nombre semántico + hex + función funcional |
| 3 | Reglas de tipografía | Familias de fuentes, tabla de jerarquía completa |
| 4 | Estabilizaciones de componentes | Botones, tarjetas, entradas, navegación con estados |
| 5 | Principios de diseño | Escala de espacio, rejilla, filosofía blanca |
| 6 | Profundidad &quot; Elevación | Sistema de sombras, jerarquía superficial |
| 7 | Hacer y no | Guardias de diseño y antipatrones |
| 8 | Comportamiento responsable | Puntos de descanso, metas táctiles, estrategia de colapso |
| 9 | Agente Prompt Guide | Rápida referencia a color, listos para usar |

Cada sitio incluye:

| Archivo | Propósito |
|------|---------|
| `DESIGN.md` | El sistema de diseño (lo que los agentes leen) |
| `preview.html` | Catálogo visual que muestra relojes de color, escala de tipo, botones, tarjetas |
| `preview-dark.html` | Mismo catálogo con superficies oscuras |
