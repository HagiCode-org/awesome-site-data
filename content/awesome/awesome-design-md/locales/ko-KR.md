# DESIGN.md 엄선 모음

프로젝트에 DESIGN.md를 복사하면 AI 에이전트에게 "이처럼 보이는 페이지를 만들"고 디자인 언어로 시각적으로 일관성있는 고품질의 UI를 생성합니다.

분석 패턴, 토큰 및 규칙을 포함한 실제 디자인 깊이로 제작되었습니다. 고품질의 UI 생성을 위해 표면 수준 출력이 아닙니다.


## DESIGN.md란?

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) Google Stitch에 소개 된 새로운 개념입니다. AI Agent가 일관된 UI를 생성하는 일반 텍스트 디자인 시스템 문서.

그것은 단지 마크 다운 파일입니다. 아니 Figma 수출, 아니 JSON schemas, 특별한 장식 없음. 프로젝트 루트에 드롭하고 AI 코딩 에이전트 또는 Google Stitch는 즉시 UI가 어떻게 보일지 이해합니다. Markdown은 LLMs가 가장 잘 읽는 형식이므로 파싱이나 구성에 아무것도 없습니다.

| 파일 형식 | 누가 그것을 읽는다 | 정의하는 것 |
|------|-------------|-----------------|
| `AGENTS.md` | Coding 대리인 | 프로젝트 구축 방법 |
| `DESIGN.md` | 회사소개 | 프로젝트가 어떻게 보일까요? |

**이 repo는 ready-to-use DESIGN.md 파일을 제공합니다.**실제 웹 사이트에서 추출.

## DESIGN.md 요청하기

당신은 할 수[DESIGN.md 요청](https://getdesign.md/request) 개인 요청을 포함하여 특정 웹 사이트를 위해 독점적으로 전달됩니다.
