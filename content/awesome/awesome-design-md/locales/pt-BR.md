# Coleção de DESIGN.md

Copie um DESIGN.md para o seu projeto, diga ao seu agente de IA “construa-me uma página parecida com esta” e gere uma interface de alta qualidade que se mantenha visualmente consistente com a linguagem de design.

Construído com profundidade real de projeto — incluindo padrões analisados, fichas e regras — para geração de interfaces de alta qualidade, não saídas de nível de superfície.


## O que é DESIGN.md?

[DESIGN.md](https://stitch.withgoogle.com/docs/design-md/overview/) é um novo conceito introduzido pelo Google Stitch. Um documento de sistema de design de texto simples que os agentes de IA leram para gerar UI consistente.

É só um ficheiro de marcação. Sem exportações de Figma, sem esquemas JSON, sem ferramentas especiais. Jogue-o na raiz do seu projeto e qualquer agente de codificação de IA ou Google Stitch compreende instantaneamente como a sua UI deve olhar. Markdown é o formato LLMs lido melhor, então não há nada para analisar ou configurar.

| Ficheiro | Quem lê? | O que define |
|------|-------------|-----------------|
| `AGENTS.md` | Agentes de codificação | Como construir o projeto |
| `DESIGN.md` | Agentes de concepção | Como o projeto deve parecer e se sentir |

**Este repo fornece arquivos prontos para usar DESIGN.md**extraído de sites reais.

## Solicitar um DESIGN.md

Podes.[solicitar um DESIGN.md](https://getdesign.md/request) para site específico, incluindo pedidos privados entregues exclusivamente a você.

### Web retrô · nostalgia de DESIGN.md

Uma série de sábados — DESIGN.md arquivos extraídos da web da década de 1990. Deixa entrar um e diz ao teu agente de IA para construir uma UI vintage.

- [**Dell (1996)**](https://getdesign.md/dell-1996/design-md) - Web corporativa da época do catálogo. Moldura de página preta literal, bloco de cores planas "cartões de fita", títulos Helvetica-Black gorduchos sobre o corpo de Times Roman, e adesivos GIF cortados à mão (NOVO! brotos, selos de prêmio, fotos do produto chanfrado).
- [**Nintendo.com (2001)**](https://getdesign.md/nintendo-2001/design-md) - Y2K "console cromo" web. Painéis de metal chanfrado de periwinkle escovado, um âmbar brilhante de navegação de carbono com meio tom, marcas de palavras Arial-Black box-art sobre campos de herói de placa de circuito, e uma bolha de boas-vindas pixel Mario.


## O que há em cada DESIGN.md

Cada arquivo segue o[formato do Stitch DESIGN.md](https://stitch.withgoogle.com/docs/design-md/specification/) com secções alargadas:

| # | Secção | O que captura |
|---|---------|-----------------|
| 1 | Tema Visual & Ambiente | Mood, densidade, filosofia de design |
| 2 | Papel & Paleta de Cores | Nome semântico + hex + função funcional |
| 3 | Regras de Tipografia | Famílias de fontes, tabela de hierarquia completa |
| 4 | Stylings de Componentes | Botões, cartões, entradas, navegação com estados |
| 5 | Princípios de Disposição | Escala de espaço, grade, filosofia do espaço em branco |
| 6 | Profundidade e Elevação | Sistema de sombras, hierarquia de superfície |
| 7 | Faz e não faz | Projeto de guarnições e anti-padrão |
| 8 | Comportamento Responsivo | Pontos de paragem, alvos de toque, estratégia de colapso |
| 9 | Guia de Pedido de Agente | Referência de cor rápida, prompts prontos para usar |

Cada site inclui:

| Ficheiro | Objecto |
|------|---------|
| `DESIGN.md` | O sistema de design (o que os agentes leram) |
| `preview.html` | Catálogo visual mostrando amostras de cores, escala de tipo, botões, cartas |
| `preview-dark.html` | Mesmo catálogo com superfícies escuras |

### Como usar


1. Copiar um site`DESIGN.md`em seu root do projeto
2. Diz ao teu agente de IA para o usar.
