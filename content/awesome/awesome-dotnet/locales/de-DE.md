## Algorithmen und Datenstrukturen

* [OneOf](https://github.com/mcintyre321/OneOf)- OneOf bietet diskriminierte Gewerkschaften für C# mit umfassendem Compilation-Time-Matching.
* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia)- Algorithmus- und Datenstrukturbibliothek für .NET 3.5 und höher. Algorithmia enthält ausgeklügelte Algorithmen und Datenstrukturen wie Graphen, Prioritätswarteschlangen, Befehle, Undo-Redo und mehr.
* [Towel](https://github.com/ZacharyPatten/Towel)- Datenstrukturen, Algorithmen, Mathematik, Metadaten, Erweiterungen, Konsolen, Messungen und andere nützliche Dinge
* [Akade.IndexedSet](https://github.com/akade/Akade.IndexedSet)- Eine bequeme Datenstruktur, die eine effiziente In-Memory-Indizierung und Abfrage unterstützt, einschließlich Range Queries und Fuzzy String Matching.

## API

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)Hochleistungs-Middleground zwischen klassischen ASP.NET Core API-Controllern und Minimal APIs. Mit einem REPR ()[Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)Diese Bibliothek eliminiert das Boilerplate und monolithische Gefühl von Controllern, indem sie die Colocation von Code verbessert.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot).NET Client für[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)Automatisieren Sie ein Benutzerkonto auf Telegram mit der neuesten Version von[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)Framework, das es einfach macht, HTTP-Dienste zu erstellen, die eine breite Palette von Clients erreichen, einschließlich Browsern und mobilen Geräten
* [Breeze](https://breeze.github.io/doc-net/)API-Framework, das den Zugriff auf Rich Data mithilfe des OData 3-Protokolls ermöglicht. Clientbibliotheken für JavaScript und C# verfügbar.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)Mobius fügt Apache Spark eine C#-Sprachbindung hinzu, die die Implementierung von Spark-Treibercode und Datenverarbeitungsvorgängen in C# ermöglicht.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- Nachdenklich architektonisch, obszön schnell, durch und durch angenehme Web-Services für alle
* [Ocelot](https://github.com/ThreeMammals/Ocelot).NET Core API Gateway
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)- Befehlsabfragetrennung für ASP.NET Core ⚡AWS Lambda ⚡Azure Functions ⚡Google Cloud Functions ⚡ASP.NET Web API 2
* [Population.NET](https://github.com/Authentic199/Population.NET)Eine .NET-Bibliothek ermöglicht es Clients, die genauen Felder anzugeben, die sie benötigen, wodurch unnötige Datenübertragungen reduziert werden, indem standardmäßig das Abrufen aller Felder vermieden wird.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)Eine Reihe von Bibliotheken und Klassen, die das Erstellen von REST-APIs und gRPC-Diensten vereinfachen und die Menge an Code reduzieren, der mit nur einer Zeile Code für einen voll funktionsfähigen REST-Controller geschrieben werden muss.
