## Algorithmes et structures de données

* [OneOf](https://github.com/mcintyre321/OneOf)- OneOf fournit des syndicats discriminés pour C# avec une compilation exhaustive de temps de correspondance.
* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia)- Algorithme et bibliothèque de data-structure pour .NET 3.5 et plus. L'algorithmie contient des algorithmes sophistiqués et des structures de données comme des graphiques, des files d'attente prioritaires, des commandes, undo-redo et plus encore.
* [Towel](https://github.com/ZacharyPatten/Towel)- structures de données, algorithmes, mathématiques, métadonnées, extensions, console, mesures et autres choses utiles
* [Akade.IndexedSet](https://github.com/akade/Akade.IndexedSet)- Une structure de données pratique prenant en charge l'indexation et l'interrogation en mémoire efficace, y compris les requêtes de gamme et les correspondances de chaînes floues.

## API

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)- Milieu de travail performant entre les contrôleurs ASP.NET Core API classiques et les API Minimal. Utilisation d'un REPR ([Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)) modèle, cette bibliothèque élimine la plaque de chaudière et la sensation monolithique des contrôleurs en améliorant la colocation du code.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)- Client .NET pour[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)- Automatiser un compte utilisateur sur Telegram, en utilisant la dernière version de[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)- Cadre qui facilite la construction de services HTTP qui atteignent un large éventail de clients, y compris les navigateurs et les appareils mobiles
* [Breeze](https://breeze.github.io/doc-net/)- Cadre API permettant un accès riche aux données en utilisant le protocole OData 3. Bibliothèques client disponibles pour JavaScript et C#.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)- Mobius ajoute une liaison en langage C# à Apache Spark, permettant la mise en œuvre du code de conduite Spark et des opérations de traitement des données dans C#.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- Les services web conçus avec soin, obscènement rapides et agréables pour tous
* [Ocelot](https://github.com/ThreeMammals/Ocelot)- .NET noyau API Gateway
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)- Séparation des requêtes de commande pour le noyau ASP.NET
* [Population.NET](https://github.com/Authentic199/Population.NET)- Une bibliothèque .NET permet aux clients de spécifier les champs exacts dont ils ont besoin, réduisant ainsi le transfert inutile de données en évitant la récupération de tous les champs par défaut.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)- Un ensemble de bibliothèques et de classes qui simplifient les API REST et les services gRPC, réduisant la quantité de code à écrire avec même une ligne de code pour un contrôleur REST entièrement fonctionnel.
