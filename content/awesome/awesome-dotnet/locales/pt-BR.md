Uma coleção incrível de bibliotecas, ferramentas, frameworks e softwares .NET.

Inspirado por [awesome-ruby](https://github.com/markets/awesome-ruby), [awesome-php](https://github.com/ziadoz/awesome-php), [awesome-python](https://github.com/vinta/awesome-python), [frontend-dev-bookmarks](https://github.com/dypsilon/frontend-dev-bookmarks) e [ruby-bookmarks](https://github.com/dreikanter/ruby-bookmarks).

Contribuições são sempre bem-vindas! Consulte primeiro as páginas de [diretrizes de contribuição e padrões de qualidade](https://github.com/quozd/awesome-dotnet/blob/master/CONTRIBUTING.md). Também aceitamos softwares proprietários e comerciais.

Agradecemos a todos os [contribuidores](https://github.com/quozd/awesome-dotnet/graphs/contributors): vocês são incríveis e este projeto não seria possível sem vocês! O objetivo é criar uma coleção categorizada e mantida pela comunidade, com recursos muito conhecidos.

## Algoritmos e estruturas de dados

* [OneOf](https://github.com/mcintyre321/OneOf) - OneOf fornece uniões discriminadas para C#, com correspondência exaustiva em tempo de compilação.
* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia) - Biblioteca de algoritmos e estruturas de dados para .NET 3.5 e posteriores. Inclui algoritmos e estruturas sofisticados, como grafos, filas de prioridade, comandos, desfazer/refazer e muito mais.
* [Towel](https://github.com/ZacharyPatten/Towel) - estruturas de dados, algoritmos, matemática, metadados, extensões, console, medições e outras utilidades.
* [Akade.IndexedSet](https://github.com/akade/Akade.IndexedSet) - Estrutura de dados conveniente que oferece indexação e consultas eficientes em memória, incluindo consultas por intervalo e correspondência aproximada de strings.

## API

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints) - Uma alternativa de alto desempenho entre os controladores clássicos de API do ASP.NET Core e as Minimal APIs. Com o padrão REPR ([Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)), esta biblioteca elimina o código repetitivo e a sensação de monólito dos controladores ao aproximar o código relacionado.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot) - Cliente .NET para a [API de bots do Telegram](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient) - Automatize uma conta de usuário do Telegram usando a versão mais recente da [API de cliente do Telegram](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis) - Framework que facilita a criação de serviços HTTP para uma ampla variedade de clientes, incluindo navegadores e dispositivos móveis.
* [Breeze](https://breeze.github.io/doc-net/) - Framework de API que permite acesso avançado a dados usando o protocolo OData 3. Há bibliotecas cliente para JavaScript e C#.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius) - O Mobius adiciona suporte à linguagem C# no Apache Spark, permitindo implementar código de driver do Spark e operações de processamento de dados em C#.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack) - Serviços web cuidadosamente projetados, absurdamente rápidos e agradáveis de usar para todos.
* [Ocelot](https://github.com/ThreeMammals/Ocelot) - API Gateway para .NET Core
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery) - Separação entre comandos e consultas para 🌐ASP.NET Core ⚡AWS Lambda ⚡Azure Functions ⚡Google Cloud Functions 🌐ASP.NET Web API 2
* [Population.NET](https://github.com/Authentic199/Population.NET) - Biblioteca .NET que permite especificar os campos exatos necessários, reduzindo transferências desnecessárias de dados ao evitar a recuperação de todos os campos por padrão.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit) - Conjunto de bibliotecas e classes que simplifica a criação de APIs REST e serviços gRPC, reduzindo a quantidade de código necessária: até mesmo um único comando pode criar um controlador REST funcional.

## Frameworks de aplicação

* [.NET Boxed Framework](https://github.com/Dotnet-Boxed/Framework) - Extensões do .NET Core e pacotes NuGet auxiliares

* [Runtime](https://github.com/dotnet/runtime) - O repositório do runtime contém a implementação das bibliotecas (anteriormente chamadas de "CoreFX") para .NET (5+). Inclui System.Collections, System.IO, System.Xml e muitos outros componentes.

* [Plastic](https://github.com/sang-hyeon/Plastic) - O Plastic encapsula elementos como domínio, regras de aplicação, regras de negócio ou lógica de negócios no aplicativo. Para isso, usa o padrão Command.
* [Signals](https://github.com/EmitKnowledge/Signals) - Framework baseado no .NET 5 que busca aumentar a qualidade e a produtividade das equipes de desenvolvimento, oferecendo ferramentas, aspectos e processos.
* [Spring.Net](https://github.com/spring-projects/spring-net) - Spring.NET é um framework de aplicativos de código aberto que facilita a criação de aplicativos corporativos .NET.
* [DotNetty](https://github.com/Azure/DotNetty) - Port do Netty, um framework de rede assíncrono e orientado a eventos para o desenvolvimento rápido de servidores e clientes de protocolo de alto desempenho e fáceis de manter.
* [AspectCore Framework](https://github.com/dotnetcore/AspectCore-Framework) - Framework multiplataforma para .NET Core e .NET Framework baseado em programação orientada a aspectos. Oferece suporte a interceptadores de aspectos, integração de injeção de dependência, aplicativos web, validação de dados e muito mais.
* [ActualLab.Fusion](https://github.com/ActualLab/Fusion) - Dispense o SignalR e o gRPC. Crie aplicativos Blazor e MAUI em tempo real escrevendo apenas 0,1% do código usual para atualizações em tempo real. Atenda a 10× mais solicitações de API com o protocolo ActualLab.Rpc — ou a 1000× mais com o cache transparente e perfeitamente coerente do Fusion. [Exemplos](https://github.com/ActualLab/Fusion.Samples). [Documentação](https://fusion.actuallab.net/).
* [silky](https://github.com/liuhll/silky) - O framework Silky foi projetado para ajudar desenvolvedores a criar rapidamente um framework de microsserviços com código e configuração simples na plataforma .NET.
* [Positron-JS](https://github.com/Positron-JS/positron-web-view) - Web View avançada (PositronWebView) com contexto JavaScript nativo para acessar APIs .NET em aplicativos híbridos, inspirada em capacitor/cordova.
