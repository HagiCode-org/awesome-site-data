## アルゴリズムとデータ構造

* [OneOf](https://github.com/mcintyre321/OneOf)- OneOf は、C# のディスクリマイゼーション解除を、コンプリートタイムマッチングで提供します。
* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia)- .NET 3.5 および .NET 3.5 用のアルゴリズムとデータ構造ライブラリ。 Algorithmiaには、グラフ、優先キュー、コマンド、undo-redoなどの高度なアルゴリズムとデータ構造が含まれています。
* [Towel](https://github.com/ZacharyPatten/Towel)- データ構造、アルゴリズム、数学、メタデータ、拡張、コンソール、測定、その他の有用なもの
* [Akade.IndexedSet](https://github.com/akade/Akade.IndexedSet)- 効率的なインメモリーインデックス作成とクエリをサポートする便利なデータ構造。範囲のクエリとファジー文字列のマッチングを含みます。

## APIサービス

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)- 古典的なASP.NETコアAPIコントローラーとMinimal API間での高性能なミドルグラウンド。 REPRの利用[Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)) パターン、このライブラリは、コードのコロケーションを改善することによって、コントローラのボイラープレートとモノリシックな感触を排除します。
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)- .NETクライアント[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)- 最新バージョンのTelegramでユーザーアカウントを自動化[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)- ブラウザやモバイルデバイスなど、幅広いクライアントにリーチする HTTP サービスを簡単に構築できるフレームワーク
* [Breeze](https://breeze.github.io/doc-net/)- OData 3 プロトコルを使用して、豊富なデータアクセスを可能にする API フレームワーク。 JavaScript と C# のクライアントライブラリが利用できます。
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)- Mobius は Apache Spark に C# 言語バインディングを追加し、Spark のドライバー コードと C# のデータの処理操作の実装を可能にします。
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- うまく設計された、猥褻な高速、徹底的にすべてのために楽しいWebサービス
* [Ocelot](https://github.com/ThreeMammals/Ocelot)- .NETコアAPIゲートウェイ
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)- コマンド Query の分離 のための ▷ASP.NET コア ⚡AWS Lambda Azure 関数 ⚡Google Cloud 関数 バックアップASP.NET Web API 2
* [Population.NET](https://github.com/Authentic199/Population.NET)- .NETライブラリは、クライアントが必要な正確なフィールドを指定し、デフォルトですべてのフィールドの検索を回避することで不要なデータ転送を減らすことができます。
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)- REST API と gRPC サービスのビルドを簡素化するライブラリとクラスをセットし、完全な機能の REST コントローラーの 1 行でも記述するコードの量を減らします。
