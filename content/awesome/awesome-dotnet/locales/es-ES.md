* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia)- Biblioteca Algoritmo y estructura de datos para .NET 3.5 y arriba. Algorithmia contiene sofisticados algoritmos y estructuras de datos como gráficos, colas prioritarias, comando, undo-redo y más.

## API

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)- Medio de alto rendimiento entre los controladores clásicos ASP.NET Core API y Minimal APIs. Utilizando un REPR ([Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)) patrón, esta biblioteca elimina la caldera y la sensación monolítica de los controladores mejorando la colocación de código.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)- Cliente .NET para[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)- Automatizar una cuenta de usuario en Telegram, utilizando la última versión de[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)- Marco que facilita la construcción de servicios HTTP que lleguen a una amplia gama de clientes, incluyendo navegadores y dispositivos móviles
* [Breeze](https://breeze.github.io/doc-net/)- Marco API que permite el acceso a datos ricos utilizando el protocolo OData 3. Bibliotecas de clientes disponibles para JavaScript y C#.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)- Mobius añade la unión de lenguaje C# a Apache Spark, permitiendo la implementación de código de controlador Spark y operaciones de procesamiento de datos en C#.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- Servicios web cuidadosamente diseñados, obscenosamente rápidos, a fondo agradables para todos
* [Ocelot](https://github.com/ThreeMammals/Ocelot)- .NET Core API Gateway
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)- Separación de la consulta de comandos para 🌐ASP.NET Core βAWS Lambda ΩAzure Funciones de nube de Google Funciones 🌐ASP.NET Web API 2
* [Population.NET](https://github.com/Authentic199/Population.NET)- Una biblioteca .NET permite a los clientes especificar los campos exactos que necesitan, reduciendo la transferencia innecesaria de datos evitando la recuperación de todos los campos por defecto.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)- Un conjunto de bibliotecas y clases que simplifican la construcción de APIs REST y servicios de GRPC, reduciendo la cantidad de código a escribir con una línea de código para un controlador REST totalmente funcional.
