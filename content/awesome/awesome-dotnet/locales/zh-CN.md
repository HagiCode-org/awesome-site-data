## API 密码

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)- 经典的ASP.NET Core API控制器和最小API之间的高性能中间场. 使用 REPR ([Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern))图案,这个库通过改进代码的合用,消除了锅炉板和单体控制器的感觉.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)- 网络客户端[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)- 使用最新版本的Telegram实现用户账户自动化[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)- 便于建立HTTP服务的框架,服务可接触到广泛的客户,包括浏览器和移动设备
* [Breeze](https://breeze.github.io/doc-net/)- API框架,通过OData 3协议使丰富的数据访问成为可能。 可供JavaScript和C#使用的客户端库.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)- Mobius在Apache Spark中添加了C#语言绑定,使得Spark驱动码和数据处理操作在C#中得以实施.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- 精心设计、淫秽迅速、人人享受的网络服务
* [Ocelot](https://github.com/ThreeMammals/Ocelot)-.NET核心API网关
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)- 命令查询分离 QQASP. NET Core QAWS Lambda QAzure 函数 Google 云函数 QQASP.NET 网络 API 2
* [Population.NET](https://github.com/Authentic199/Population.NET)- 一个.NET库允许客户端指定他们需要的确切字段,通过避免默认检索所有字段来减少不必要的数据传输.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)- 一套简化建筑 REST API 和 gRPC 服务的库和类,减少一个功能完备的 REST 控制器要用甚至一行代码写入的代码数量。
