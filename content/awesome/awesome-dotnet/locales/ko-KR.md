## Algorithms 및 데이터 구조

* [OneOf](https://github.com/mcintyre321/OneOf)- OneOf는 C#를 위한 discriminated 조합을 배부합니다.
* [Algorithmia](https://github.com/SolutionsDesign/Algorithmia)- .NET 3.5 및 위를위한 알고리즘 및 데이터 구조 라이브러리. Algorithmia는 그래프, 우선 순위 큐, 명령, undo-redo 등과 같은 정교한 알고리즘과 데이터 구조를 포함합니다.
* [Towel](https://github.com/ZacharyPatten/Towel)- 데이터 구조, 알고리즘, 수학, 메타데이터, 확장, 콘솔, 측정 및 기타 유용한 물건
* [Akade.IndexedSet](https://github.com/akade/Akade.IndexedSet)- 범위 쿼리 및 fuzzy 문자열 일치를 포함하여 효율적인 in-memory 색인 및 쿼리를 지원하는 편리한 데이터 구조.

## API 지원

* [FastEndpoints](https://github.com/FastEndpoints/FastEndpoints)- 고전 ASP.NET Core API 컨트롤러와 Minimal API 사이의 고성능 중경. REPR 사용[Request-Endpoint-Response](https://deviq.com/design-patterns/repr-design-pattern)) 본, 이 도서관은 부호의 colocation를 개량해서 관제사의 보일러판 그리고 monolithic 느낌을 삭제합니다.
* [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)- .NET 클라이언트[Telegram Bot API](https://core.telegram.org/bots/api)
* [WTelegramClient](https://github.com/wiz0u/WTelegramClient)- Telegram의 사용자 계정을 Automate, 최신 버전을 사용하여[Telegram Client API](https://core.telegram.org/methods)
* [ASP.NET Web API](https://dotnet.microsoft.com/apps/aspnet/apis)- 브라우저 및 모바일 기기를 포함한 광범위한 클라이언트에 도달하는 HTTP 서비스를 쉽게 구축 할 수 있는 Framework
* [Breeze](https://breeze.github.io/doc-net/)- API Framework는 OData 3 프로토콜을 사용하여 풍부한 데이터 액세스를 가능하게 합니다. JavaScript 및 C#에 사용할 수 있는 클라이언트 라이브러리.
* [Mobius: C# API for Spark](https://github.com/Microsoft/Mobius)- Mobius는 C#에서 Spark 드라이버 코드 및 데이터 처리 작업을 수행 할 수 있도록 C# 언어 바인딩을 추가합니다.
* [ServiceStack](https://github.com/ServiceStack/ServiceStack)- 건축가, 비평하게 빠른, 완전히 모든 것을 위한 즐거운 웹 서비스
* [Ocelot](https://github.com/ThreeMammals/Ocelot)- .NET 핵심 API 게이트웨이
* [CommandQuery](https://github.com/hlaueriksson/CommandQuery)-  LambASP.NET Core AAWS Lambda ⚡Azure Functions ⚡ASP.NET Web API 2
* [Population.NET](https://github.com/Authentic199/Population.NET)- .NET 라이브러리는 클라이언트가 필요한 정확한 필드를 지정할 수 있으며, 기본으로 모든 필드의 검색을 방지하여 불필요한 데이터 전송을 줄입니다.
* [Wissance.WebApiTookit](https://github.com/Wissance/WebApiToolkit)- REST API 및 gRPC 서비스를 구축하는 라이브러리 및 클래스 세트로, 완전히 기능적인 REST 컨트롤러에 대한 코드의 한 줄도 작성할 수 있는 코드의 양을 줄입니다.

* [Signals](https://github.com/EmitKnowledge/Signals)- Signals는 .NET5 기반 프레임 워크로서 개발 팀 내에서 품질과 생산성을 늘리고 도구, 측면 및 프로세스를 제공합니다.

Rpc 프로토콜 또는 1000 × Fusion의 투명하고 완벽하게 일관성 캐싱.[Samples](https://github.com/ActualLab/Fusion.Samples)·[Documentation](https://fusion.actuallab.net/)·

* [Positron-JS](https://github.com/Positron-JS/positron-web-view)- Native JavaScript Context를 사용하여 고급 웹뷰(PositronWebView)를 통해 커패시터/cordova에서 영감을 받은 하이브리드 애플리케이션에서 .NET API에 액세스할 수 있습니다.

* [CodeBehind Framework](https://github.com/elanatframework/Code_behind)- ASP.NET Core의 현대적이고 강력한 백엔드 프레임 워크.
* [Suave.IO](https://suave.io/)- Framework/library/web 서버는 F#에서 작성한 아름다운 코드를 볼 때 프로젝트의 앞에 시간 완료 후 기쁨의 눈물을 울립니다.
* [DotVVM](https://github.com/riganti/dotvvm)- MVVM 프레임 워크는 OWIN 및 ASP.NET 코어 지원 및 Visual Studio 2015 및 2017의 무료 확장과 함께 JavaScript를 작성하지 않는 사람들을 위해.
* [Giraffe](https://github.com/giraffe-fsharp/Giraffe)- 기능성(F#) ASP.NET 풍부한 웹 애플리케이션 구축을위한 핵심 마이크로 프레임 워크

## 웹 서버

* [EmbedIO](https://github.com/unosquare/embedio)- Mono 및 cross-platform에 내장된 웹 서버
* [GenHTTP](https://github.com/Kaliumhexacyanoferrat/GenHTTP)- 빠른 REST API를 만들기 위한 경량, embeddable 웹 서버
* [SimpleW](https://stratdev3.github.io/SimpleW)- .NET Core의 웹 서버 라이브러리. 강력하게 단순하고, Blazingly 빠르고 빌드 인 구성 요소 (API REST, JWT, Websockets, 자체 직렬화, Opentelemetry).

## 웹소켓

* [SignalR](https://github.com/SignalR/SignalR)- ASP.NET 개발자를 위한 라이브러리는 애플리케이션에 실시간 웹 기능을 추가하는 매우 간단합니다.
* [SuperSocket](https://github.com/kerryjiang/SuperSocket)- SuperSocket은 경량 확장 소켓 애플리케이션 프레임 워크입니다.
* [Websocket-Sharp](https://github.com/sta/websocket-sharp)- WebSocket 프로토콜 클라이언트 및 서버의 C# 구현
* [Crossertech](https://crosser.io/)- Microsoft에서 실시간 응용 프로그램을 구축 할 수있는 훌륭한 도구 세트를 제공합니다. NET plattform 및 훨씬 더. **[$]**
* [Websocket.Client](https://github.com/Marfusios/websocket-client)- 기본 C# 클래스 ClientWebSocket을 통한 멀티플랫폼 래퍼 구축 및 오류 처리.

## 소스 생성기

* [CodegenCS](https://github.com/Drizin/CodegenCS)- 템플릿이 일반 C#를 사용하여 작성되는 코드 생성 툴킷. 명령줄 도구, MSBuild 작업, Visual Studio Extension 및 Roslyn Source Generator.
* [M31.FluentAPI](https://github.com/m31coding/M31.FluentAPI)- Effortlessly는 당신의 C# 종류를 위한 유창한 APIs를 생성합니다.
* [Supernova.Enum.Generators](https://github.com/EngRajabi/Enum.Source.Generator)- C# 소스 생성기는 enum 유형에서 enumeration 클래스를 만듭니다. 이 포장으로, 당신은 반영을 사용하지 않고 매우 빠른 enums에 작동 할 수 있습니다.
* [Vogan](https://github.com/SteveDunn/Vogen)- 분석기와 값 객체 생성기.
* [Dunet](https://github.com/domn1995/dunet)- C#에 있는 discriminated 조합을 위한 간단한 근원 발전기.
* [SyncMethodGenerator](https://github.com/zompinc/sync-method-generator)– 코드 복제를 방지하기 위해 async ones에서 동시 메소드를 생성한다.
