#### 什麼是混沌工程？
> 混沌工程是在分散式系統上進行實驗的學科，目的是建立對系統在生產環境中承受動盪條件能力的信心。——[混沌工程原則](http://principlesofchaos.org/)網站。

## 知名工具
* [Chaos Monkey](https://github.com/Netflix/chaosmonkey) - 一款彈性工具，可協助應用程式容忍隨機的執行個體故障。
* [orchestrator](https://github.com/github/orchestrator) - MySQL 複製拓撲管理與高可用性工具。
* [kube-monkey](https://github.com/asobti/kube-monkey) - 適用於 Kubernetes 叢集的 Netflix Chaos Monkey 實作。
* [Gremlin Inc.](https://www.gremlin.com/) - 故障即服務（Failure as a Service）。
* [Chaos Toolkit](https://github.com/chaostoolkit/chaostoolkit) - 一款混沌工程工具包，協助你建立對軟體系統的信心。
* [steadybit](https://www.steadybit.com/) - 一款混沌工程平台（SaaS 或本地部署），具備自動探索、多種攻擊類型、使用者管理等功能。
* [PowerfulSeal](https://github.com/bloomberg/powerfulseal) - 為你的 Kubernetes 叢集注入混沌，以便盡早發現系統中的問題。它會終止目標 Pod，並使虛擬機上下線。
* [drax](https://github.com/dcos-labs/drax) - DC/OS 彈性自動化診斷工具。它借鏡 Chaos Monkey 的思路，透過主動、侵入式的測試方法來檢驗 DC/OS 部署。
* [Wiremock](http://wiremock.org/) - API 模擬（服務虛擬化）工具，可對真實世界中的故障和延遲進行建模。
* [MockLab](http://get.mocklab.io/) - 以服務形式提供的 API 模擬（服務虛擬化）工具，可對真實世界中的故障和延遲進行建模。
* [Pod-Reaper](https://github.com/target/pod-reaper) - 一款基於規則的 Pod 終止容器。Pod-Reaper 旨在終止符合特定條件的 Pod，可用於 Kubernetes 中的混沌測試。
* [Muxy](https://github.com/mefellows/muxy/) - 一款用於模擬真實分散式系統故障的混沌測試工具。
* [Toxiproxy](https://github.com/Shopify/toxiproxy) - 一款用於模擬網路與系統條件以進行混沌和彈性測試的 TCP 代理。
* 適用於 Docker 的混沌工程：
  * [Pumba](https://github.com/gaia-adm/pumba) - 適用於 Docker 容器（及叢集）的混沌測試與網路模擬工具。
  * [Blockade](https://github.com/worstcase/blockade) - 基於 Docker 的工具，用於測試分散式應用中的網路故障與分割。
* [chaos-lambda](https://github.com/bbc/chaos-lambda) - 在工作時間隨機終止 ASG 執行個體。
* [Namazu](https://github.com/osrg/namazu) - 用於測試分散式系統的可程式化模糊排程器。
* [Chaos Monkey for Spring Boot](https://codecentric.github.io/chaos-monkey-spring-boot/) - 向 Spring Boot 應用中注入延遲、例外和終止。
* [Byte-Monkey](https://github.com/mrwilson/byte-monkey) - 適用於 JVM 的位元組碼層級故障注入工具。它透過執行階段動態插桩應用程式碼，故意引入例外和延遲等故障。
* [GomJabbar](https://github.com/outbrain/GomJabbar) - 適用於私有雲的 ChaosMonkey。
* [Turbulence](https://github.com/cppforlife/turbulence-release) - 專注於 BOSH 環境的工具，能夠對虛擬機施加壓力、操縱網路流量等。它與 Gremlin 非常相似。
* [chaosblade](https://github.com/chaosblade-io/chaosblade) - 一款易用且強大的混沌工程工具包。
* [KubeInvaders](https://github.com/lucky-sideburn/KubeInvaders) - 適用於 Kubernetes 叢集的遊戲化混沌工程工具。
* [Cthulhu](https://github.com/xmatters/cthulhu-chaos-testing) - 一款混沌工程工具，可透過資料驅動的方式模擬各種災難場景，評估微服務系統的彈性。
* [VMware Mangle](https://vmware.github.io/mangle/) - 編排混沌工程。
* [Byteman](https://byteman.jboss.org/) - 一款位元組碼操作的瑞士軍刀。
* [Litmus](https://github.com/litmuschaos/litmus) - 適用於 Kubernetes 環境的框架，可執行測試套件、擷取日誌、產生報告並執行混沌測試。
* [Perses](https://github.com/nicolasmanic/perses) - 一個用於對 JVM 應用程式造成（可控）破壞的專案。

* [failure-lambda](https://github.com/gunnargrosch/failure-lambda) - 一個用於在 AWS Lambda 中透過延遲、例外、狀態碼或磁碟空間注入故障的小型 Node 模組。
