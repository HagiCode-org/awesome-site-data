## ツール
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - GitHub の履歴から独自の決定論的なピクセルアート盆栽を育てます。コミットするたびに README のアニメーション GIF も成長します 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - プロフィール README に Todoist の日次統計を表示
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - GitHub の README.md、Issue、PR への訪問者数をカウント
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - Markdown を1行追加するだけで、1990年代風の訪問者カウンターを設置できます。
- [Visitor Count](https://pufler.dev/badge-it/) - shields.io と組み合わせて README.md の訪問者数をカウント
- [Shields Project](https://shields.io/) - Shields で Simple Icons 対応のプロフィールバッジを作成
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - GitHub 統計、言語の分布、コミット傾向、コントリビューションの連続記録、開発者ランキング、トロフィー、スポンサーを表示する動的 SVG カード生成ツールとライブ API。([Web ジェネレーター](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - README に動的に生成した GitHub 統計を表示
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 True Glassmorphism デザインとテーマを備えた、超高速で美しい SVG 統計ジェネレーター
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - GitHub プロフィール README 用に、ターミナル風のコントリビューショングラフ、統計、主要言語の SVG を生成
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: 実際にコミットしたリポジトリの GitHub コントリビューター統計を README に動的表示
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 GitHub のコントリビューショングラフを重力で落下させ、カスタムテキストと衝突させて美しいアニメーション SVG を作成
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 モチベーションを保ち、連続コントリビューションをアピール！🌟 合計、現在、最長の連続記録をプロフィール README に表示
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - 16種類のビジュアルスタイル、21テーマ、グラフカード（ドーナツ、ゲージ、コミット活動）とビジュアルカードビルダーを備えたセルフホスト可能な GitHub 統計カード
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - README.md 用の人気ブランドの SVG アイコン
- [Laravel GitHub Profile Visit Counter](https://github.com/caneco/laravel-github-profile-view-counter) - Laravel プロジェクトに簡単なバッジを追加してプロフィール訪問数をカウント
- [Dev Metrics in Readme](https://github.com/athul/waka-readme) - プロフィール README に [WakaTime](https://wakatime.com/) の週間メトリクスを表示
- [Profile Activity Generator](https://github.com/omidnikrah/profile-activity-generator) - プロフィール README 用のカスタムアクティビティを生成
