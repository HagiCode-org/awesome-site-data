## Herramientas
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - Crea un bonsái único y determinista de pixel art a partir del historial de GitHub; el GIF animado del README sigue creciendo con cada commit 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - Estadísticas diarias de Todoist en tu README de perfil
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - Cuenta las visitas de tu README.md, Issues y PR en GitHub
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - Añade un contador de visitas al estilo de los años 90 con una línea de Markdown.
- [Visitor Count](https://pufler.dev/badge-it/) - Cuenta las visitas del README.md y puede usarse con shields.io
- [Shields Project](https://shields.io/) - Crea insignias de perfil con Shields, compatible con Simple Icons
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - Generador de tarjetas SVG dinámicas y API en directo para estadísticas de GitHub, distribución de lenguajes, hábitos de commits, rachas de contribuciones, clasificación de desarrolladores, trofeos y patrocinadores. ([Generador web](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - Obtén estadísticas de GitHub generadas dinámicamente en tus README
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 Generador de estadísticas SVG ultrarrápido y atractivo, con diseño True Glassmorphism y temas
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - Genera gráficos de contribuciones, estadísticas y SVG de los lenguajes principales con estilo de terminal para el README de tu perfil de GitHub
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: Obtén estadísticas de contribuciones de GitHub generadas dinámicamente en tus README (repositorios en los que realmente has contribuido)
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 Haz que tu gráfico de contribuciones de GitHub caiga por efecto de la gravedad y choque con texto personalizado para crear un hermoso SVG animado
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 ¡Mantén la motivación y presume de tu racha de contribuciones! 🌟 Muestra el total de contribuciones, la racha actual y la más larga en el README de tu perfil de GitHub
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - Tarjetas de estadísticas de GitHub autoalojables, con 16 estilos visuales, 21 temas, tarjetas de gráficos (anillos, medidores y actividad de commits) y un creador visual
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - Iconos SVG de marcas populares para tus archivos README.md
- [Laravel GitHub Profile Visit Counter](https://github.com/caneco/laravel-github-profile-view-counter) - Añade a tu proyecto Laravel una insignia rápida para contar las visitas a tu perfil.
- [Dev Metrics in Readme](https://github.com/athul/waka-readme) - Métricas semanales de [WakaTime](https://wakatime.com/) en tu README de perfil
- [Profile Activity Generator](https://github.com/omidnikrah/profile-activity-generator) - Genera actividad personalizada para el README de tu perfil
- [Current UTC time](https://github.com/jojoee/jojoee) - Ejemplo de código de un servidor que puede servir contenido dinámico en un perfil de GitHub
- [Github Activity in README](https://github.com/jamesgeorge007/github-activity-readme) - Actualiza `README.md` con la actividad reciente de GitHub de un usuario
- [Github Profile README Generator](https://github.com/rahuldkjain/github-profile-readme-generator) - Esta herramienta facilita la creación de un README de perfil de GitHub con complementos recientes como el recuento de visitas y las estadísticas de GitHub.
