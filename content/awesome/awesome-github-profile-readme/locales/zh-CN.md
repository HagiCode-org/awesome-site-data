## 工具
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - 从 GitHub 历史记录中生成独一无二、结果确定的像素艺术盆景；每次提交都会让 README 中的动画 GIF 继续生长 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - 在个人资料 README 中每日展示 Todoist 统计数据
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - 统计 GitHub 上 README.md、Issues 和 PR 的访客数
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - 只需一行 Markdown，即可添加 20 世纪 90 年代风格的访客计数器。
- [Visitor Count](https://pufler.dev/badge-it/) - 统计 README.md 的访客数，可与 shields.io 搭配使用
- [Shields Project](https://shields.io/) - 使用 Shields 创建个人资料徽章，并兼容 Simple Icons
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - 动态 SVG 卡片生成器和实时 API，可展示 GitHub 统计、语言分布、提交习惯矩阵、贡献连续记录、开发者排名、奖杯和赞助者。([网页生成器](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - 在 README 中动态生成 GitHub 统计数据
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 极速且美观的 SVG 统计生成器，采用 True Glassmorphism 设计并提供多种主题
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - 为 GitHub 个人资料 README 生成终端风格的贡献图、统计数据和常用语言 SVG 图
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: 在 README 中动态生成 GitHub 贡献者统计数据（你实际提交过代码的仓库）
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 让 GitHub 贡献图在重力作用下坠落，与自定义文字碰撞，生成精美的动画 SVG
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 保持动力并展示你的贡献连续记录！🌟 在 GitHub 个人资料 README 中显示贡献总数、当前连续记录和最长连续记录
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - 可自行托管的 GitHub 统计卡片，提供 16 种视觉样式、21 种主题、图表卡片（环形图、仪表盘、提交活动）和可视化卡片构建器
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - 为 README.md 文件提供热门品牌的 SVG 图标
- [Laravel GitHub Profile Visit Counter](https://github.com/caneco/laravel-github-profile-view-counter) - 为 Laravel 项目添加快速徽章，统计个人资料访问量。
- [Dev Metrics in Readme](https://github.com/athul/waka-readme) - 在个人资料 README 中展示 [WakaTime](https://wakatime.com/) 每周指标
- [Profile Activity Generator](https://github.com/omidnikrah/profile-activity-generator) - 为个人资料 README 生成自定义活动内容
