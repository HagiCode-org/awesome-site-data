## Инструменты
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - Создаёт уникальный детерминированный бонсай в пиксельном стиле на основе истории GitHub: анимированный GIF в README растёт с каждым коммитом 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - Ежедневная статистика Todoist в README профиля
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - Подсчитывает посещения README.md, Issues и PR на GitHub
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - Добавьте счётчик посещений в стиле 1990-х одной строкой Markdown.
- [Visitor Count](https://pufler.dev/badge-it/) - Подсчитывает посещения README.md и может использоваться с shields.io
- [Shields Project](https://shields.io/) - Создавайте значки профиля с Shields, совместимые с Simple Icons
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - Генератор динамических SVG-карточек и API в реальном времени для статистики GitHub, распределения языков, привычек коммитов, серий вкладов, рейтинга разработчиков, трофеев и спонсоров. ([Веб-генератор](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - Получайте динамически создаваемую статистику GitHub в README
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 Молниеносно быстрый и эстетичный генератор SVG-статистики с дизайном True Glassmorphism и темами
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - Создавайте график вкладов, статистику и SVG с популярными языками в стиле терминала для README профиля GitHub
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: Получайте динамическую статистику участников GitHub в README (репозитории, в которые вы действительно вносили коммиты)
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 Подчините график вкладов GitHub гравитации и столкните его с произвольным текстом, чтобы создать красивый анимированный SVG
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 Сохраняйте мотивацию и демонстрируйте серию вкладов! 🌟 Показывайте общее число вкладов, текущую и самую длинную серию в README профиля GitHub
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - Самостоятельно размещаемые карточки статистики GitHub: 16 визуальных стилей, 21 тема, карточки диаграмм (кольцевые, шкалы, активность коммитов) и визуальный конструктор карточек
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - SVG-значки популярных брендов для файлов README.md
