## 工具
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - 從 GitHub 歷史記錄中生成獨一無二、結果確定的像素藝術盆景；每次提交都會讓 README 中的動畫 GIF 繼續生長 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - 在個人檔案 README 中每日展示 Todoist 統計資料
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - 統計 GitHub 上 README.md、Issues 和 PR 的訪客数
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - 只需一行 Markdown，即可添加 20 世紀 90 年代風格的訪客計数器。
- [Visitor Count](https://pufler.dev/badge-it/) - 統計 README.md 的訪客数，可與 shields.io 搭配使用
- [Shields Project](https://shields.io/) - 使用 Shields 建立個人檔案徽章，並兼容 Simple Icons
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - 動態 SVG 卡片生成器和實時 API，可展示 GitHub 統計、語言分布、提交習慣矩陣、貢獻連續記錄、開發者排名、獎杯和讚助者。([網頁生成器](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - 在 README 中動態生成 GitHub 統計資料
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 極速且美觀的 SVG 統計生成器，採用 True Glassmorphism 設計並提供多種主題
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - 為 GitHub 個人檔案 README 生成終端風格的貢獻圖、統計資料和常用語言 SVG 圖
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: 在 README 中動態生成 GitHub 貢獻者統計資料（你實際提交過代碼的倉庫）
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 讓 GitHub 貢獻圖在重力作用下墜落，與自定義文字碰撞，生成精美的動畫 SVG
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 保持動力並展示你的貢獻連續記錄！🌟 在 GitHub 個人檔案 README 中顯示貢獻總数、當前連續記錄和最長連續記錄
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - 可自行托管的 GitHub 統計卡片，提供 16 種視覺樣式、21 種主題、圖表卡片（环形圖、儀表盘、提交活動）和可視化卡片構建器
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - 為 README.md 文件提供熱門品牌的 SVG 圖標
- [Laravel GitHub Profile Visit Counter](https://github.com/caneco/laravel-github-profile-view-counter) - 為 Laravel 專案添加快速徽章，統計個人檔案訪問量。
- [Dev Metrics in Readme](https://github.com/athul/waka-readme) - 在個人檔案 README 中展示 [WakaTime](https://wakatime.com/) 每周指標
- [Profile Activity Generator](https://github.com/omidnikrah/profile-activity-generator) - 為個人檔案 README 生成自定義活動內容
