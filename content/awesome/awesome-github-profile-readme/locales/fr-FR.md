## Outils
- [Git Bonsai](https://github.com/egorthinks/git-bonsai) - Crée un bonsaï pixel-art unique et déterministe à partir de l’historique GitHub : le GIF animé du README grandit à chaque commit 🌳
- [Todoist Stats in Readme](https://github.com/abhisheknaiidu/todoist-readme) - Statistiques Todoist quotidiennes dans votre README de profil
- [Visitor Badge](https://visitor-badge.glitch.me/#docs) - Comptez les visites de votre README.md, des Issues et des PR sur GitHub
- [1990s style Visitor Counter](https://twitter.com/ryanlanciaux/status/1283755637126705152) - Ajoutez un compteur de visites au style des années 1990 avec une seule ligne Markdown.
- [Visitor Count](https://pufler.dev/badge-it/) - Comptez les visites du README.md avec un badge compatible avec shields.io
- [Shields Project](https://shields.io/) - Créez des badges de profil avec Shields, compatibles avec Simple Icons
- [GitCard Studio](https://github.com/creativecodeco/gitcard-studio) - Générateur de cartes SVG dynamiques et API en direct pour les statistiques GitHub, la répartition des langages, les habitudes de commit, les séries de contributions, le classement des développeurs, les trophées et les sponsors. ([Générateur web](https://gitcard-studio.creativecode.com.co/))
- [Github Readme Stats](https://github.com/anuraghazra/github-readme-stats) - Obtenez des statistiques GitHub générées dynamiquement dans vos README
- [GitHub Stats](https://github.com/dvigo/github-stats) - 🚀 Générateur de statistiques SVG ultrarapide et esthétique, avec un vrai design Glassmorphism et des thèmes
- [Github Readme Insight Terminal Ascii](https://github.com/seuthootDev/github-readme-insight-terminal-ascii) - Générez pour votre README de profil GitHub un graphe de contributions, des statistiques et des SVG de langages principaux au style terminal
- [Github Contributor Stats](https://github.com/HwangTaehyun/github-contributor-stats) - :fire: Affichez dans vos README des statistiques GitHub de contributeur générées dynamiquement (dépôts auxquels vous avez réellement contribué)
- [GitHub Gravity](https://github.com/flycran/github-gravity) - 🌌 Faites tomber votre graphe de contributions GitHub sous l’effet de la gravité et entrez en collision avec du texte personnalisé pour créer un superbe SVG animé
- [GitHub Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats) - 🔥 Restez motivé et mettez en valeur votre série de contributions ! 🌟 Affichez le total de vos contributions, votre série actuelle et votre plus longue série dans le README de votre profil GitHub
- [gitglance](https://github.com/rafaeloliveiraz/gitglance) - Cartes de statistiques GitHub hébergeables soi-même, avec 16 styles visuels, 21 thèmes, des cartes graphiques (anneau, jauges, activité des commits) et un éditeur visuel
- [Simple Icons](https://github.com/simple-icons/simple-icons#cdn-usage) - Icônes SVG de marques populaires pour vos fichiers README.md
- [Laravel GitHub Profile Visit Counter](https://github.com/caneco/laravel-github-profile-view-counter) - Ajoutez à votre projet Laravel un badge rapide pour compter les visites de votre profil.
- [Dev Metrics in Readme](https://github.com/athul/waka-readme) - Indicateurs hebdomadaires [WakaTime](https://wakatime.com/) dans votre README de profil
- [Profile Activity Generator](https://github.com/omidnikrah/profile-activity-generator) - Générez une activité personnalisée pour votre README de profil
- [Current UTC time](https://github.com/jojoee/jojoee) - Exemple de code serveur pouvant fournir du contenu dynamique sur un profil GitHub
- [Github Activity in README](https://github.com/jamesgeorge007/github-activity-readme) - Mettez à jour le `README.md` avec l’activité GitHub récente d’un utilisateur
- [Github Profile README Generator](https://github.com/rahuldkjain/github-profile-readme-generator) - Cet outil facilite la création d’un README de profil GitHub avec les dernières extensions, comme le nombre de visiteurs et les statistiques GitHub.
- [Dynamic Profile Page On Github](https://github.com/umutphp/github-action-dynamic-profile-page) - Générez dynamiquement dans le README de profil GitHub la liste des commits des dépôts configurés.
- [npm package downloads](https://github.com/maddhruv/github-readme-npm-downloads) - Affichez tous vos packages npm et leur nombre total de téléchargements
