## 什么是数据科学？
**[`^        返回顶部        ^`](#awesome-data-science)**

如今，数据科学是计算机和互联网领域最热门的话题之一。人们至今已从应用程序和系统中收集了大量数据，现在正是分析这些数据的时候。接下来要根据数据提出建议，并对未来进行预测。你可以在[这里](https://www.quora.com/Data-Science/What-is-data-science)找到关于**数据科学**的核心问题，以及数百位专家给出的回答。

## 从哪里开始？
**[`^        返回顶部        ^`](#awesome-data-science)**

虽然并非绝对必要，但掌握一门编程语言是成为高效数据科学家的关键技能。目前最流行的语言是_Python_，其次是_R_。Python 是一种通用脚本语言，应用领域广泛。R 是面向统计学的领域专用语言，内置了大量常用统计工具。

[Python](https://python.org/) 远远领先于其他语言，是科学领域最受欢迎的语言，这很大程度上得益于其易用性以及活跃的用户软件包生态系统。安装软件包主要有两种方式：随 Python 一同提供的软件包管理器 Pip（使用 `pip install` 调用），以及功能强大的软件包管理器 [Anaconda](https://www.anaconda.com)（使用 `conda install` 调用），后者可以安装 Python、R 的软件包，还能下载 Git 等可执行程序。

与 R 不同，Python 并非从一开始就为数据科学而设计，但丰富的第三方库弥补了这一点。本文后面会列出更完整的软件包清单，而以下四个软件包是开启数据科学之旅的不错选择：[Scikit-Learn](https://scikit-learn.org/stable/index.html) 是通用数据科学软件包，实现了最受欢迎的算法，并提供丰富的文档、教程和模型示例。即使你更愿意自己实现算法，Scikit-Learn 也是了解许多常见算法基本原理的宝贵参考。[Pandas](https://pandas.pydata.org/) 可以将数据收集并分析为方便的表格格式。[Numpy](https://numpy.org/) 提供高速数学运算工具，重点支持向量和矩阵。[Seaborn](https://seaborn.pydata.org/) 基于 [Matplotlib](https://matplotlib.org/)，可快速生成精美的数据可视化，内置许多实用默认设置，并提供展示常见可视化绘制方式的图库。

开始成为数据科学家的旅程时，语言选择并非特别重要，Python 和 R 各有优缺点。选择你喜欢的语言，并查看下方列出的[免费课程](#free-courses)！

### 初学者路线图
如果你刚刚起步，推荐按照以下简单路径学习：

1. **学习 Python** – 从基础开始：变量、循环、函数
2. **学习核心库** – Pandas、NumPy、Matplotlib、Scikit-Learn
3. **通过入门项目练习** – 在 Kaggle 上尝试泰坦尼克号生存预测或房价预测
4. **学习数学基础** – 统计学、线性代数、概率论
5. **进阶学习机器学习** – 监督学习 → 无监督学习 → 深度学习

## 智能体

本节介绍适用于数据科学工作流的智能体框架和工具。

### 框架
- [ADK-Rust](https://github.com/zavora-ai/adk-rust) - 面向 Rust 的生产级 AI 智能体开发套件，采用模型无关设计（Gemini、OpenAI、Anthropic），支持多种智能体类型（LLM、图、工作流）、MCP 和内置遥测。
- [Lumen](https://github.com/holoviz/lumen) - 用于与数据对话的智能体框架，可将自然语言转换为 SQL、转换流水线和可视化。输出为声明式规范，可供检查、编辑、在笔记本中重新打开，或组合成仪表板。

### 工具
- [Frostbyte MCP](https://github.com/OzorOwn/frostbyte-mcp) - 为 AI 智能体提供 13 种数据工具的 MCP 服务器：实时加密货币价格、IP 地理定位、DNS 查询、网页转 Markdown、代码执行和截图。一个 API 密钥即可使用 40 多项服务。
- [Arch Tools](https://archtools.dev) - 提供 61 种可用于生产环境的 AI API 工具，适用于数据科学工作流，包括代码分析、网页抓取、NLP、图像生成、加密货币数据和搜索。支持 REST API 和 MCP 协议。[GitHub](https://github.com/Deesmo/Arch-AI-Tools)
- [Not Human Search](https://nothumansearch.ai) - 面向 AI 智能体的搜索引擎，索引了 9,000 多种 AI 工具和 API，并根据智能体就绪程度（llms.txt、OpenAPI、MCP、ai-plugin.json）进行评分。提供 REST API 和 MCP 服务器，以编程方式发现工具。[GitHub](https://github.com/unitedideas/nothumansearch)
- [DeepAlpha](https://github.com/stefanoviana/deepalpha) - 使用 LightGBM + XGBoost 集成模型的 AI 加密货币交易框架，具备 72 个机器学习特征。在样本外数据上经滚动前向验证的准确率为 70.9%。支持 Bybit 和 Binance。采用 MIT 许可证，可从 [PyPI](https://pypi.org/project/deepalpha-bot/) 获取。
- [CAJAL](https://github.com/Agnuxo1/CAJAL) - 本地 AI 智能体，可生成包含真实 arXiv 引文、IMRaD 结构和评审评分的出版级科学论文。通过 Ollama 和 4B–9B 模型实现 100% 离线运行。采用 MIT 许可证。[HuggingFace](https://huggingface.co/Agnuxo/CAJAL-9B-P2PCLAW)
- [ai-evaluation](https://github.com/future-agi/ai-evaluation) - 开源 LLM 与智能体评估框架，包含 50 多项指标、LLM-as-Judge 增强功能和防护扫描器（越狱、PII、提示注入）。适用于为 RAG 输出、智能体轨迹和函数调用行为评分。
- [Kitaru](https://github.com/zenml-io/kitaru) - 开源平台，可记录真实 AI 智能体运行过程、针对变更重放，并在部署前评估结果。
- [Jev Social](https://github.com/socai-io/jev-social) - 只读社交研究智能体，可让 Jev 选择有限范围内的 Instagram、TikTok 和 LinkedIn 操作，通过 Chrome 中的本地 socai CLI 执行，并在带引文的报告旁保留链接到来源的证据。
- [YYLO Benchmark](https://github.com/yylo-dev/yylo-benchmark) - 开源、可信主机上的实验运行器，适用于历史智能体任务、提供的编码提示和工作流。它可运行彼此独立的尝试并保留输出，之后还能用不同检查或评审器比较模型、工具框架和配置。采用 MIT 许可证。
- [YYLO](https://github.com/yylo-dev/yylo) - 面向编码智能体和可重复工作流的开源命令行编排工具，具有类型化的任务、验证、合并和发布就绪边界，并通过凭据记录支持仓库变更。采用 MIT 许可证，可通过 npm 安装。
- [YYLO Ledger](https://github.com/yylo-dev/yylo-ledger) - 面向编码智能体项目的命令行任务与工作流台账：在仓库内以哈希链 Markdown 保存看板和任务状态、跟踪凭据并归档，同时通过智能体工作树驱动类型化的合并与发布流程。采用 MIT 许可证。

### 研究与知识检索
- [BGPT MCP](https://bgpt.pro/mcp) - 为 AI 智能体提供科学论文数据库访问的 MCP 服务器。数据库基于从全文研究中提取的原始实验数据构建，每篇论文返回 25 多个结构化字段，包括方法、结果、样本量和质量分数。[GitHub](https://github.com/connerlambden/bgpt-mcp)
- [Chunk Tuner](https://github.com/shantanu-deshmukh/chunktuner) - 开源 Python 库和 MCP 服务器，用于评测 RAG 的文档分块策略、评估检索质量，并为语料推荐配置。
- [II-Commons](https://github.com/Intelligent-Internet/II-Commons-Skills) - 每日更新的技能和 CLI，可对 arXiv、PubMed/PMC 及受支持的美国政策语料进行确定性检索。
- [Spraay x402 Gateway](https://docs.spraay.app/#cat-research) - 面向 AI 智能体的 x402 支付网关，提供 23 个研究与参考端点，包括 Wikipedia、arXiv、PubMed、Wikidata、学术引用查询、实体提取等。通过 Base 和 Solana 上的 USDC 按次付费——无需 API 密钥或订阅。另提供 39 个类别的 150 多个端点，涵盖地理空间、AI 推理、DeFi 和计算等。[GitHub](https://github.com/plagtech)

- [Suppr](https://suppr.wilddata.cn/) - 面向研究人员的 AI 文献搜索、文档翻译和深度研究工作空间。
