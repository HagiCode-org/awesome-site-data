- [Vutron](https://github.com/jooy2/vutron) - Vite + Electron + Vue 3 + Vuetify + TypeScript에 대한 빠른 시작 템플릿.
- [electron-vite-vue](https://github.com/electron-vite/electron-vite-vue) - 정말 간단한 Electron + Vite + Vue 보일러 플레이트.
- [MōBrowser](https://teamdev.com/mobrowser) - 웹 기술로 데스크톱 앱 구축을위한 프레임 워크. Vite + Vue + Quasar에 대한 템플릿과 배관이 포함되어 있습니다.
- [sketch-to-vue](https://github.com/chenboxun87/sketch-to-vue) - Sketch MeaXure / MasterGo 디자인 수출을 픽셀 퍼펙트 Vue 2/3 구성 요소로 변환하는 Claude Code & Cursor에 대한 AI 기술. 대쉬보드/cockpit/big-screen 페이지를 위해 전문화하는: 세례적인 자산 해결책, ECharts 자동 탐지, 장면 도표 분석 및 가득 차있는 소비 감사.
- [OxideDock](https://github.com/fridzema/oxide-dock) - Tauri v2에 내장 된 Vue 3 데스크탑 앱 스타터, Tailwind CSS, Pinia, Vitest, Playwright 및 자동화 된 크로스 플랫폼 출시.
