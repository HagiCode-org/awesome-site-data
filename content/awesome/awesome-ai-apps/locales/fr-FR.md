## Pour commencer

### Prérequis

- **Python 3.10+** (Python 3.11+ recommandé pour les projets plus récents)
- **Git** pour cloner le dépôt
- **Gestionnaire de paquets** : `pip` ou `uv` (recommandé pour des installations plus rapides)
- **Clés API** : La plupart des projets nécessitent des clés API (voir les README de chaque projet)

### Démarrage rapide

1. **Cloner le dépôt**

   ```bash
   git clone https://github.com/Arindam200/awesome-ai-apps.git
   cd awesome-ai-apps
   ```

2. **Choisir un projet** et naviguer vers son répertoire

   ```bash
   cd starter_ai_agents/agno_starter  # Example: Start with Agno starter
   ```

3. **Configurer les variables d'environnement**

   ```bash
   cp .env.example .env  # Copy example environment file
   # Edit .env with your API keys
   ```

4. **Installer les dépendances**

   ```bash
   # Using pip
   pip install -r requirements.txt

   # OR using uv (recommended - faster)
   uv sync
   # or
   uv pip install -e .
   ```

5. **Lancer le projet**

   ```bash
   python main.py
   # or for Streamlit apps
   streamlit run app.py
   ```
