### 🧩 스타터 에이전트

**다양한 AI 프레임워크를 학습하고 확장하기 위한 빠른 시작 에이전트.** _21개 프로젝트_

- [AutoGen Tool-Calling Starter](starter_ai_agents/autogen_starter): 사용자 정의 도구가 포함된 Microsoft AutoGen `AssistantAgent` (Nebius Token Factory 제공)
- [AWS Strands Agent Starter](starter_ai_agents/aws_strands_starter): AWS Strands SDK를 사용한 날씨 보고 에이전트
- [CAMEL AI Model Benchmark](starter_ai_agents/camel_ai_starter): 다양한 AI 모델의 성능을 비교하는 벤치마크 도구
- [Coding Harness Starter](starter_ai_agents/coding_harness_starter): 계획, 승인 게이트 편집, 고정 테스트, 유계 검토가 포함된 OpenAI Agents SDK 코딩 루프 (Nebius Token Factory 제공)
- [CrewAI Research Crew](starter_ai_agents/crewai_starter): 다중 에이전트 연구 팀 예제
- [Docker cagent Multi-Agent Starter](starter_ai_agents/cagent_starter): Docker의 오픈소스 커스텀 가능 다중 에이전트 런타임
- [DSPy Optimization Starter](starter_ai_agents/dspy_starter): AI 시스템 구축 및 최적화를 위한 DSPy 프레임워크
- [Google Agent Development Kit Starter](starter_ai_agents/google_adk_starter): Google Agent Development Kit 스타터 템플릿
- [Hacker News Trend Analyst (Agno)](starter_ai_agents/agno_starter): Hacker News 추세 분석을 위한 Agno 기반 에이전트
- [Hugging Face smolagents Starter](starter_ai_agents/smolagents_starter): Hugging Face smolagents 코드 우선 웹 검색 에이전트
- [KAOS Kubernetes Multi-Agent Starter](starter_ai_agents/kaos_starter): MCP 도구와 인클러스터 LLM을 갖춘 Kubernetes 네이티브 다중 에이전트 시스템
- [LangChain Tool-Calling Starter](starter_ai_agents/langchain_starter): `create_tool_calling_agent` + `AgentExecutor`를 사용하는 LangChain 도구 호출 에이전트 (Nebius 제공)
- [LangGraph ReAct Agent Starter](starter_ai_agents/langgraph_starter): 사용자 정의 도구가 포함된 LangGraph 사전 구축 ReAct 에이전트 (`create_react_agent`) (Nebius 제공)
- [Letta Stateful Memory Agent](starter_ai_agents/letta_starter): 세션 간 지속되는 장기 메모리를 가진 상태 저장 에이전트
- [LlamaIndex Task Manager](starter_ai_agents/llamaindex_starter): LlamaIndex 기반 작업 비서
- [Mastra Tool-Calling Starter](starter_ai_agents/mastra_starter): 사용자 정의 도구가 포함된 TypeScript 우선 에이전트 (Nebius Token Factory 제공)
- [Microsoft Agent Framework Starter](starter_ai_agents/microsoft_agents_starter): Microsoft Agent Framework 기반 다중 에이전트 여행 계획 데모
- [OpenAI Agents SDK Starter](starter_ai_agents/openai_agents_sdk): 이메일 도우미와 하이쿠 작성기 예제가 포함된 OpenAI Agents SDK
- [PydanticAI Weather Bot](starter_ai_agents/pydantic_starter): 실시간 날씨 정보 에이전트
- [Sayna Realtime Voice Agent](starter_ai_agents/sayna_starter): 다중 공급자 STT/TTS(Deepgram, ElevenLabs, Azure, Google)와 WebSocket 스트리밍을 갖춘 실시간 음성 인프라
- [Semantic Kernel Starter](starter_ai_agents/semantic_kernel_starter): 플러그인 기반 도구 호출이 포함된 Microsoft Semantic Kernel `ChatCompletionAgent`

### 🎙️ 음성 에이전트

**실시간 음성 비서 및 스트리밍 음성 파이프라인** —— LiveKit, Pipecat, Gradium, 그리고 [VoxCode](voice_agents/Cursor_code_editor)(Deepgram + Cursor SDK) 포함. _9개 프로젝트_

- [Customer Support Voice Agent (LiveKit)](voice_agents/customer_support_agent): 컨텍스트를 유지하는 AI 매니저 인계, 노이즈 캔슬링, 비활성 처리를 갖춘 Nebius 제공 음성 지원 에이전트
- [Gemini Realtime Voice Agent (LiveKit)](voice_agents/livekit_gemini_agents): Google Gemini Live(`gemini` 멀티모달 실시간)를 사용한 LiveKit 룸 내 저지연 음성 대화용 LiveKit Agents
- [Healthcare Voice Contact Center](voice_agents/healthcare_contact_center): 예약, FAQ 처리, 슈퍼바이저 에스컬레이션을 갖춘 Pipecat 의료 컨택 센터
- [Multilingual Voice Agent (Pipecat + Sarvam)](voice_agents/pipecat_agent): Sarvam STT/TTS와 OpenAI를 사용한 채팅용 Pipecat 음성 파이프라인; Pipecat runner를 통한 WebRTC(브라우저) 또는 Daily 전송
- [RSVP Confirmation Voice Agent (LiveKit)](voice_agents/livekit_rsvp_agent): 참석자에게 전화하고 RSVP를 확인하며 JSON 기반 이벤트 데이터베이스를 업데이트하는 발신 음성 에이전트
- [Speed-to-Lead Sales Voice Agent](voice_agents/speed_to_lead_agent): 유입 리드에 즉시 전화하고 전문가에게 라우팅하며 모의 CRM에 기록하는 LiveKit 기반 음성 에이전트
- [VoxCode — Deepgram + Cursor Voice Coding Agent](voice_agents/Cursor_code_editor): 코드베이스 요약 및 아키텍처 Q&A를 위한 로컬 음성 워크스페이스; Deepgram Voice Agent 오케스트레이션, Nebius 추론, 선택적 Cursor SDK 파일 검사 및 편집
- [Web-Search Voice Agent (LiveKit)](voice_agents/livekit_web_search_agent): Olostep 기반 `web_search` 도구를 갖춘 LiveKit + Gemini 실시간 음성 에이전트(신선하고 출처가 인용된 답변 제공)

## 시작하기

### 사전 요구사항

- **Python 3.10+**(최신 프로젝트에는 Python 3.11+ 권장)
- **Git**(저장소 복제용)
- **패키지 관리자**: `pip` 또는 `uv`(더 빠른 설치를 위해 권장)
- **API 키**: 대부분의 프로젝트에는 API 키가 필요합니다(각 프로젝트의 README 참조)

### 빠른 시작

1. **저장소 복제**

   ```bash
   git clone https://github.com/Arindam200/awesome-ai-apps.git
   cd awesome-ai-apps
   ```

2. **프로젝트 선택** 후 해당 디렉터리로 이동

   ```bash
   cd starter_ai_agents/agno_starter  # Example: Start with Agno starter
   ```

3. **환경 변수 설정**

   ```bash
   cp .env.example .env  # Copy example environment file
   # Edit .env with your API keys
   ```

4. **의존성 설치**

   ```bash
   # Using pip
   pip install -r requirements.txt

   # OR using uv (recommended - faster)
   uv sync
   # or
   uv pip install -e .
   ```

5. **프로젝트 실행**

   ```bash
   python main.py
   # or for Streamlit apps
   streamlit run app.py
   ```

## 🤝 기여

우리는 커뮤니티의 기여를 환영합니다! 기여 방법은 다음과 같습니다:

- 💡 **새 프로젝트 추가**: 본인의 AI 에이전트 예제 제출
- 🔧 **문제 수정**: 코드 개선 및 버그 수정 기여
- 📝 **문서 개선**: 프로젝트를 더 접근하기 쉽게
- 🐛 [GitHub Issues](https://github.com/Arindam200/awesome-ai-apps/issues)를 통해 **버그 보고** 또는 개선 제안

**기여하기 전에:**

- 자세한 내용은 [기여 가이드라인](CONTRIBUTING.md)을 읽으세요
- 중복을 피하기 위해 기존 이슈 확인
- 프로젝트 구조 및 명명 규칙 준수
- 프로젝트에 완전한 README.md가 포함되어 있는지 확인

**중요:** 이 프로젝트는 [기여자 행동 강령](CODE_OF_CONDUCT.md)을 따릅니다. 참여함으로써 그 조건에 동의하는 것으로 간주됩니다.

## 📜 라이선스
