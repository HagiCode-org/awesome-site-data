## はじめに

### 前提条件

- **Python 3.10+**（新しいプロジェクトには Python 3.11+ を推奨）
- **Git**（リポジトリのクローン用）
- **パッケージマネージャー**：`pip` または `uv`（インストールを高速化するため推奨）
- **API キー**：ほとんどのプロジェクトには API キーが必要です（各プロジェクトの README を参照）

### クイックスタート

1. **リポジトリをクローン**

   ```bash
   git clone https://github.com/Arindam200/awesome-ai-apps.git
   cd awesome-ai-apps
   ```

2. **プロジェクトを選択**し、そのディレクトリに移動

   ```bash
   cd starter_ai_agents/agno_starter  # Example: Start with Agno starter
   ```

3. **環境変数を設定**

   ```bash
   cp .env.example .env  # Copy example environment file
   # Edit .env with your API keys
   ```

4. **依存関係をインストール**

   ```bash
   # Using pip
   pip install -r requirements.txt

   # OR using uv (recommended - faster)
   uv sync
   # or
   uv pip install -e .
   ```

5. **プロジェクトを実行**

   ```bash
   python main.py
   # or for Streamlit apps
   streamlit run app.py
   ```
