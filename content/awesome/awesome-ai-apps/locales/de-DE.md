## Erste Schritte

### Voraussetzungen

- **Python 3.10+** (Python 3.11+ für neuere Projekte empfohlen)
- **Git** zum Klonen des Repositories
- **Paketmanager**: `pip` oder `uv` (für schnellere Installationen empfohlen)
- **API-Schlüssel**: Die meisten Projekte benötigen API-Schlüssel (siehe die jeweiligen Projekt-READMEs)

### Schnellstart

1. **Repository klonen**

   ```bash
   git clone https://github.com/Arindam200/awesome-ai-apps.git
   cd awesome-ai-apps
   ```

2. **Ein Projekt auswählen** und in dessen Verzeichnis navigieren

   ```bash
   cd starter_ai_agents/agno_starter  # Example: Start with Agno starter
   ```

3. **Umgebungsvariablen einrichten**

   ```bash
   cp .env.example .env  # Copy example environment file
   # Edit .env with your API keys
   ```

4. **Abhängigkeiten installieren**

   ```bash
   # Using pip
   pip install -r requirements.txt

   # OR using uv (recommended - faster)
   uv sync
   # or
   uv pip install -e .
   ```

5. **Projekt ausführen**

   ```bash
   python main.py
   # or for Streamlit apps
   streamlit run app.py
   ```
