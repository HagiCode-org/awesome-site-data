## Начало работы

### Предварительные требования

- **Python 3.10+** (Python 3.11+ рекомендуется для новых проектов)
- **Git** для клонирования репозитория
- **Менеджер пакетов**: `pip` или `uv` (рекомендуется для более быстрой установки)
- **API-ключи**: Большинству проектов требуются API-ключи (см. отдельные README проектов)

### Быстрый старт

1. **Клонируйте репозиторий**

   ```bash
   git clone https://github.com/Arindam200/awesome-ai-apps.git
   cd awesome-ai-apps
   ```

2. **Выберите проект** и перейдите в его каталог

   ```bash
   cd starter_ai_agents/agno_starter  # Example: Start with Agno starter
   ```

3. **Настройте переменные окружения**

   ```bash
   cp .env.example .env  # Copy example environment file
   # Edit .env with your API keys
   ```

4. **Установите зависимости**

   ```bash
   # Using pip
   pip install -r requirements.txt

   # OR using uv (recommended - faster)
   uv sync
   # or
   uv pip install -e .
   ```

5. **Запустите проект**

   ```bash
   python main.py
   # or for Streamlit apps
   streamlit run app.py
   ```
