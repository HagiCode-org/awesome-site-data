# 一、項目簡介

本項目是由[飛槳官方](https://www.paddlepaddle.org.cn/?fr=paddleEdu_github)打造的一站式深度學習在線百科。飛槳致力於讓深度學習技術創新與應用更加簡單。瞭解更多飛槳內容，請訪問[飛槳官網](https://www.paddlepaddle.org.cn/?fr=paddleEdu_github)。本項目涵蓋：

📒課程類：[**零基礎實踐深度學習**](https://aistudio.baidu.com/aistudio/course/introduce/1297)、**產業實踐深度學習**、**[特色課程](https://aistudio.baidu.com/aistudio/education/group/info/24322)、飛槳套件課程彙總資料**

📒書籍類：**《動手學深度學習》飛槳版**

📒寶典類：[**深度學習百問**](https://paddlepedia.readthedocs.io/en/latest/index.html)、**面試寶典**

📒案例類：**[飛槳產業實踐範例庫](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library)**（包含智慧城市：[火災煙霧檢測](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library/Fire_and_Smoke_Detection)、 [安全帽檢測](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library/Hemtle%20Detection) ；智能製造：[鋼材缺陷檢測](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library/paddlex_steel_defect_seg-master) 、 [機械手抓取](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library/robot_grab)；互聯網：[財報識別與關鍵字段抽取](https://github.com/PaddlePaddle/awesome-DeepLearning/tree/master/Paddle_Industry_Practice_Sample_Library/Report_Recognition_and_Analysis) 等。

從理論到實踐，從科研到產業應用，各類學習材料一應俱全，旨在幫助開發者高效地學習和掌握深度學習知識，快速成爲AI跨界人才。

<center><img src="./docs/images/cover/repo_cover1.png" width=60%></center>

* **內容全面**：無論您是深度學習初學者，還是資深用戶，都可以在本項目中快速獲取到需要的學習材料。
* **形式豐富**：材料形式多樣，包括可在線運行的notebook、視頻、書籍、B站直播等，滿足您隨時隨地學習的需求。
* **實時更新**：本項目中涉及到的代碼均匹配Paddle最新發布版本，開發者可以實時學習最新的深度學習任務實現方案。
* **前沿分享**：定期分享頂會最新論文解讀和代碼復現，開發者可以實時掌握最新的深度學習算法。

# 👉書籍類

## <span id ='dive'>《動手學深度學習》paddle版</span>

本項目將《[動手學深度學習](http://zh.d2l.ai/)》原書中MXNet代碼實現改爲PaddlePaddle實現。原書作者：阿斯頓·張、李沐、扎卡里 C. 立頓、亞歷山大 J. 斯莫拉以及其他社區貢獻者，GitHub地址：https://github.com/d2l-ai/d2l-zh。

本項目面向對深度學習感興趣，尤其是想使用PaddlePaddle進行深度學習的童鞋。本項目並不要求你有任何深度學習或者機器學習的背景知識，你只需瞭解基礎的數學和編程，如基礎的線性代數、微分和概率，以及基礎的Python編程。

### 代碼貢獻規範

> pip install pre-commit
>
> pre-commit install

添加修改的代碼後，對修改的文件進行代碼規範，pre-commit 會自動調整代碼格式，執行一次即可，後續commit不需要再執行。提交pr流程，詳見：[awesome-DeepLearning 提交 pull request 流程](./examples/awesome-DeepLearning_pr_procedure.md)。
