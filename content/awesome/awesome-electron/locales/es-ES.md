# Awesome Electron [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Recursos útiles para crear aplicaciones con [Electron](https://electronjs.org)

Electron es un framework de código abierto para crear aplicaciones de escritorio con tecnologías web. Combina el motor de renderizado Chromium con el entorno de ejecución de Node.js.
