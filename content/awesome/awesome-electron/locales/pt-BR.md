> Recursos úteis para criar aplicativos com [Electron](https://electronjs.org)

Electron é um framework de código aberto para criar aplicativos de desktop usando tecnologias web. Ele combina o mecanismo de renderização Chromium com o ambiente de execução do Node.js.
