# Awesome Electron [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

[<img src="electron-logo.svg" align="right" width="100">](https://electronjs.org)

> Полезные ресурсы для создания приложений на [Electron](https://electronjs.org)

Electron — это фреймворк с открытым исходным кодом для создания настольных приложений с помощью веб-технологий. Он объединяет движок рендеринга Chromium и среду выполнения Node.js.
