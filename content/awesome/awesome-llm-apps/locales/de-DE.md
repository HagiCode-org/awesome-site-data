## 🚀 Jetzt einen starten

Geben Sie Ihrem Programmieragenten in 10 Sekunden einen neuen Skill:

```bash
npx skills add https://github.com/Shubhamsaboo/awesome-llm-apps/tree/main/agent_skills/project-graveyard
```

Fragen Sie ihn dann: *„Warum werde ich mit meinen Nebenprojekten nie fertig?“*

Oder klonen und starten Sie einen beliebigen Agenten in 30 Sekunden:

```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
pip install -r requirements.txt
streamlit run travel_agent.py
```

> 📬 Jede Woche erscheinen neue Vorlagen. [Erhalten Sie sie per E-Mail bei Unwind AI](https://www.theunwindai.com).
