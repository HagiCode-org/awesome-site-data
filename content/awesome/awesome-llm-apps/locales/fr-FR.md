## 🚀 Lancez-en un maintenant

Offrez une nouvelle compétence à votre agent de programmation en 10 secondes :

```bash
npx skills add https://github.com/Shubhamsaboo/awesome-llm-apps/tree/main/agent_skills/project-graveyard
```

Puis demandez-lui : *« Pourquoi est-ce que je ne termine jamais mes projets personnels ? »*

Ou clonez et lancez n’importe quel agent en 30 secondes :

```bash
git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps/starter_ai_agents/ai_travel_agent
pip install -r requirements.txt
streamlit run travel_agent.py
```

> 📬 De nouveaux modèles arrivent chaque semaine. [Recevez-les dans votre boîte mail sur Unwind AI](https://www.theunwindai.com).
