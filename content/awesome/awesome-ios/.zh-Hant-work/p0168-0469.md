- [PredicateFlow](@156) - 撰寫出色、強型別且易讀的 NSPredicate，讓你以流暢的方式撰寫 NSPredicate，無須猜測屬性名稱、述詞運算，也不會寫錯引數型別。
- [PrediKit](@157) - 適用於 iOS、macOS、tvOS 與 watchOS 的 NSPredicate DSL。靈感來自 SnapKit，並以 Swift 用心撰寫。
- [Skopelos](@158) - 極簡、執行緒安全、無樣板程式碼且超級易用的 Core Data 版 Active Record。使用 Core Data 所需的一切盡在於此。
- [Sync](@159) - 以現代 Swift 將 JSON 同步至 Core Data。
