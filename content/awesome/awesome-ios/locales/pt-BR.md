## Análise de dados

 *Plataformas de análise, SDKs, rastreamento de erros e respostas em tempo real sobre o seu aplicativo*

- [Answers by Fabric](https://get.fabric.io) - O Answers oferece insights em tempo real sobre a experiência das pessoas no seu aplicativo.
- [Aptabase](https://aptabase.com/for-swift) - Análise de dados simples, de código aberto e com foco em privacidade para aplicativos Swift.
- [Bugsnag](https://www.bugsnag.com/platforms/ios-crash-reporting) - Rastreamento de erros com plano gratuito. Os relatórios de erro incluem dados sobre o dispositivo, a versão e o usuário, e aceitam dados arbitrários.
- [Countly](https://count.ly) - Plataforma de código aberto de análise mobile e web, relatórios de falhas e notificações push para iOS e Android.
- [devtodev](https://www.devtodev.com/) - Serviço de análise abrangente que aprimora seu projeto e economiza tempo no desenvolvimento do produto.
- [Embrace](http://embrace.io) - Observabilidade mobile, construída sobre o OpenTelemetry, para oferecer aplicativos confiáveis e focados no usuário.
- [Emerge Tools](https://www.emergetools.com) - Evite regressões de tamanho e desempenho do aplicativo em cada pull request e receba insights automatizados sobre como melhorar.
- [Instabug](https://instabug.com) - Feedback no aplicativo, relatórios de bugs e falhas; corrija bugs mais rápido com os passos do usuário, gravações de vídeo, anotações de tela e registro de requisições de rede.
- [Matomo](https://github.com/matomo-org/matomo-sdk-ios) - O MatomoTracker é um SDK para iOS, tvOS e macOS que envia dados de análise do aplicativo para um servidor Matomo.
- [Measure](https://measure.sh/) - Monitoramento de aplicativos móveis de código aberto e auto-hospedável, com rastreamento de erros, rastreamento de desempenho e linhas do tempo completas das sessões, para gastar menos tempo juntando contexto e corrigir problemas mais rápido.
- [Mixpanel](https://mixpanel.com/) - Plataforma avançada de análise de dados.
- [MOCA Analytics](https://www.mocaplatform.com/features) - Backend pago de análise de dados multiplataforma.
- [Segment](https://github.com/segmentio/analytics-ios) - A forma descomplicada de integrar análise de dados a qualquer aplicativo iOS.
- [Sentry](https://sentry.io/) - O Sentry oferece monitoramento de erros auto-hospedado e baseado em nuvem que ajuda todas as equipes de software a descobrir, triar e priorizar erros em tempo real.
- [Shake](https://www.shakebugs.com/) - Ferramenta de feedback e relatório de bugs no aplicativo. Corrija bugs até 50x mais rápido com dados detalhados do dispositivo, passos para reprodução, gravação de vídeo, dados de caixa-preta, requisições de rede e logs personalizados.

## Roteamento de aplicativos

  *Roteamento elegante de URLs, frameworks de navegação, deep links e muito mais*

- [ApplicationCoordinator](https://github.com/AndreyPanov/ApplicationCoordinator) - Coordinator é um objeto que gerencia o fluxo de navegação e repassa o controle do fluxo para o próximo coordinator ao avançar para a próxima etapa da cadeia.
- [Appz](https://github.com/SwiftKitz/Appz) - Abra facilmente aplicativos externos e crie deep links para eles, recorrendo à web caso não estejam instalados.
- [Composable Navigator](https://github.com/Bahn-X/swift-composable-navigator) - Uma biblioteca de código aberto para criar aplicativos SwiftUI com suporte a deep links, pensada para composição, testes e ergonomia
- [Crossroad](https://github.com/giginet/Crossroad) - Crossroad é um roteador de URLs focado em lidar com esquemas de URL personalizados. Com ele, você pode rotear vários esquemas de URL e obter argumentos e parâmetros facilmente.
- [DeepLinkKit](https://github.com/button/DeepLinkKit) - Uma forma esplêndida, baseada em blocos e em correspondência de rotas, de lidar com seus deep links.
- [JLRoutes](https://github.com/joeldev/JLRoutes) - Biblioteca de roteamento de URLs para iOS com uma API simples baseada em blocos.
- [Linker](https://github.com/MaksimKurpa/Linker) - Forma leve de lidar com deep links internos e externos no iOS.
- [Marshroute](https://github.com/avito-tech/Marshroute) - Marshroute é uma biblioteca iOS para tornar seus Routers simples, mas extremamente poderosos.
- [RouteComposer](https://github.com/ekazaev/route-composer) - Biblioteca que ajuda nas tarefas de composição de view controllers, roteamento e deep linking.
- [RxFlow](https://github.com/RxSwiftCommunity/RxFlow) - Framework de navegação para aplicativos iOS baseado no padrão Reactive Flow Coordinator.
- [SwiftCurrent](https://github.com/wwt/SwiftCurrent) - Uma biblioteca para gerenciar fluxos de trabalho complexos.
- [SwiftRouter](https://github.com/skyline75489/SwiftRouter) - Um roteador de URLs para iOS.
- [URLNavigator](https://github.com/devxoul/URLNavigator) - Roteamento elegante de URLs para Swift
- [WAAppRouting](https://github.com/Wasappli/WAAppRouting) - Roteamento no iOS feito do jeito certo. Lida tanto com o reconhecimento de URLs quanto com a exibição de controllers com os parâmetros já processados. Tudo em uma linha, com a pilha de controllers preservada automaticamente!

## Padrões de arquitetura

*Clean Architecture, Viper, MVVM, reativa... escolha sua arma.*

- [Clean Architecture for SwiftUI + Combine](https://github.com/nalexn/clean-architecture-swiftui) - Um projeto de demonstração que mostra a configuração de produção de um aplicativo SwiftUI com Clean Architecture.

- [The Composable Architecture](https://github.com/pointfreeco/swift-composable-architecture) - The Composable Architecture é uma biblioteca para criar aplicativos de forma consistente e compreensível, pensada para composição, testes e ergonomia.
- [Viperit](https://github.com/ferranabello/Viperit) - Framework VIPER para iOS. Desenvolva um aplicativo seguindo a arquitetura VIPER de forma fácil. Escrito e testado em Swift.

### Extensões

*Extensões do editor de código e de projetos do Xcode.*

* [CleanClosureXcode](https://github.com/BalestraPatrick/CleanClosureXcode) - Uma extensão do Xcode Source Editor para limpar a sintaxe de closures.
* [xTextHandler](https://github.com/cyanzhong/xTextHandler) - Conjunto de ferramentas de extensão do Xcode Source Editor (plugins para o Xcode 8).
* [SwiftInitializerGenerator](https://github.com/Bouke/SwiftInitializerGenerator) - Extensão de código-fonte do Xcode 8 para gerar inicializadores Swift.
* [XcodeEquatableGenerator](https://github.com/sergdort/XcodeEquatableGenerator) - Extensão de código-fonte do Xcode 8 que gera conformidade ao protocolo Equatable de Swift com base na seleção de tipo e campos.
* [Import](https://github.com/markohlebar/Import) - Extensão do Xcode para adicionar imports de qualquer lugar do código.
* [Mark](https://github.com/velyan/Mark) - Extensão do Xcode para gerar comentários MARK.
* [XShared](https://github.com/Otbivnoe/XShared) - Extensão do Xcode que permite copiar o código com aspas de formatação especiais para redes sociais (Slack, Telegram).
* [XGist](https://github.com/Bunn/Xgist) - Extensão do Xcode que permite enviar a sua seleção de texto ou o arquivo inteiro para o Gist do GitHub e copia automaticamente a URL do Gist para a sua área de transferência.
* [Swiftify](https://swiftify.com/) - Conversor online de código Objective-C para Swift e extensão do Xcode.
* [DocumenterXcode](https://github.com/serhii-londar/DocumenterXcode) - Tentativa de dar uma nova vida ao VVDocumenter-Xcode como extensão de editor de código.
* [Snowonder](https://github.com/Karetski/Snowonder) - Formatador mágico de declarações de import para o Xcode.
* [XVim2](https://github.com/XVimProject/XVim2) - Atalhos de teclado do Vim para o Xcode 9.
* [Comment Spell Checker](https://github.com/velyan/Comment-Spell-Checker) - Extensão do Xcode para verificação ortográfica e correção automática de comentários de código.
* [nef](https://github.com/bow-swift/nef-plugin) - Esta extensão do Xcode permite selecionar um trecho de código e exportá-lo como snippet. Disponível na Mac AppStore.
