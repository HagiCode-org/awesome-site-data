## 분석

 *분석 플랫폼, SDK, 오류 추적 및 앱에 대한 실시간 답변*

- [Answers by Fabric](https://get.fabric.io) - Answers는 앱에서 사람들이 겪는 경험에 대한 실시간 인사이트를 제공합니다.
- [Aptabase](https://aptabase.com/for-swift) - Swift 앱을 위한 오픈 소스, 개인정보 보호 우선의 간단한 분석 도구.
- [Bugsnag](https://www.bugsnag.com/platforms/ios-crash-reporting) - 무료 플랜이 있는 오류 추적 서비스. 오류 보고서에는 기기, 릴리스, 사용자 데이터가 포함되며 임의의 데이터도 첨부할 수 있습니다.
- [Countly](https://count.ly) - iOS 및 Android용 오픈 소스 모바일 및 웹 분석, 크래시 리포트, 푸시 알림 플랫폼.
- [devtodev](https://www.devtodev.com/) - 프로젝트를 개선하고 제품 개발 시간을 절약해 주는 종합 분석 서비스.
- [Embrace](http://embrace.io) - OpenTelemetry 기반의 모바일 관측성(observability) 도구로, 사용자 중심의 안정적인 앱을 제공할 수 있게 해 줍니다.
- [Emerge Tools](https://www.emergetools.com) - 모든 풀 리퀘스트에서 앱 크기와 성능 저하를 방지하고, 개선 방법에 대한 자동화된 인사이트를 얻을 수 있습니다.
- [Instabug](https://instabug.com) - 인앱 피드백, 버그 및 크래시 리포팅. 사용자 단계, 비디오 녹화, 화면 주석, 네트워크 요청 로깅을 통해 버그를 더 빠르게 수정하세요.
- [Matomo](https://github.com/matomo-org/matomo-sdk-ios) - MatomoTracker는 앱 분석 데이터를 Matomo 서버로 전송하기 위한 iOS, tvOS, macOS용 SDK입니다.
- [Measure](https://measure.sh/) - 오류 추적, 성능 트레이싱, 전체 세션 타임라인을 제공하는 오픈 소스 자체 호스팅 가능 모바일 앱 모니터링 도구로, 맥락을 짜 맞추는 데 드는 시간을 줄이고 문제를 더 빠르게 해결할 수 있습니다.
- [Mixpanel](https://mixpanel.com/) - 고급 분석 플랫폼.
- [MOCA Analytics](https://www.mocaplatform.com/features) - 유료 크로스 플랫폼 분석 백엔드.
- [Segment](https://github.com/segmentio/analytics-ios) - 어떤 iOS 애플리케이션에든 번거로움 없이 분석 기능을 통합하는 방법.
- [Sentry](https://sentry.io/) - Sentry는 모든 소프트웨어 팀이 오류를 실시간으로 발견하고, 분류하고, 우선순위를 정할 수 있도록 돕는 자체 호스팅 및 클라우드 기반 오류 모니터링을 제공합니다.
- [Shake](https://www.shakebugs.com/) - 인앱 피드백 및 버그 리포팅 도구. 상세한 기기 데이터, 재현 단계, 비디오 녹화, 블랙박스 데이터, 네트워크 요청 및 커스텀 로깅으로 앱 버그를 최대 50배 더 빠르게 수정하세요.

## 앱 라우팅

  *우아한 URL 라우팅, 내비게이션 프레임워크, 딥 링크 등*

- [ApplicationCoordinator](https://github.com/AndreyPanov/ApplicationCoordinator) - Coordinator는 내비게이션 흐름을 처리하고, 다음 체인으로 전환한 뒤 흐름 처리를 다음 코디네이터와 공유하는 객체입니다.
- [Appz](https://github.com/SwiftKitz/Appz) - 외부 애플리케이션을 손쉽게 실행하고 딥 링크로 연결하며, 설치되어 있지 않으면 웹으로 대체합니다.
- [Composable Navigator](https://github.com/Bahn-X/swift-composable-navigator) - 구성(composition), 테스트, 사용 편의성을 염두에 두고 딥 링크를 지원하는 SwiftUI 애플리케이션을 만들기 위한 오픈 소스 라이브러리
- [Crossroad](https://github.com/giginet/Crossroad) - Crossroad는 커스텀 URL 스킴 처리에 중점을 둔 URL 라우터입니다. 이를 사용하면 여러 URL 스킴을 라우팅하고 인자와 매개변수를 쉽게 가져올 수 있습니다.
- [DeepLinkKit](https://github.com/button/DeepLinkKit) - 딥 링크를 처리하는 훌륭한 라우트 매칭 기반의 블록 기반 방식.
- [JLRoutes](https://github.com/joeldev/JLRoutes) - 간단한 블록 기반 API를 갖춘 iOS용 URL 라우팅 라이브러리.
- [Linker](https://github.com/MaksimKurpa/Linker) - iOS에서 내부 및 외부 딥 링크를 처리하는 가벼운 방법.
- [Marshroute](https://github.com/avito-tech/Marshroute) - Marshroute는 라우터를 단순하면서도 매우 강력하게 만들어 주는 iOS 라이브러리입니다.
- [RouteComposer](https://github.com/ekazaev/route-composer) - 뷰 컨트롤러 구성, 라우팅, 딥 링크 작업 처리를 돕는 라이브러리.
- [RxFlow](https://github.com/RxSwiftCommunity/RxFlow) - Reactive Flow Coordinator 패턴 기반의 iOS 애플리케이션용 내비게이션 프레임워크.
- [SwiftCurrent](https://github.com/wwt/SwiftCurrent) - 복잡한 워크플로를 관리하기 위한 라이브러리.
- [SwiftRouter](https://github.com/skyline75489/SwiftRouter) - iOS용 URL 라우터.
- [URLNavigator](https://github.com/devxoul/URLNavigator) - Swift를 위한 우아한 URL 라우팅
- [WAAppRouting](https://github.com/Wasappli/WAAppRouting) - 제대로 만든 iOS 라우팅. URL 인식과 파싱된 매개변수를 이용한 컨트롤러 표시를 모두 처리합니다. 모두 한 줄로 처리되며, 컨트롤러 스택은 자동으로 유지됩니다!

## 아키텍처 패턴

*클린 아키텍처, Viper, MVVM, 리액티브... 원하는 무기를 고르세요.*

- [Clean Architecture for SwiftUI + Combine](https://github.com/nalexn/clean-architecture-swiftui) - 클린 아키텍처를 적용한 SwiftUI 앱의 프로덕션 구성을 보여 주는 데모 프로젝트.
- [CleanArchitectureRxSwift](https://github.com/sergdort/CleanArchitectureRxSwift) - RxSwift를 사용한 iOS 앱의 클린 아키텍처 예제.
- [ios-architecture](https://github.com/tailec/ios-architecture) - iOS 아키텍처 모음 - MVC, MVVM, MVVM+RxSwift, VIPER, RIBs 등 다수.
- [iOS-Viper-Architecture](https://github.com/MindorksOpenSource/iOS-Viper-Architecture) - Alamofire, AlamofireImage, PKHUD, CoreData 등의 라이브러리와 프레임워크를 사용해 iOS에서 VIPER 아키텍처를 구현한 상세한 샘플 앱이 담긴 저장소입니다.
- [Reactant](https://github.com/Brightify/Reactant) - Reactant는 iOS를 위한 리액티브 아키텍처입니다.
- [Spin](https://github.com/Spinners/Spin.Swift) - RxSwift, ReactiveSwift, Combine을 위한 피드백 루프 시스템의 범용 구현
- [SwiftyVIPER](https://github.com/codytwinton/SwiftyVIPER) - VIPER 아키텍처를 훨씬 쉽고 깔끔하게 구현할 수 있게 해 줍니다.
- [The Composable Architecture](https://github.com/pointfreeco/swift-composable-architecture) - The Composable Architecture는 구성, 테스트, 사용 편의성을 염두에 두고 일관되고 이해하기 쉬운 방식으로 애플리케이션을 만들기 위한 라이브러리입니다.
- [Viperit](https://github.com/ferranabello/Viperit) - iOS용 Viper 프레임워크. VIPER 아키텍처를 따르는 앱을 쉽게 개발하세요. Swift로 작성되고 테스트되었습니다.
