# Awesome Production Machine Learning

Este repositorio reúne una lista seleccionada de excelentes bibliotecas de código abierto que te ayudarán a desplegar, supervisar, versionar, escalar y proteger el aprendizaje automático en producción 🚀

Puedes mantenerte al día siguiendo este repositorio de GitHub y recibir cada mes un resumen de las nuevas bibliotecas de ML para producción añadidas [mediante las versiones](https://github.com/EthicalML/awesome-production-machine-learning/releases) 🤩

Además, ofrecemos un [kit de búsqueda](https://huggingface.co/spaces/zhiminy/Awesome-Production-Machine-Learning-Search) que te ayuda a recorrer rápidamente la cadena de herramientas.

# Contenido principal

## AutoML
* [AIDE](https://github.com/WecoAI/aideml) ![](https://img.shields.io/github/stars/WecoAI/aideml.svg?cacheSeconds=172800) - AIDE es un agente de ingeniería de ML de código abierto que utiliza un algoritmo de búsqueda en árbol para explorar, implementar y evaluar de forma autónoma estrategias de solución para tareas de aprendizaje automático.
* [AutoGluon](https://github.com/autogluon/autogluon) ![](https://img.shields.io/github/stars/autogluon/autogluon.svg?cacheSeconds=172800) - Selección automatizada de características, modelos e hiperparámetros para datos tabulares, imágenes y texto, basada en bibliotecas populares de aprendizaje automático (Scikit-Learn, LightGBM, CatBoost, PyTorch, MXNet).
* [Autokeras](https://github.com/keras-team/autokeras) ![](https://img.shields.io/github/stars/keras-team/autokeras.svg?cacheSeconds=172800) - Biblioteca AutoML para Keras basada en ["Auto-Keras: Efficient Neural Architecture Search with Network Morphism"](https://arxiv.org/abs/1806.10282).
* [auto-sklearn](https://github.com/automl/auto-sklearn) ![](https://img.shields.io/github/stars/automl/auto-sklearn.svg?cacheSeconds=172800) - Marco para automatizar el ajuste de algoritmos e hiperparámetros para sklearn.
* [Ax](https://github.com/facebook/Ax) ![](https://img.shields.io/github/stars/facebook/Ax.svg?cacheSeconds=172800) - Ax es una plataforma accesible de propósito general para comprender, gestionar, desplegar y automatizar experimentos adaptativos.
* [BoTorch](https://github.com/meta-pytorch/botorch) ![](https://img.shields.io/github/stars/meta-pytorch/botorch.svg?cacheSeconds=172800) - BoTorch es una biblioteca de optimización bayesiana basada en PyTorch.
* [EvalML](https://github.com/alteryx/evalml) ![](https://img.shields.io/github/stars/alteryx/evalml.svg?cacheSeconds=172800) - EvalML es una biblioteca AutoML que crea, optimiza y evalúa canalizaciones de aprendizaje automático mediante funciones objetivo específicas del dominio.
* [Feature Engine](https://github.com/feature-engine/feature_engine) ![](https://img.shields.io/github/stars/feature-engine/feature_engine.svg?cacheSeconds=172800) - Feature-engine es una biblioteca de Python que incluye varios transformadores para crear características destinadas a modelos de aprendizaje automático.
* [Featuretools](https://github.com/alteryx/featuretools) ![](https://img.shields.io/github/stars/alteryx/featuretools.svg?cacheSeconds=172800) - Marco de código abierto para la ingeniería automatizada de características.
* [FLAML](https://github.com/microsoft/FLAML) ![](https://img.shields.io/github/stars/microsoft/FLAML.svg?cacheSeconds=172800) - FLAML es una biblioteca rápida para el aprendizaje automático automatizado y el ajuste de modelos.
* [HEBO](https://github.com/huawei-noah/hebo) ![](https://img.shields.io/github/stars/huawei-noah/hebo.svg?cacheSeconds=172800) - Conjunto de marcos de código abierto para la optimización de hiperparámetros, incluida la propuesta ganadora del [NeurIPS 2020 Black-Box Optimisation Challenge](https://bbochallenge.com/leaderboard), probados en tareas de ajuste de hiperparámetros.
* [Katib](https://github.com/kubeflow/katib) ![](https://img.shields.io/github/stars/kubeflow/katib.svg?cacheSeconds=172800) - Sistema basado en Kubernetes para el ajuste de hiperparámetros y la búsqueda de arquitecturas neuronales.
* [keras-tuner](https://github.com/keras-team/keras-tuner) ![](https://img.shields.io/github/stars/keras-team/keras-tuner.svg?cacheSeconds=172800) - Keras Tuner es un marco de optimización de hiperparámetros fácil de usar y distribuible que resuelve las dificultades de realizar búsquedas de hiperparámetros. Facilita la definición de un espacio de búsqueda y el uso de los algoritmos incluidos para encontrar los mejores valores de hiperparámetros.
* [Optuna](https://github.com/optuna/optuna) ![](https://img.shields.io/github/stars/optuna/optuna.svg?cacheSeconds=172800) - Optuna es un marco de software para la optimización automática de hiperparámetros, diseñado especialmente para el aprendizaje automático.
* [OSS Vizier](https://github.com/google/vizier) ![](https://img.shields.io/github/stars/google/vizier.svg?cacheSeconds=172800) - OSS Vizier es un servicio basado en Python para la optimización de caja negra y la investigación; fue uno de los primeros servicios de ajuste de hiperparámetros diseñados para funcionar a gran escala.
* [Perpetual](https://github.com/perpetual-ml/perpetual) ![](https://img.shields.io/github/stars/perpetual-ml/perpetual.svg?cacheSeconds=172800) - Método de gradient boosting que no requiere optimizar hiperparámetros; un sencillo parámetro de presupuesto controla la complejidad del modelo.
* [TPOT](https://github.com/epistasislab/tpot) ![](https://img.shields.io/github/stars/epistasislab/tpot.svg?cacheSeconds=172800) - Automatiza la creación de canalizaciones de sklearn (incluida la selección de características, el preprocesamiento, etc.).
* [tsfresh](https://github.com/blue-yonder/tsfresh) ![](https://img.shields.io/github/stars/blue-yonder/tsfresh.svg?cacheSeconds=172800) - Extracción automática de características relevantes de series temporales.

## Optimización del cálculo y la comunicación

* [Accelerate](https://github.com/huggingface/accelerate) ![](https://img.shields.io/github/stars/huggingface/accelerate.svg?cacheSeconds=172800) - Accelerate abstrae exactamente el código repetitivo relacionado con varias GPU/TPU y la precisión mixta, y deja intacto el resto del código.
* [Adapters](https://github.com/adapter-hub/adapters) ![](https://img.shields.io/github/stars/adapter-hub/adapters.svg?cacheSeconds=172800) - Adapters es una biblioteca unificada para el aprendizaje por transferencia modular y eficiente en parámetros.
* [Cache-DiT](https://github.com/vipshop/cache-dit) ![](https://img.shields.io/github/stars/vipshop/cache-dit.svg?cacheSeconds=172800) - Cache-DiT se basa en Diffusers y admite casi todos los DiT; ofrece aceleración híbrida mediante caché (DBCache, TaylorSeer, SCM, etc.) y optimizaciones integrales del paralelismo, incluido el paralelismo de contexto, de tensores y el paralelismo híbrido 2D/3D, además de ser compatible con compilación, descarga a CPU y cuantización.
* [Colossal-AI](https://github.com/hpcaitech/ColossalAI) ![](https://img.shields.io/github/stars/hpcaitech/ColossalAI.svg?cacheSeconds=172800) - Sistema unificado de aprendizaje profundo para la era de los modelos grandes, que ayuda a desplegar de forma rápida y eficiente el entrenamiento y la inferencia de modelos de IA de gran tamaño.
* [Composer](https://github.com/mosaicml/composer) ![](https://img.shields.io/github/stars/mosaicml/composer.svg?cacheSeconds=172800) - Composer es una biblioteca de PyTorch que permite entrenar redes neuronales más rápido, a menor coste y con mayor precisión.
* [CuDF](https://github.com/NVIDIA/cudf) ![](https://img.shields.io/github/stars/NVIDIA/cudf.svg?cacheSeconds=172800) - Basada en el formato de memoria columnar Apache Arrow, cuDF es una biblioteca de GPU para cargar, combinar, agregar, filtrar y manipular datos de DataFrame.
* [CuML](https://github.com/NVIDIA/cuml) ![](https://img.shields.io/github/stars/NVIDIA/cuml.svg?cacheSeconds=172800) - cuML es un conjunto de bibliotecas que implementan algoritmos de aprendizaje automático y funciones primitivas matemáticas con API compatibles con otros proyectos RAPIDS.
* [CuPy](https://github.com/cupy/cupy) ![](https://img.shields.io/github/stars/cupy/cupy.svg?cacheSeconds=172800) - Implementación de matrices multidimensionales compatible con NumPy sobre CUDA. CuPy incluye la clase central de matrices multidimensionales cupy.ndarray y numerosas funciones para trabajar con ellas.
* [DEAP](https://github.com/DEAP/deap) ![](https://img.shields.io/github/stars/DEAP/deap.svg?cacheSeconds=172800) - Innovador marco de computación evolutiva para crear prototipos y probar ideas rápidamente. Busca hacer explícitos los algoritmos y transparentes las estructuras de datos. Funciona a la perfección con mecanismos de paralelización como multiprocessing y SCOOP.
* [DeepEP](https://github.com/deepseek-ai/DeepEP) ![](https://img.shields.io/github/stars/deepseek-ai/DeepEP.svg?cacheSeconds=172800) - DeepEP es una biblioteca de comunicación especializada en Mixture-of-Experts (MoE) y paralelismo de expertos (EP). Ofrece kernels GPU all-to-all de alto rendimiento y baja latencia, también conocidos como despacho y combinación MoE. La biblioteca también admite operaciones de baja precisión, incluido FP8.
* [DGL](https://github.com/dmlc/dgl) ![](https://img.shields.io/github/stars/dmlc/dgl.svg?cacheSeconds=172800) - DGL es un paquete de Python fácil de usar, de alto rendimiento y escalable para el aprendizaje profundo sobre grafos.
* [DLRover](https://github.com/intelligent-machine-learning/dlrover) ![](https://img.shields.io/github/stars/intelligent-machine-learning/dlrover.svg?cacheSeconds=172800) - DLRover facilita que el entrenamiento distribuido de grandes modelos de IA sea sencillo, estable, rápido y sostenible.
* [Dask](https://github.com/dask/dask) ![](https://img.shields.io/github/stars/dask/dask.svg?cacheSeconds=172800) - Marco de procesamiento paralelo distribuido para cálculos de Pandas y NumPy.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) ![](https://img.shields.io/github/stars/deepspeedai/DeepSpeed.svg?cacheSeconds=172800) - DeepSpeed es una biblioteca de optimización del aprendizaje profundo que facilita el entrenamiento y la inferencia distribuidos, y los hace eficientes y eficaces.
* [FlagGems](https://github.com/flagos-ai/FlagGems) ![](https://img.shields.io/github/stars/flagos-ai/FlagGems.svg?cacheSeconds=172800) - FlagGems es una biblioteca de operadores de alto rendimiento implementada en OpenAI Triton. Se basa en una colección de kernels independientes del backend, concebidos para acelerar el entrenamiento y la inferencia de LLM en distintas plataformas de hardware.
* [Flashlight](https://github.com/flashlight/flashlight) ![](https://img.shields.io/github/stars/flashlight/flashlight.svg?cacheSeconds=172800) - Biblioteca de aprendizaje automático rápida y flexible, escrita íntegramente en C++ por Facebook AI Research y los creadores de Torch, TensorFlow, Eigen y Deep Speech.
* [Flax](https://github.com/google/flax) ![](https://img.shields.io/github/stars/google/flax.svg?cacheSeconds=172800) - Biblioteca y ecosistema de redes neuronales para JAX, diseñados para ofrecer flexibilidad.
* [GPUStack](https://github.com/gpustack/gpustack) ![](https://img.shields.io/github/stars/gpustack/gpustack.svg?cacheSeconds=172800) - GPUStack es un gestor de clústeres GPU de código abierto para ejecutar modelos de IA.
* [Hivemind](https://github.com/learning-at-home/hivemind) ![](https://img.shields.io/github/stars/learning-at-home/hivemind.svg?cacheSeconds=172800) - Aprendizaje profundo descentralizado en PyTorch.
* [Jax](https://github.com/jax-ml/jax) ![](https://img.shields.io/github/stars/jax-ml/jax.svg?cacheSeconds=172800) - Transformaciones componibles de programas Python+NumPy: diferenciación, vectorización, compilación JIT para GPU/TPU y mucho más.
* [Kompute](https://github.com/KomputeProject/kompute) ![](https://img.shields.io/github/stars/KomputeProject/kompute.svg?cacheSeconds=172800) - Marco de cálculo Vulkan ultrarrápido, ligero y compatible con teléfonos móviles, optimizado para casos de uso avanzados de procesamiento de datos en GPU.
* [Liger Kernel](https://github.com/linkedin/Liger-Kernel) ![](https://img.shields.io/github/stars/linkedin/Liger-Kernel.svg?cacheSeconds=172800) - Liger Kernel es una colección de kernels Triton diseñados específicamente para entrenar LLM.
* [LightGBM](https://github.com/lightgbm-org/LightGBM) ![](https://img.shields.io/github/stars/lightgbm-org/LightGBM.svg?cacheSeconds=172800) - LightGBM es un marco de gradient boosting que utiliza algoritmos de aprendizaje basados en árboles.
* [MLX](https://github.com/ml-explore/mlx) ![](https://img.shields.io/github/stars/ml-explore/mlx.svg?cacheSeconds=172800) - MLX es un marco de matrices para el aprendizaje automático en Apple silicon.
* [Modin](https://github.com/modin-project/modin) ![](https://img.shields.io/github/stars/modin-project/modin.svg?cacheSeconds=172800) - Acelera tus flujos de trabajo de Pandas cambiando una sola línea de código.
* [NVIDIA TensorRT](https://github.com/NVIDIA/TensorRT) ![](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?cacheSeconds=172800) - TensorRT es una biblioteca C++ para inferencias de alto rendimiento en GPU NVIDIA y aceleradores de aprendizaje profundo.
* [Nevergrad](https://github.com/facebookresearch/nevergrad) ![](https://img.shields.io/github/stars/facebookresearch/nevergrad.svg?cacheSeconds=172800) - Nevergrad es una plataforma de optimización sin gradientes.
* [Norse](https://github.com/norse/norse) ![](https://img.shields.io/github/stars/norse/norse.svg?cacheSeconds=172800) - Norse busca aprovechar las ventajas de los componentes neuronales inspirados en la biología, que son dispersos y se activan por eventos: una diferencia fundamental frente a las redes neuronales artificiales.
* [Numba](https://github.com/numba/numba) ![](https://img.shields.io/github/stars/numba/numba.svg?cacheSeconds=172800)  - Compilador para funciones numéricas y de matrices de Python.
* [Optimum](https://github.com/huggingface/optimum) ![](https://img.shields.io/github/stars/huggingface/optimum.svg?cacheSeconds=172800) - Optimum amplía Transformers y Diffusers con un conjunto de herramientas de optimización que permite entrenar y ejecutar modelos de forma muy eficiente en el hardware elegido, sin renunciar a la facilidad de uso.
* [PEFT](https://github.com/huggingface/peft) ![](https://img.shields.io/github/stars/huggingface/peft.svg?cacheSeconds=172800) - Los métodos de ajuste fino eficiente en parámetros (PEFT) permiten adaptar eficazmente modelos de lenguaje preentrenados (PLM) a diversas aplicaciones posteriores sin ajustar todos los parámetros del modelo.
* [PaddlePaddle](https://github.com/PaddlePaddle/Paddle) ![](https://img.shields.io/github/stars/PaddlePaddle/Paddle.svg?cacheSeconds=172800) - PaddlePaddle es un marco para entrenar redes profundas a gran escala con fuentes de datos distribuidas entre cientos de nodos.
* [PyG](https://github.com/pyg-team/pytorch_geometric) ![](https://img.shields.io/github/stars/pyg-team/pytorch_geometric.svg?cacheSeconds=172800) - PyG (PyTorch Geometric) es una biblioteca basada en PyTorch que facilita la creación y el entrenamiento de redes neuronales de grafos (GNN) para una amplia variedad de aplicaciones con datos estructurados.
* [PyTorch Lightning](https://github.com/Lightning-AI/pytorch-lightning) ![](https://img.shields.io/github/stars/Lightning-AI/pytorch-lightning.svg?cacheSeconds=172800) - PyTorch Lightning preentrena, ajusta y despliega modelos de IA en varias GPU y TPU sin cambiar el código.
* [PyTorch](https://github.com/pytorch/pytorch) ![](https://img.shields.io/github/stars/pytorch/pytorch.svg?cacheSeconds=172800) - PyTorch es una biblioteca para desarrollar y entrenar modelos de aprendizaje profundo basados en redes neuronales.
* [Ray](https://github.com/ray-project/ray) ![](https://img.shields.io/github/stars/ray-project/ray.svg?cacheSeconds=172800) - Ray es un marco flexible y de alto rendimiento para la ejecución distribuida de cargas de trabajo de aprendizaje automático.
* [SetFit](https://github.com/huggingface/setfit) ![](https://img.shields.io/github/stars/huggingface/setfit.svg?cacheSeconds=172800) - SetFit es un marco eficiente, que no requiere prompts, para el ajuste fino de pocos ejemplos de Sentence Transformers.
* [Sonnet](https://github.com/google-deepmind/sonnet) ![](https://img.shields.io/github/stars/google-deepmind/sonnet.svg?cacheSeconds=172800) - Sonnet es una biblioteca basada en TensorFlow 2 que ofrece abstracciones sencillas y componibles para la investigación en aprendizaje automático.
* [Streaming](https://github.com/mosaicml/streaming) ![](https://img.shields.io/github/stars/mosaicml/streaming.svg?cacheSeconds=172800) - Biblioteca de flujos de datos para entrenar redes neuronales de forma eficiente.
* [TensorFlow](https://github.com/tensorflow/tensorflow) ![](https://img.shields.io/github/stars/tensorflow/tensorflow.svg?cacheSeconds=172800) - TensorFlow es una biblioteca líder diseñada para desarrollar y desplegar aplicaciones de aprendizaje automático de última generación.
* [ThunderKittens](https://github.com/HazyResearch/ThunderKittens) ![](https://img.shields.io/github/stars/HazyResearch/ThunderKittens.svg?cacheSeconds=172800) ThunderKittens es un marco que facilita la escritura de kernels rápidos de aprendizaje profundo en CUDA.
* [TorchOpt](https://github.com/metaopt/torchopt) ![](https://img.shields.io/github/stars/metaopt/torchopt.svg?cacheSeconds=172800) - TorchOpt es una biblioteca eficiente para la optimización diferenciable basada en PyTorch.
* [Triton](https://github.com/triton-lang/triton) ![](https://img.shields.io/github/stars/triton-lang/triton.svg?cacheSeconds=172800) - Triton es un lenguaje y compilador para escribir primitivas personalizadas de aprendizaje profundo muy eficientes. Su objetivo es ofrecer un entorno de código abierto para crear código rápido con mayor productividad que CUDA y más flexibilidad que otros DSL existentes.
* [Vaex](https://github.com/vaexio/vaex) ![](https://img.shields.io/github/stars/vaexio/vaex.svg?cacheSeconds=172800) Vaex es una biblioteca Python de alto rendimiento para DataFrames diferidos y externos a memoria (similares a Pandas), destinada a visualizar y explorar grandes conjuntos de datos tabulares. Utiliza asignación de memoria, una política de copia cero y cálculos diferidos para ofrecer el máximo rendimiento sin desperdiciar memoria.
