# Awesome Production Machine Learning

Dieses Repository enthält eine kuratierte Liste hervorragender Open-Source-Bibliotheken, mit denen du maschinelles Lernen in der Produktion bereitstellen, überwachen, versionieren, skalieren und absichern kannst 🚀

Du bleibst auf dem Laufenden, wenn du dieses GitHub-Repository beobachtest: Über [Releases](https://github.com/EthicalML/awesome-production-machine-learning/releases) erhältst du jeden Monat eine Zusammenfassung der neu hinzugefügten Produktions-ML-Bibliotheken 🤩

Zusätzlich bieten wir ein [Such-Toolkit](https://huggingface.co/spaces/zhiminy/Awesome-Production-Machine-Learning-Search), mit dem du dich schnell durch die Toolchain navigieren kannst.

# Hauptinhalt

## AutoML
* [AIDE](https://github.com/WecoAI/aideml) ![](https://img.shields.io/github/stars/WecoAI/aideml.svg?cacheSeconds=172800) - AIDE ist ein Open-Source-Agent für ML-Engineering, der einen Baumsuchalgorithmus verwendet, um Lösungsstrategien für Aufgaben des maschinellen Lernens autonom zu erkunden, umzusetzen und zu bewerten.
* [AutoGluon](https://github.com/autogluon/autogluon) ![](https://img.shields.io/github/stars/autogluon/autogluon.svg?cacheSeconds=172800) - Automatisierte Auswahl von Merkmalen, Modellen und Hyperparametern für Tabellen-, Bild- und Textdaten auf Basis beliebter Bibliotheken für maschinelles Lernen (Scikit-Learn, LightGBM, CatBoost, PyTorch, MXNet).
* [Autokeras](https://github.com/keras-team/autokeras) ![](https://img.shields.io/github/stars/keras-team/autokeras.svg?cacheSeconds=172800) - AutoML-Bibliothek für Keras auf Grundlage von ["Auto-Keras: Efficient Neural Architecture Search with Network Morphism"](https://arxiv.org/abs/1806.10282).
* [auto-sklearn](https://github.com/automl/auto-sklearn) ![](https://img.shields.io/github/stars/automl/auto-sklearn.svg?cacheSeconds=172800) - Framework zur Automatisierung der Algorithmus- und Hyperparameteroptimierung für sklearn.
* [Ax](https://github.com/facebook/Ax) ![](https://img.shields.io/github/stars/facebook/Ax.svg?cacheSeconds=172800) - Ax ist eine zugängliche, universell einsetzbare Plattform zum Verstehen, Verwalten, Bereitstellen und Automatisieren adaptiver Experimente.
* [BoTorch](https://github.com/meta-pytorch/botorch) ![](https://img.shields.io/github/stars/meta-pytorch/botorch.svg?cacheSeconds=172800) - BoTorch ist eine auf PyTorch aufbauende Bibliothek für Bayes’sche Optimierung.
* [EvalML](https://github.com/alteryx/evalml) ![](https://img.shields.io/github/stars/alteryx/evalml.svg?cacheSeconds=172800) - EvalML ist eine AutoML-Bibliothek, die ML-Pipelines mithilfe domänenspezifischer Zielfunktionen erstellt, optimiert und bewertet.
* [Feature Engine](https://github.com/feature-engine/feature_engine) ![](https://img.shields.io/github/stars/feature-engine/feature_engine.svg?cacheSeconds=172800) - Feature-engine ist eine Python-Bibliothek mit verschiedenen Transformatoren zur Merkmalsentwicklung für den Einsatz in Modellen des maschinellen Lernens.
* [Featuretools](https://github.com/alteryx/featuretools) ![](https://img.shields.io/github/stars/alteryx/featuretools.svg?cacheSeconds=172800) - Ein Open-Source-Framework für die automatisierte Merkmalsentwicklung.
* [FLAML](https://github.com/microsoft/FLAML) ![](https://img.shields.io/github/stars/microsoft/FLAML.svg?cacheSeconds=172800) - FLAML ist eine schnelle Bibliothek für automatisiertes maschinelles Lernen und Tuning.
* [HEBO](https://github.com/huawei-noah/hebo) ![](https://img.shields.io/github/stars/huawei-noah/hebo.svg?cacheSeconds=172800) - Sammlung von Open-Source-Frameworks zur Hyperparameteroptimierung, darunter der Siegerbeitrag zur [NeurIPS 2020 Black-Box Optimisation Challenge](https://bbochallenge.com/leaderboard), getestet mit Aufgaben zur Hyperparameteroptimierung.
* [Katib](https://github.com/kubeflow/katib) ![](https://img.shields.io/github/stars/kubeflow/katib.svg?cacheSeconds=172800) - Ein Kubernetes-basiertes System für Hyperparameteroptimierung und die Suche nach neuronalen Architekturen.
* [keras-tuner](https://github.com/keras-team/keras-tuner) ![](https://img.shields.io/github/stars/keras-team/keras-tuner.svg?cacheSeconds=172800) - Keras Tuner ist ein einfach zu verwendendes, verteilbares Framework zur Hyperparameteroptimierung, das die Schwierigkeiten bei der Hyperparametersuche behebt. Mit Keras Tuner lassen sich Suchräume leicht definieren und die enthaltenen Algorithmen nutzen, um die besten Hyperparameterwerte zu finden.
* [Optuna](https://github.com/optuna/optuna) ![](https://img.shields.io/github/stars/optuna/optuna.svg?cacheSeconds=172800) - Optuna ist ein Framework für automatische Hyperparameteroptimierung, das speziell für maschinelles Lernen entwickelt wurde.
* [OSS Vizier](https://github.com/google/vizier) ![](https://img.shields.io/github/stars/google/vizier.svg?cacheSeconds=172800) - OSS Vizier ist ein Python-basierter Dienst für Black-Box-Optimierung und Forschung und war einer der ersten Hyperparameter-Tuning-Dienste, die für den Einsatz in großem Maßstab konzipiert wurden.
* [Perpetual](https://github.com/perpetual-ml/perpetual) ![](https://img.shields.io/github/stars/perpetual-ml/perpetual.svg?cacheSeconds=172800) - Ein Gradient-Boosting-Verfahren, das keine Hyperparameteroptimierung benötigt; ein einfacher Budgetparameter steuert die Modellkomplexität.
* [TPOT](https://github.com/epistasislab/tpot) ![](https://img.shields.io/github/stars/epistasislab/tpot.svg?cacheSeconds=172800) - Automatisiert die Erstellung von sklearn-Pipelines (einschließlich Merkmalsauswahl, Vorverarbeitung usw.).
* [tsfresh](https://github.com/blue-yonder/tsfresh) ![](https://img.shields.io/github/stars/blue-yonder/tsfresh.svg?cacheSeconds=172800) - Automatische Extraktion relevanter Merkmale aus Zeitreihen.

## Computation and Communication Optimisation

* [Accelerate](https://github.com/huggingface/accelerate) ![](https://img.shields.io/github/stars/huggingface/accelerate.svg?cacheSeconds=172800) - Accelerate abstrahiert genau und ausschließlich den Boilerplate-Code für Multi-GPU-/TPU-Betrieb und gemischte Genauigkeit; der übrige Code bleibt unverändert.
* [Adapters](https://github.com/adapter-hub/adapters) ![](https://img.shields.io/github/stars/adapter-hub/adapters.svg?cacheSeconds=172800) - Adapters ist eine einheitliche Bibliothek für modulare, parametereffiziente Transfer-Learning-Verfahren.
* [Cache-DiT](https://github.com/vipshop/cache-dit) ![](https://img.shields.io/github/stars/vipshop/cache-dit.svg?cacheSeconds=172800) - Cache-DiT baut auf Diffusers auf und unterstützt nahezu alle DiTs. Die Bibliothek bietet hybride Cache-Beschleunigung (DBCache, TaylorSeer, SCM usw.) sowie umfassende Parallelisierungsoptimierungen, darunter Context Parallelism, Tensor Parallelism und hybride 2D-/3D-Parallelisierung, und ist mit Kompilierung, CPU-Offloading und Quantisierung kompatibel.
* [Colossal-AI](https://github.com/hpcaitech/ColossalAI) ![](https://img.shields.io/github/stars/hpcaitech/ColossalAI.svg?cacheSeconds=172800) - Ein einheitliches Deep-Learning-System für das Zeitalter großer Modelle, mit dem sich das Training und die Inferenz großer KI-Modelle effizient und schnell bereitstellen lassen.
* [Composer](https://github.com/mosaicml/composer) ![](https://img.shields.io/github/stars/mosaicml/composer.svg?cacheSeconds=172800) - Composer ist eine PyTorch-Bibliothek, mit der sich neuronale Netze schneller, kostengünstiger und mit höherer Genauigkeit trainieren lassen.
* [CuDF](https://github.com/NVIDIA/cudf) ![](https://img.shields.io/github/stars/NVIDIA/cudf.svg?cacheSeconds=172800) - cuDF basiert auf dem spaltenorientierten Apache-Arrow-Speicherformat und ist eine GPU-DataFrame-Bibliothek zum Laden, Verbinden, Aggregieren, Filtern und anderweitigen Bearbeiten von Daten.
* [CuML](https://github.com/NVIDIA/cuml) ![](https://img.shields.io/github/stars/NVIDIA/cuml.svg?cacheSeconds=172800) - cuML ist eine Sammlung von Bibliotheken, die Algorithmen des maschinellen Lernens und mathematische Primitive mit APIs implementiert, die mit anderen RAPIDS-Projekten kompatibel sind.
* [CuPy](https://github.com/cupy/cupy) ![](https://img.shields.io/github/stars/cupy/cupy.svg?cacheSeconds=172800) - Eine CUDA-Implementierung mehrdimensionaler Arrays, die mit NumPy kompatibel ist. CuPy umfasst die zentrale mehrdimensionale Array-Klasse cupy.ndarray sowie zahlreiche Funktionen dafür.
* [DEAP](https://github.com/DEAP/deap) ![](https://img.shields.io/github/stars/DEAP/deap.svg?cacheSeconds=172800) - Ein neuartiges Framework für evolutionäre Berechnung zur schnellen Erstellung von Prototypen und zum Testen von Ideen. Es macht Algorithmen explizit und Datenstrukturen transparent und harmoniert hervorragend mit Parallelisierungsmechanismen wie multiprocessing und SCOOP.
* [DeepEP](https://github.com/deepseek-ai/DeepEP) ![](https://img.shields.io/github/stars/deepseek-ai/DeepEP.svg?cacheSeconds=172800) - DeepEP ist eine Kommunikationsbibliothek speziell für Mixture-of-Experts (MoE) und Expert Parallelism (EP). Sie stellt GPU-Kernels für All-to-All-Kommunikation mit hohem Durchsatz und geringer Latenz bereit, auch bekannt als MoE Dispatch und Combine. Außerdem unterstützt die Bibliothek Operationen mit geringer Genauigkeit, darunter FP8.
* [DGL](https://github.com/dmlc/dgl) ![](https://img.shields.io/github/stars/dmlc/dgl.svg?cacheSeconds=172800) - DGL ist ein benutzerfreundliches, leistungsstarkes und skalierbares Python-Paket für Deep Learning auf Graphen.
* [DLRover](https://github.com/intelligent-machine-learning/dlrover) ![](https://img.shields.io/github/stars/intelligent-machine-learning/dlrover.svg?cacheSeconds=172800) - DLRover macht verteiltes Training großer KI-Modelle einfach, stabil, schnell und ressourcenschonend.
* [Dask](https://github.com/dask/dask) ![](https://img.shields.io/github/stars/dask/dask.svg?cacheSeconds=172800) - Framework für verteilte parallele Verarbeitung von Pandas- und NumPy-Berechnungen.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) ![](https://img.shields.io/github/stars/deepspeedai/DeepSpeed.svg?cacheSeconds=172800) - DeepSpeed ist eine Optimierungsbibliothek für Deep Learning, die verteiltes Training und Inferenz einfach, effizient und effektiv macht.
* [FlagGems](https://github.com/flagos-ai/FlagGems) ![](https://img.shields.io/github/stars/flagos-ai/FlagGems.svg?cacheSeconds=172800) - FlagGems ist eine leistungsstarke, universell einsetzbare Operatorbibliothek, implementiert mit OpenAI Triton. Sie baut auf einer Sammlung backendneutraler Kernels auf, die das Training und die Inferenz von LLMs auf unterschiedlichen Hardwareplattformen beschleunigen sollen.
* [Flashlight](https://github.com/flashlight/flashlight) ![](https://img.shields.io/github/stars/flashlight/flashlight.svg?cacheSeconds=172800) - Eine schnelle, flexible ML-Bibliothek, vollständig in C++ geschrieben, von Facebook AI Research und den Entwicklern von Torch, TensorFlow, Eigen und Deep Speech.
* [Flax](https://github.com/google/flax) ![](https://img.shields.io/github/stars/google/flax.svg?cacheSeconds=172800) - Eine auf Flexibilität ausgelegte Bibliothek für neuronale Netze samt Ökosystem für JAX.
* [GPUStack](https://github.com/gpustack/gpustack) ![](https://img.shields.io/github/stars/gpustack/gpustack.svg?cacheSeconds=172800) - GPUStack ist ein Open-Source-Manager für GPU-Cluster zum Ausführen von KI-Modellen.
* [Hivemind](https://github.com/learning-at-home/hivemind) ![](https://img.shields.io/github/stars/learning-at-home/hivemind.svg?cacheSeconds=172800) - Dezentrales Deep Learning mit PyTorch.
* [Jax](https://github.com/jax-ml/jax) ![](https://img.shields.io/github/stars/jax-ml/jax.svg?cacheSeconds=172800) - Kombinierbare Transformationen von Python- und NumPy-Programmen: differenzieren, vektorisieren, per JIT für GPU/TPU kompilieren und mehr.
* [Kompute](https://github.com/KomputeProject/kompute) ![](https://img.shields.io/github/stars/KomputeProject/kompute.svg?cacheSeconds=172800) - Ein blitzschnelles, leichtgewichtiges und mobilgerätetaugliches Vulkan-Compute-Framework, optimiert für fortgeschrittene GPU-Datenverarbeitung.
* [Liger Kernel](https://github.com/linkedin/Liger-Kernel) ![](https://img.shields.io/github/stars/linkedin/Liger-Kernel.svg?cacheSeconds=172800) - Liger Kernel ist eine Sammlung von Triton-Kernels, die speziell für das Training von LLMs entwickelt wurden.
* [LightGBM](https://github.com/lightgbm-org/LightGBM) ![](https://img.shields.io/github/stars/lightgbm-org/LightGBM.svg?cacheSeconds=172800) - LightGBM ist ein Gradient-Boosting-Framework, das baumbasierte Lernalgorithmen verwendet.
* [MLX](https://github.com/ml-explore/mlx) ![](https://img.shields.io/github/stars/ml-explore/mlx.svg?cacheSeconds=172800) - MLX ist ein Array-Framework für maschinelles Lernen auf Apple-Silicon.
* [Modin](https://github.com/modin-project/modin) ![](https://img.shields.io/github/stars/modin-project/modin.svg?cacheSeconds=172800) - Beschleunige deine Pandas-Workflows mit nur einer Codezeile.
* [NVIDIA TensorRT](https://github.com/NVIDIA/TensorRT) ![](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?cacheSeconds=172800) - TensorRT ist eine C++-Bibliothek für leistungsstarke Inferenz auf NVIDIA-GPUs und Deep-Learning-Beschleunigern.
* [Nevergrad](https://github.com/facebookresearch/nevergrad) ![](https://img.shields.io/github/stars/facebookresearch/nevergrad.svg?cacheSeconds=172800) - Nevergrad ist eine Plattform für gradientenfreie Optimierung.
* [Norse](https://github.com/norse/norse) ![](https://img.shields.io/github/stars/norse/norse.svg?cacheSeconds=172800) - Norse soll die Vorteile bioinspirierter neuronaler Komponenten nutzen, die dünn besetzt und ereignisgesteuert sind – ein grundlegender Unterschied zu künstlichen neuronalen Netzen.
* [Numba](https://github.com/numba/numba) ![](https://img.shields.io/github/stars/numba/numba.svg?cacheSeconds=172800)  - Ein Compiler für Python-Array- und numerische Funktionen.
* [Optimum](https://github.com/huggingface/optimum) ![](https://img.shields.io/github/stars/huggingface/optimum.svg?cacheSeconds=172800) - Optimum ist eine Erweiterung von Transformers und Diffusers und bietet Optimierungswerkzeuge, mit denen sich Modelle auf bestimmter Hardware möglichst effizient trainieren und ausführen lassen, ohne die einfache Bedienung aufzugeben.
* [PEFT](https://github.com/huggingface/peft) ![](https://img.shields.io/github/stars/huggingface/peft.svg?cacheSeconds=172800) - Verfahren für Parameter-Efficient Fine-Tuning (PEFT) ermöglichen die effiziente Anpassung vortrainierter Sprachmodelle (PLMs) an verschiedene nachgelagerte Anwendungen, ohne alle Modellparameter feinabzustimmen.
* [PaddlePaddle](https://github.com/PaddlePaddle/Paddle) ![](https://img.shields.io/github/stars/PaddlePaddle/Paddle.svg?cacheSeconds=172800) - PaddlePaddle ist ein Framework für das Training großer neuronaler Netze mit Datenquellen, die auf Hunderte von Knoten verteilt sind.
* [PyG](https://github.com/pyg-team/pytorch_geometric) ![](https://img.shields.io/github/stars/pyg-team/pytorch_geometric.svg?cacheSeconds=172800) - PyG (PyTorch Geometric) baut auf PyTorch auf und erleichtert das Schreiben und Trainieren neuronaler Graphennetze (GNNs) für vielfältige Anwendungen mit strukturierten Daten.
* [PyTorch Lightning](https://github.com/Lightning-AI/pytorch-lightning) ![](https://img.shields.io/github/stars/Lightning-AI/pytorch-lightning.svg?cacheSeconds=172800) - PyTorch Lightning trainiert vor und feinab, und stellt KI-Modelle auf mehreren GPUs und TPUs bereit – ohne Änderungen am Code.
* [PyTorch](https://github.com/pytorch/pytorch) ![](https://img.shields.io/github/stars/pytorch/pytorch.svg?cacheSeconds=172800) - PyTorch ist eine Bibliothek zum Entwickeln und Trainieren neuronaler Deep-Learning-Modelle.
* [Ray](https://github.com/ray-project/ray) ![](https://img.shields.io/github/stars/ray-project/ray.svg?cacheSeconds=172800) - Ray ist ein flexibles, leistungsstarkes Framework für verteilte Ausführung im maschinellen Lernen.
* [SetFit](https://github.com/huggingface/setfit) ![](https://img.shields.io/github/stars/huggingface/setfit.svg?cacheSeconds=172800) - SetFit ist ein effizientes, promptfreies Framework für Few-Shot-Fine-Tuning von Sentence Transformers.
* [Sonnet](https://github.com/google-deepmind/sonnet) ![](https://img.shields.io/github/stars/google-deepmind/sonnet.svg?cacheSeconds=172800) - Sonnet baut auf TensorFlow 2 auf und bietet einfache, kombinierbare Abstraktionen für die ML-Forschung.
* [Streaming](https://github.com/mosaicml/streaming) ![](https://img.shields.io/github/stars/mosaicml/streaming.svg?cacheSeconds=172800) - Eine Bibliothek für Datenstreaming zum effizienten Training neuronaler Netze.
* [TensorFlow](https://github.com/tensorflow/tensorflow) ![](https://img.shields.io/github/stars/tensorflow/tensorflow.svg?cacheSeconds=172800) - TensorFlow ist eine führende Bibliothek zur Entwicklung und Bereitstellung hochmoderner Anwendungen für maschinelles Lernen.
* [ThunderKittens](https://github.com/HazyResearch/ThunderKittens) ![](https://img.shields.io/github/stars/HazyResearch/ThunderKittens.svg?cacheSeconds=172800) ThunderKittens ist ein Framework, das das Schreiben schneller Deep-Learning-Kernels in CUDA erleichtert.
* [TorchOpt](https://github.com/metaopt/torchopt) ![](https://img.shields.io/github/stars/metaopt/torchopt.svg?cacheSeconds=172800) - TorchOpt ist eine effiziente Bibliothek für differenzierbare Optimierung auf Basis von PyTorch.
* [Triton](https://github.com/triton-lang/triton) ![](https://img.shields.io/github/stars/triton-lang/triton.svg?cacheSeconds=172800) - Triton ist eine Sprache und ein Compiler zum Schreiben hocheffizienter, benutzerdefinierter Deep-Learning-Primitiven. Ziel von Triton ist eine Open-Source-Umgebung, in der sich schneller Code produktiver als mit CUDA und zugleich flexibler als mit anderen vorhandenen DSLs schreiben lässt.
* [Vaex](https://github.com/vaexio/vaex) ![](https://img.shields.io/github/stars/vaexio/vaex.svg?cacheSeconds=172800) Vaex ist eine leistungsstarke Python-Bibliothek für verzögerte Out-of-Core-DataFrames (ähnlich wie Pandas), um große tabellarische Datensätze zu visualisieren und zu erkunden. Vaex nutzt Memory Mapping, kopierfreien Speicherzugriff und verzögerte Berechnungen für maximale Leistung (ohne Speicher zu verschwenden).
