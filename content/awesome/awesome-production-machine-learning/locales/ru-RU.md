# Избранное: машинное обучение в промышленной эксплуатации

В этом репозитории собран список отличных библиотек с открытым исходным кодом, которые помогут развертывать, отслеживать, версионировать, масштабировать и защищать модели машинного обучения в промышленной эксплуатации 🚀

Следите за этим репозиторием на GitHub, чтобы каждый месяц получать сводку о новых библиотеках для промышленного машинного обучения [в выпусках](https://github.com/EthicalML/awesome-production-machine-learning/releases) 🤩

Кроме того, мы подготовили [инструментарий поиска](https://huggingface.co/spaces/zhiminy/Awesome-Production-Machine-Learning-Search), который поможет быстро сориентироваться в инструментах.

# Основное содержание

## Автоматическое машинное обучение (AutoML)
* [AIDE](https://github.com/WecoAI/aideml) ![](https://img.shields.io/github/stars/WecoAI/aideml.svg?cacheSeconds=172800) - AIDE — агент для разработки ML с открытым исходным кодом, который использует алгоритм поиска по дереву для автономного изучения, реализации и оценки стратегий решения задач машинного обучения.
* [AutoGluon](https://github.com/autogluon/autogluon) ![](https://img.shields.io/github/stars/autogluon/autogluon.svg?cacheSeconds=172800) - Автоматический выбор признаков, моделей и гиперпараметров для табличных данных, изображений и текста на базе популярных библиотек машинного обучения (Scikit-Learn, LightGBM, CatBoost, PyTorch, MXNet).
* [Autokeras](https://github.com/keras-team/autokeras) ![](https://img.shields.io/github/stars/keras-team/autokeras.svg?cacheSeconds=172800) - Библиотека AutoML для Keras, основанная на работе [«Auto-Keras: эффективный поиск архитектуры нейронной сети с помощью Network Morphism»](https://arxiv.org/abs/1806.10282).
* [auto-sklearn](https://github.com/automl/auto-sklearn) ![](https://img.shields.io/github/stars/automl/auto-sklearn.svg?cacheSeconds=172800) - Фреймворк для автоматизации подбора алгоритмов и гиперпараметров в sklearn.
* [Ax](https://github.com/facebook/Ax) ![](https://img.shields.io/github/stars/facebook/Ax.svg?cacheSeconds=172800) - Ax — доступная универсальная платформа для изучения, управления, развертывания и автоматизации адаптивных экспериментов.
* [BoTorch](https://github.com/meta-pytorch/botorch) ![](https://img.shields.io/github/stars/meta-pytorch/botorch.svg?cacheSeconds=172800) - Библиотека для байесовской оптимизации на базе PyTorch.
* [EvalML](https://github.com/alteryx/evalml) ![](https://img.shields.io/github/stars/alteryx/evalml.svg?cacheSeconds=172800) - EvalML — библиотека AutoML, которая создает, оптимизирует и оценивает конвейеры машинного обучения с помощью предметно-ориентированных целевых функций.
* [Feature Engine](https://github.com/feature-engine/feature_engine) ![](https://img.shields.io/github/stars/feature-engine/feature_engine.svg?cacheSeconds=172800) - Feature-engine — библиотека Python с набором преобразователей для создания признаков, используемых в моделях машинного обучения.
* [Featuretools](https://github.com/alteryx/featuretools) ![](https://img.shields.io/github/stars/alteryx/featuretools.svg?cacheSeconds=172800) - Фреймворк с открытым исходным кодом для автоматизированного создания признаков.
* [FLAML](https://github.com/microsoft/FLAML) ![](https://img.shields.io/github/stars/microsoft/FLAML.svg?cacheSeconds=172800) - FLAML — быстрая библиотека для автоматизированного машинного обучения и настройки моделей.
* [HEBO](https://github.com/huawei-noah/hebo) ![](https://img.shields.io/github/stars/huawei-noah/hebo.svg?cacheSeconds=172800) - Набор фреймворков для оптимизации гиперпараметров с открытым исходным кодом, включая работу-победителя [соревнования NeurIPS 2020 по оптимизации «чёрного ящика»](https://bbochallenge.com/leaderboard), проверенную на задачах подбора гиперпараметров.
* [Katib](https://github.com/kubeflow/katib) ![](https://img.shields.io/github/stars/kubeflow/katib.svg?cacheSeconds=172800) - Система на базе Kubernetes для настройки гиперпараметров и поиска архитектур нейронных сетей.
* [keras-tuner](https://github.com/keras-team/keras-tuner) ![](https://img.shields.io/github/stars/keras-team/keras-tuner.svg?cacheSeconds=172800) - Keras Tuner — простой в использовании распределяемый фреймворк оптимизации гиперпараметров, решающий сложности их подбора. Он упрощает задание пространства поиска и использование встроенных алгоритмов для нахождения оптимальных значений гиперпараметров.
* [Optuna](https://github.com/optuna/optuna) ![](https://img.shields.io/github/stars/optuna/optuna.svg?cacheSeconds=172800) - Optuna — программный фреймворк для автоматической оптимизации гиперпараметров, предназначенный в первую очередь для машинного обучения.
* [OSS Vizier](https://github.com/google/vizier) ![](https://img.shields.io/github/stars/google/vizier.svg?cacheSeconds=172800) - OSS Vizier — сервис на Python для оптимизации «чёрного ящика» и исследований, один из первых сервисов настройки гиперпараметров, рассчитанных на работу в крупном масштабе.
* [Perpetual](https://github.com/perpetual-ml/perpetual) ![](https://img.shields.io/github/stars/perpetual-ml/perpetual.svg?cacheSeconds=172800) - Градиентный бустинг, которому не нужна оптимизация гиперпараметров: сложность модели регулируется простым параметром бюджета.
* [TPOT](https://github.com/epistasislab/tpot) ![](https://img.shields.io/github/stars/epistasislab/tpot.svg?cacheSeconds=172800) - Автоматизация создания конвейеров sklearn (включая отбор признаков, предварительную обработку и т. д.).
* [tsfresh](https://github.com/blue-yonder/tsfresh) ![](https://img.shields.io/github/stars/blue-yonder/tsfresh.svg?cacheSeconds=172800) - Автоматическое извлечение значимых признаков из временных рядов.

## Оптимизация вычислений и коммуникаций

* [Accelerate](https://github.com/huggingface/accelerate) ![](https://img.shields.io/github/stars/huggingface/accelerate.svg?cacheSeconds=172800) - Accelerate абстрагирует ровно тот шаблонный код, который связан с несколькими GPU/TPU и смешанной точностью, оставляя остальной код без изменений.
* [Adapters](https://github.com/adapter-hub/adapters) ![](https://img.shields.io/github/stars/adapter-hub/adapters.svg?cacheSeconds=172800) - Adapters — унифицированная библиотека для модульного трансферного обучения с эффективным использованием параметров.
* [Cache-DiT](https://github.com/vipshop/cache-dit) ![](https://img.shields.io/github/stars/vipshop/cache-dit.svg?cacheSeconds=172800) - Cache-DiT построена на базе Diffusers и поддерживает почти все DiT, обеспечивая гибридное ускорение с помощью кэша (DBCache, TaylorSeer, SCM и др.) и комплексную оптимизацию параллелизма, включая параллелизм по контексту и тензорам, а также гибридный параллелизм 2D/3D; поддерживаются компиляция, выгрузка на CPU и квантование.
* [Colossal-AI](https://github.com/hpcaitech/ColossalAI) ![](https://img.shields.io/github/stars/hpcaitech/ColossalAI.svg?cacheSeconds=172800) - Унифицированная система глубокого обучения для эпохи больших моделей, помогающая быстро и эффективно развертывать обучение и инференс крупных моделей ИИ.
* [Composer](https://github.com/mosaicml/composer) ![](https://img.shields.io/github/stars/mosaicml/composer.svg?cacheSeconds=172800) - Composer — библиотека PyTorch, позволяющая обучать нейронные сети быстрее, дешевле и с более высокой точностью.
* [CuDF](https://github.com/NVIDIA/cudf) ![](https://img.shields.io/github/stars/NVIDIA/cudf.svg?cacheSeconds=172800) - Созданная на основе колоночного формата памяти Apache Arrow библиотека DataFrame для GPU: загрузка, объединение, агрегация, фильтрация и другие операции с данными.
* [CuML](https://github.com/NVIDIA/cuml) ![](https://img.shields.io/github/stars/NVIDIA/cuml.svg?cacheSeconds=172800) - cuML — набор библиотек с алгоритмами машинного обучения и математическими примитивами, API которых совместимы с другими проектами RAPIDS.
* [CuPy](https://github.com/cupy/cupy) ![](https://img.shields.io/github/stars/cupy/cupy.svg?cacheSeconds=172800) - Реализация совместимых с NumPy многомерных массивов для CUDA. CuPy включает основной класс многомерных массивов cupy.ndarray и множество функций для работы с ним.
* [DEAP](https://github.com/DEAP/deap) ![](https://img.shields.io/github/stars/DEAP/deap.svg?cacheSeconds=172800) - Новый фреймворк эволюционных вычислений для быстрого прототипирования и проверки идей. Он делает алгоритмы явными, а структуры данных — прозрачными. Фреймворк отлично сочетается с механизмами параллелизации, такими как multiprocessing и SCOOP.
* [DeepEP](https://github.com/deepseek-ai/DeepEP) ![](https://img.shields.io/github/stars/deepseek-ai/DeepEP.svg?cacheSeconds=172800) - DeepEP — библиотека коммуникации для смесей экспертов (MoE) и параллелизма экспертов (EP). Она предоставляет высокопроизводительные GPU-ядра с низкой задержкой для операций all-to-all, также известных как диспетчеризация и объединение MoE. Поддерживаются и операции с низкой точностью, включая FP8.
* [DGL](https://github.com/dmlc/dgl) ![](https://img.shields.io/github/stars/dmlc/dgl.svg?cacheSeconds=172800) - DGL — простой в использовании, высокопроизводительный и масштабируемый пакет Python для глубокого обучения на графах.
* [DLRover](https://github.com/intelligent-machine-learning/dlrover) ![](https://img.shields.io/github/stars/intelligent-machine-learning/dlrover.svg?cacheSeconds=172800) - DLRover упрощает распределённое обучение крупных моделей ИИ, делая его стабильным, быстрым и экологичным.
* [Dask](https://github.com/dask/dask) ![](https://img.shields.io/github/stars/dask/dask.svg?cacheSeconds=172800) - Фреймворк распределённой параллельной обработки вычислений Pandas и NumPy.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) ![](https://img.shields.io/github/stars/deepspeedai/DeepSpeed.svg?cacheSeconds=172800) - DeepSpeed — библиотека оптимизации глубокого обучения, упрощающая распределённое обучение и инференс, делая их эффективными и результативными.
* [FlagGems](https://github.com/flagos-ai/FlagGems) ![](https://img.shields.io/github/stars/flagos-ai/FlagGems.svg?cacheSeconds=172800) - FlagGems — высокопроизводительная библиотека универсальных операторов, реализованная на OpenAI Triton. В её основе — независимые от бэкенда ядра для ускорения обучения и инференса LLM на разных аппаратных платформах.
* [Flashlight](https://github.com/flashlight/flashlight) ![](https://img.shields.io/github/stars/flashlight/flashlight.svg?cacheSeconds=172800) - Быстрая и гибкая библиотека машинного обучения, полностью написанная на C++ исследовательской группой Facebook AI Research и создателями Torch, TensorFlow, Eigen и Deep Speech.
* [Flax](https://github.com/google/flax) ![](https://img.shields.io/github/stars/google/flax.svg?cacheSeconds=172800) - Библиотека нейронных сетей и экосистема для JAX, разработанная с упором на гибкость.
* [GPUStack](https://github.com/gpustack/gpustack) ![](https://img.shields.io/github/stars/gpustack/gpustack.svg?cacheSeconds=172800) - GPUStack — диспетчер кластеров GPU с открытым исходным кодом для запуска моделей ИИ.
* [Hivemind](https://github.com/learning-at-home/hivemind) ![](https://img.shields.io/github/stars/learning-at-home/hivemind.svg?cacheSeconds=172800) - Децентрализованное глубокое обучение на PyTorch.
* [Jax](https://github.com/jax-ml/jax) ![](https://img.shields.io/github/stars/jax-ml/jax.svg?cacheSeconds=172800) - Компонентные преобразования программ на Python и NumPy: дифференцирование, векторизация, JIT-компиляция для GPU/TPU и многое другое.
* [Kompute](https://github.com/KomputeProject/kompute) ![](https://img.shields.io/github/stars/KomputeProject/kompute.svg?cacheSeconds=172800) - Молниеносно быстрый, лёгкий и работающий на мобильных телефонах фреймворк вычислений Vulkan, оптимизированный для сложной обработки данных на GPU.
* [Liger Kernel](https://github.com/linkedin/Liger-Kernel) ![](https://img.shields.io/github/stars/linkedin/Liger-Kernel.svg?cacheSeconds=172800) - Liger Kernel — набор ядер Triton, специально разработанных для обучения LLM.
* [LightGBM](https://github.com/lightgbm-org/LightGBM) ![](https://img.shields.io/github/stars/lightgbm-org/LightGBM.svg?cacheSeconds=172800) - LightGBM — фреймворк градиентного бустинга с алгоритмами обучения на основе деревьев.
* [MLX](https://github.com/ml-explore/mlx) ![](https://img.shields.io/github/stars/ml-explore/mlx.svg?cacheSeconds=172800) - MLX — фреймворк массивов для машинного обучения на Apple silicon.
* [Modin](https://github.com/modin-project/modin) ![](https://img.shields.io/github/stars/modin-project/modin.svg?cacheSeconds=172800) - Ускорьте работу с Pandas, изменив всего одну строку кода.
* [NVIDIA TensorRT](https://github.com/NVIDIA/TensorRT) ![](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?cacheSeconds=172800) - TensorRT — библиотека C++ для высокопроизводительного инференса на GPU NVIDIA и ускорителях глубокого обучения.
* [Nevergrad](https://github.com/facebookresearch/nevergrad) ![](https://img.shields.io/github/stars/facebookresearch/nevergrad.svg?cacheSeconds=172800) - Nevergrad — платформа оптимизации без градиентов.
* [Norse](https://github.com/norse/norse) ![](https://img.shields.io/github/stars/norse/norse.svg?cacheSeconds=172800) - Norse использует преимущества биоинспирированных нейронных компонентов, которые являются разреженными и управляются событиями, что принципиально отличает их от искусственных нейронных сетей.
* [Numba](https://github.com/numba/numba) ![](https://img.shields.io/github/stars/numba/numba.svg?cacheSeconds=172800) Компилятор для массивов Python и числовых функций.

* [NeMo Guardrails](https://github.com/NVIDIA-NeMo/Guardrails) ![](https://img.shields.io/github/stars/NVIDIA-NeMo/Guardrails.svg?cacheSeconds=172800) - NeMo Guardrails — инструментарий с открытым исходным кодом, упрощающий добавление программируемых защитных механизмов в диалоговые системы на основе LLM.
* [Opacus](https://github.com/meta-pytorch/opacus)  ![](https://img.shields.io/github/stars/meta-pytorch/opacus.svg?cacheSeconds=172800) - Opacus — библиотека для обучения моделей PyTorch с дифференциальной приватностью.
