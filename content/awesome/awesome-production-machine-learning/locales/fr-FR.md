# Awesome Production Machine Learning

Ce dépôt rassemble une sélection de bibliothèques open source remarquables pour déployer, surveiller, versionner, mettre à l’échelle et sécuriser des systèmes de machine learning en production 🚀

Pour rester au courant, suivez ce dépôt GitHub : vous recevrez chaque mois, [via les releases](https://github.com/EthicalML/awesome-production-machine-learning/releases), un récapitulatif des nouvelles bibliothèques de ML en production 🤩

Nous proposons également une [boîte à outils de recherche](https://huggingface.co/spaces/zhiminy/Awesome-Production-Machine-Learning-Search) pour parcourir rapidement cet ensemble d’outils.

# Contenu principal

## AutoML
* [AIDE](https://github.com/WecoAI/aideml) ![](https://img.shields.io/github/stars/WecoAI/aideml.svg?cacheSeconds=172800) - AIDE est un agent d’ingénierie ML open source qui utilise un algorithme de recherche arborescente pour explorer, mettre en œuvre et évaluer de manière autonome des stratégies de résolution de tâches de machine learning.
* [AutoGluon](https://github.com/autogluon/autogluon) ![](https://img.shields.io/github/stars/autogluon/autogluon.svg?cacheSeconds=172800) - Sélection automatisée de caractéristiques, de modèles et d’hyperparamètres pour les données tabulaires, les images et le texte, reposant sur des bibliothèques de machine learning populaires (Scikit-Learn, LightGBM, CatBoost, PyTorch, MXNet).
* [Autokeras](https://github.com/keras-team/autokeras) ![](https://img.shields.io/github/stars/keras-team/autokeras.svg?cacheSeconds=172800) - Bibliothèque AutoML pour Keras fondée sur [« Auto-Keras: Efficient Neural Architecture Search with Network Morphism »](https://arxiv.org/abs/1806.10282).
* [auto-sklearn](https://github.com/automl/auto-sklearn) ![](https://img.shields.io/github/stars/automl/auto-sklearn.svg?cacheSeconds=172800) - Framework qui automatise le réglage des algorithmes et des hyperparamètres pour sklearn.
* [Ax](https://github.com/facebook/Ax) ![](https://img.shields.io/github/stars/facebook/Ax.svg?cacheSeconds=172800) - Ax est une plateforme accessible et polyvalente pour comprendre, gérer, déployer et automatiser des expériences adaptatives.
* [BoTorch](https://github.com/meta-pytorch/botorch) ![](https://img.shields.io/github/stars/meta-pytorch/botorch.svg?cacheSeconds=172800) - BoTorch est une bibliothèque d’optimisation bayésienne conçue sur PyTorch.
* [EvalML](https://github.com/alteryx/evalml) ![](https://img.shields.io/github/stars/alteryx/evalml.svg?cacheSeconds=172800) - EvalML est une bibliothèque AutoML qui construit, optimise et évalue des pipelines de machine learning à l’aide de fonctions objectif propres au domaine.
* [Feature Engine](https://github.com/feature-engine/feature_engine) ![](https://img.shields.io/github/stars/feature-engine/feature_engine.svg?cacheSeconds=172800) - Feature-engine est une bibliothèque Python qui contient plusieurs transformateurs pour créer des caractéristiques destinées aux modèles de machine learning.
* [Featuretools](https://github.com/alteryx/featuretools) ![](https://img.shields.io/github/stars/alteryx/featuretools.svg?cacheSeconds=172800) - Framework open source pour l’ingénierie automatisée des caractéristiques.
* [FLAML](https://github.com/microsoft/FLAML) ![](https://img.shields.io/github/stars/microsoft/FLAML.svg?cacheSeconds=172800) - FLAML est une bibliothèque rapide pour le machine learning automatisé et le réglage des modèles.
* [HEBO](https://github.com/huawei-noah/hebo) ![](https://img.shields.io/github/stars/huawei-noah/hebo.svg?cacheSeconds=172800) - Ensemble de frameworks open source d’optimisation des hyperparamètres, dont le projet lauréat du [NeurIPS 2020 Black-Box Optimisation Challenge](https://bbochallenge.com/leaderboard), testé sur des tâches de réglage d’hyperparamètres.
* [Katib](https://github.com/kubeflow/katib) ![](https://img.shields.io/github/stars/kubeflow/katib.svg?cacheSeconds=172800) - Système de réglage des hyperparamètres et de recherche d’architectures neuronales fondé sur Kubernetes.
* [keras-tuner](https://github.com/keras-team/keras-tuner) ![](https://img.shields.io/github/stars/keras-team/keras-tuner.svg?cacheSeconds=172800) - Keras Tuner est un framework de réglage des hyperparamètres facile à utiliser et distribuable, qui résout les difficultés de la recherche d’hyperparamètres. Il permet de définir facilement un espace de recherche et d’utiliser les algorithmes intégrés pour trouver les meilleures valeurs.
* [Optuna](https://github.com/optuna/optuna) ![](https://img.shields.io/github/stars/optuna/optuna.svg?cacheSeconds=172800) - Optuna est un framework logiciel d’optimisation automatique des hyperparamètres, conçu notamment pour le machine learning.
* [OSS Vizier](https://github.com/google/vizier) ![](https://img.shields.io/github/stars/google/vizier.svg?cacheSeconds=172800) - OSS Vizier est un service Python d’optimisation en boîte noire et de recherche, l’un des premiers services de réglage des hyperparamètres conçus pour fonctionner à grande échelle.
* [Perpetual](https://github.com/perpetual-ml/perpetual) ![](https://img.shields.io/github/stars/perpetual-ml/perpetual.svg?cacheSeconds=172800) - Machine de boosting par gradient qui ne nécessite pas d’optimisation des hyperparamètres ; un simple paramètre de budget permet de contrôler la complexité du modèle.
* [TPOT](https://github.com/epistasislab/tpot) ![](https://img.shields.io/github/stars/epistasislab/tpot.svg?cacheSeconds=172800) - Automatisation de la création de pipelines sklearn (y compris la sélection de caractéristiques, le prétraitement, etc.).
* [tsfresh](https://github.com/blue-yonder/tsfresh) ![](https://img.shields.io/github/stars/blue-yonder/tsfresh.svg?cacheSeconds=172800) - Extraction automatique de caractéristiques pertinentes à partir de séries temporelles.

## Optimisation du calcul et de la communication

* [Accelerate](https://github.com/huggingface/accelerate) ![](https://img.shields.io/github/stars/huggingface/accelerate.svg?cacheSeconds=172800) - Accelerate n’abstrait que le code répétitif lié au multi-GPU/TPU et à la précision mixte ; le reste de votre code demeure inchangé.
* [Adapters](https://github.com/adapter-hub/adapters) ![](https://img.shields.io/github/stars/adapter-hub/adapters.svg?cacheSeconds=172800) - Adapters est une bibliothèque unifiée pour l’apprentissage par transfert modulaire et économe en paramètres.
* [Cache-DiT](https://github.com/vipshop/cache-dit) ![](https://img.shields.io/github/stars/vipshop/cache-dit.svg?cacheSeconds=172800) - Cache-DiT repose sur Diffusers et prend en charge presque tous les DiT. Il fournit une accélération hybride par cache (DBCache, TaylorSeer, SCM, etc.) ainsi que des optimisations complètes du parallélisme : parallélisme de contexte, de tenseurs et parallélisme hybride 2D/3D, avec compatibilité pour la compilation, le déchargement vers le CPU et la quantification.
* [Colossal-AI](https://github.com/hpcaitech/ColossalAI) ![](https://img.shields.io/github/stars/hpcaitech/ColossalAI.svg?cacheSeconds=172800) - Système unifié d’apprentissage profond pour l’ère des grands modèles, qui aide à déployer rapidement et efficacement l’entraînement et l’inférence de grands modèles d’IA.
* [Composer](https://github.com/mosaicml/composer) ![](https://img.shields.io/github/stars/mosaicml/composer.svg?cacheSeconds=172800) - Composer est une bibliothèque PyTorch qui permet d’entraîner des réseaux neuronaux plus rapidement, à moindre coût et avec une meilleure précision.
* [CuDF](https://github.com/NVIDIA/cudf) ![](https://img.shields.io/github/stars/NVIDIA/cudf.svg?cacheSeconds=172800) - Fondée sur le format mémoire colonnaire Apache Arrow, cuDF est une bibliothèque GPU de DataFrames permettant de charger, joindre, agréger, filtrer et manipuler des données.
* [CuML](https://github.com/NVIDIA/cuml) ![](https://img.shields.io/github/stars/NVIDIA/cuml.svg?cacheSeconds=172800) - cuML est une suite de bibliothèques qui implémentent des algorithmes de machine learning et des fonctions primitives mathématiques, avec des API compatibles avec celles des autres projets RAPIDS.
* [CuPy](https://github.com/cupy/cupy) ![](https://img.shields.io/github/stars/cupy/cupy.svg?cacheSeconds=172800) - Implémentation sur CUDA de tableaux multidimensionnels compatibles avec NumPy. CuPy comprend la classe centrale de tableaux multidimensionnels cupy.ndarray et de nombreuses fonctions associées.
* [DEAP](https://github.com/DEAP/deap) ![](https://img.shields.io/github/stars/DEAP/deap.svg?cacheSeconds=172800) - Framework original de calcul évolutif permettant de prototyper et de tester rapidement des idées. Il vise à rendre les algorithmes explicites et les structures de données transparentes. Il s’intègre parfaitement aux mécanismes de parallélisation tels que multiprocessing et SCOOP.
* [DeepEP](https://github.com/deepseek-ai/DeepEP) ![](https://img.shields.io/github/stars/deepseek-ai/DeepEP.svg?cacheSeconds=172800) - DeepEP est une bibliothèque de communication adaptée aux Mixture-of-Experts (MoE) et au parallélisme des experts (EP). Elle fournit des noyaux GPU all-to-all à haut débit et faible latence, également appelés dispatch et combinaison MoE. La bibliothèque prend aussi en charge les opérations en faible précision, notamment FP8.
* [DGL](https://github.com/dmlc/dgl) ![](https://img.shields.io/github/stars/dmlc/dgl.svg?cacheSeconds=172800) - DGL est un package Python évolutif, performant et facile à utiliser pour l’apprentissage profond sur graphes.
* [DLRover](https://github.com/intelligent-machine-learning/dlrover) ![](https://img.shields.io/github/stars/intelligent-machine-learning/dlrover.svg?cacheSeconds=172800) - DLRover simplifie l’entraînement distribué de grands modèles d’IA : il le rend facile, stable, rapide et écoresponsable.
* [Dask](https://github.com/dask/dask) ![](https://img.shields.io/github/stars/dask/dask.svg?cacheSeconds=172800) - Framework de traitement parallèle distribué pour les calculs Pandas et NumPy.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) ![](https://img.shields.io/github/stars/deepspeedai/DeepSpeed.svg?cacheSeconds=172800) - DeepSpeed est une bibliothèque d’optimisation de l’apprentissage profond qui rend l’entraînement et l’inférence distribués faciles, efficaces et performants.
* [FlagGems](https://github.com/flagos-ai/FlagGems) ![](https://img.shields.io/github/stars/flagos-ai/FlagGems.svg?cacheSeconds=172800) - FlagGems est une bibliothèque générale d’opérateurs performants, implémentée dans OpenAI Triton. Elle s’appuie sur un ensemble de noyaux indépendants du backend visant à accélérer l’entraînement et l’inférence des LLM sur des plateformes matérielles variées.
* [Flashlight](https://github.com/flashlight/flashlight) ![](https://img.shields.io/github/stars/flashlight/flashlight.svg?cacheSeconds=172800) - Bibliothèque de machine learning rapide et flexible, entièrement écrite en C++ par Facebook AI Research et les créateurs de Torch, TensorFlow, Eigen et Deep Speech.
* [Flax](https://github.com/google/flax) ![](https://img.shields.io/github/stars/google/flax.svg?cacheSeconds=172800) - Bibliothèque de réseaux neuronaux et écosystème pour JAX, conçus pour offrir de la flexibilité.
* [GPUStack](https://github.com/gpustack/gpustack) ![](https://img.shields.io/github/stars/gpustack/gpustack.svg?cacheSeconds=172800) - GPUStack est un gestionnaire open source de clusters GPU destiné à l’exécution de modèles d’IA.
* [Hivemind](https://github.com/learning-at-home/hivemind) ![](https://img.shields.io/github/stars/learning-at-home/hivemind.svg?cacheSeconds=172800) - Apprentissage profond décentralisé avec PyTorch.
* [Jax](https://github.com/jax-ml/jax) ![](https://img.shields.io/github/stars/jax-ml/jax.svg?cacheSeconds=172800) - Transformations composables de programmes Python+NumPy : différentiation, vectorisation, compilation JIT pour GPU/TPU, et bien plus.
* [Kompute](https://github.com/KomputeProject/kompute) ![](https://img.shields.io/github/stars/KomputeProject/kompute.svg?cacheSeconds=172800) - Framework de calcul Vulkan rapide, léger et compatible avec les téléphones mobiles, optimisé pour les usages avancés de traitement de données sur GPU.
* [Liger Kernel](https://github.com/linkedin/Liger-Kernel) ![](https://img.shields.io/github/stars/linkedin/Liger-Kernel.svg?cacheSeconds=172800) - Liger Kernel est un ensemble de noyaux Triton spécialement conçus pour l’entraînement des LLM.
* [LightGBM](https://github.com/lightgbm-org/LightGBM) ![](https://img.shields.io/github/stars/lightgbm-org/LightGBM.svg?cacheSeconds=172800) - LightGBM est un framework de boosting par gradient qui utilise des algorithmes d’apprentissage fondés sur des arbres.
* [MLX](https://github.com/ml-explore/mlx) ![](https://img.shields.io/github/stars/ml-explore/mlx.svg?cacheSeconds=172800) - MLX est un framework de tableaux destiné au machine learning sur les puces Apple.
* [Modin](https://github.com/modin-project/modin) ![](https://img.shields.io/github/stars/modin-project/modin.svg?cacheSeconds=172800) - Accélérez vos workflows Pandas en ne modifiant qu’une seule ligne de code.
* [NVIDIA TensorRT](https://github.com/NVIDIA/TensorRT) ![](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?cacheSeconds=172800) - TensorRT est une bibliothèque C++ destinée à l’inférence haute performance sur les GPU NVIDIA et les accélérateurs d’apprentissage profond.
* [Nevergrad](https://github.com/facebookresearch/nevergrad) ![](https://img.shields.io/github/stars/facebookresearch/nevergrad.svg?cacheSeconds=172800) - Nevergrad est une plateforme d’optimisation sans gradient.
* [Norse](https://github.com/norse/norse) ![](https://img.shields.io/github/stars/norse/norse.svg?cacheSeconds=172800) - Norse vise à exploiter les avantages des composants neuronaux inspirés de la biologie, clairsemés et déclenchés par événements, une différence fondamentale par rapport aux réseaux neuronaux artificiels.
* [Numba](https://github.com/numba/numba) ![](https://img.shields.io/github/stars/numba/numba.svg?cacheSeconds=172800)  - Compilateur pour les fonctions Python de calcul numérique et sur tableaux.
* [Optimum](https://github.com/huggingface/optimum) ![](https://img.shields.io/github/stars/huggingface/optimum.svg?cacheSeconds=172800) - Optimum étend Transformers et Diffusers en fournissant des outils d’optimisation qui maximisent l’efficacité de l’entraînement et de l’exécution des modèles sur le matériel visé, tout en restant faciles à utiliser.
* [PEFT](https://github.com/huggingface/peft) ![](https://img.shields.io/github/stars/huggingface/peft.svg?cacheSeconds=172800) - Les méthodes PEFT (Parameter-Efficient Fine-Tuning) permettent d’adapter efficacement des modèles de langue préentraînés (PLM) à diverses tâches en aval sans ajuster tous leurs paramètres.
* [PaddlePaddle](https://github.com/PaddlePaddle/Paddle) ![](https://img.shields.io/github/stars/PaddlePaddle/Paddle.svg?cacheSeconds=172800) - PaddlePaddle est un framework pour l’entraînement de réseaux profonds à grande échelle, utilisant des sources de données réparties sur des centaines de nœuds.
* [PyG](https://github.com/pyg-team/pytorch_geometric) ![](https://img.shields.io/github/stars/pyg-team/pytorch_geometric.svg?cacheSeconds=172800) - PyG (PyTorch Geometric) est une bibliothèque construite sur PyTorch qui facilite l’écriture et l’entraînement de réseaux neuronaux sur graphes (GNN) pour de nombreuses applications liées aux données structurées.
* [PyTorch Lightning](https://github.com/Lightning-AI/pytorch-lightning) ![](https://img.shields.io/github/stars/Lightning-AI/pytorch-lightning.svg?cacheSeconds=172800) - PyTorch Lightning préentraîne, ajuste finement et déploie des modèles d’IA sur plusieurs GPU et TPU sans modifier le code.
* [PyTorch](https://github.com/pytorch/pytorch) ![](https://img.shields.io/github/stars/pytorch/pytorch.svg?cacheSeconds=172800) - PyTorch est une bibliothèque pour développer et entraîner des modèles d’apprentissage profond fondés sur des réseaux neuronaux.
* [Ray](https://github.com/ray-project/ray) ![](https://img.shields.io/github/stars/ray-project/ray.svg?cacheSeconds=172800) - Ray est un framework d’exécution distribuée flexible et performant pour le machine learning.
* [SetFit](https://github.com/huggingface/setfit) ![](https://img.shields.io/github/stars/huggingface/setfit.svg?cacheSeconds=172800) - SetFit est un framework efficace, sans prompt, pour l’ajustement fin en few-shot de Sentence Transformers.
* [Sonnet](https://github.com/google-deepmind/sonnet) ![](https://img.shields.io/github/stars/google-deepmind/sonnet.svg?cacheSeconds=172800) - Sonnet est une bibliothèque construite sur TensorFlow 2, conçue pour fournir des abstractions simples et composables destinées à la recherche en machine learning.
* [Streaming](https://github.com/mosaicml/streaming) ![](https://img.shields.io/github/stars/mosaicml/streaming.svg?cacheSeconds=172800) - Bibliothèque de diffusion de données pour entraîner efficacement des réseaux neuronaux.
* [TensorFlow](https://github.com/tensorflow/tensorflow) ![](https://img.shields.io/github/stars/tensorflow/tensorflow.svg?cacheSeconds=172800) - TensorFlow est une bibliothèque de premier plan conçue pour développer et déployer des applications de machine learning de pointe.
* [ThunderKittens](https://github.com/HazyResearch/ThunderKittens) ![](https://img.shields.io/github/stars/HazyResearch/ThunderKittens.svg?cacheSeconds=172800) ThunderKittens est un framework qui facilite l’écriture de noyaux d’apprentissage profond rapides en CUDA.
* [TorchOpt](https://github.com/metaopt/torchopt) ![](https://img.shields.io/github/stars/metaopt/torchopt.svg?cacheSeconds=172800) - TorchOpt est une bibliothèque efficace d’optimisation différentiable fondée sur PyTorch.
* [Triton](https://github.com/triton-lang/triton) ![](https://img.shields.io/github/stars/triton-lang/triton.svg?cacheSeconds=172800) - Triton est un langage et un compilateur permettant d’écrire des primitives personnalisées d’apprentissage profond très efficaces. Son objectif est de fournir un environnement open source pour produire rapidement du code avec une productivité supérieure à CUDA, tout en offrant davantage de flexibilité que les autres DSL existants.
* [Vaex](https://github.com/vaexio/vaex) ![](https://img.shields.io/github/stars/vaexio/vaex.svg?cacheSeconds=172800) Vaex est une bibliothèque Python performante pour les DataFrames différés hors mémoire (similaires à Pandas), qui permet de visualiser et d’explorer de grands jeux de données tabulaires. Vaex utilise le mappage mémoire, la copie mémoire nulle et les calculs différés pour offrir les meilleures performances sans gaspiller de mémoire.
* [Vowpal Wabbit](https://github.com/VowpalWabbit/vowpal_wabbit) ![](https://img.shields.io/github/stars/VowpalWabbit/vowpal_wabbit.svg?cacheSeconds=172800) Vowpal Wabbit est un système de machine learning qui repousse les limites du domaine grâce à des techniques telles que l’apprentissage en ligne, le hachage, allreduce, les réductions, learning2search, l’apprentissage actif et interactif.
