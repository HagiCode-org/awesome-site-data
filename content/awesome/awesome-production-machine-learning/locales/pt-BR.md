# Awesome Production Machine Learning

Este repositório reúne uma lista selecionada de bibliotecas incríveis de código aberto que ajudam a implantar, monitorar, versionar, escalar e proteger o aprendizado de máquina em produção 🚀

Você pode acompanhar as novidades seguindo este repositório no GitHub para receber, todos os meses, um resumo das novas bibliotecas de ML para produção adicionadas [nas versões](https://github.com/EthicalML/awesome-production-machine-learning/releases) 🤩

Além disso, oferecemos um [kit de busca](https://huggingface.co/spaces/zhiminy/Awesome-Production-Machine-Learning-Search) que ajuda a navegar rapidamente pela cadeia de ferramentas.

# Conteúdo principal

## AutoML
* [AIDE](https://github.com/WecoAI/aideml) ![](https://img.shields.io/github/stars/WecoAI/aideml.svg?cacheSeconds=172800) - O AIDE é um agente de engenharia de ML de código aberto que usa um algoritmo de busca em árvore para explorar, implementar e avaliar estratégias de solução para tarefas de aprendizado de máquina de forma autônoma.
* [AutoGluon](https://github.com/autogluon/autogluon) ![](https://img.shields.io/github/stars/autogluon/autogluon.svg?cacheSeconds=172800) - Seleção automatizada de recursos, modelos e hiperparâmetros para dados tabulares, de imagem e texto, baseada em bibliotecas populares de aprendizado de máquina (Scikit-Learn, LightGBM, CatBoost, PyTorch, MXNet).
* [Autokeras](https://github.com/keras-team/autokeras) ![](https://img.shields.io/github/stars/keras-team/autokeras.svg?cacheSeconds=172800) - Biblioteca AutoML para Keras baseada em ["Auto-Keras: Efficient Neural Architecture Search with Network Morphism"](https://arxiv.org/abs/1806.10282).
* [auto-sklearn](https://github.com/automl/auto-sklearn) ![](https://img.shields.io/github/stars/automl/auto-sklearn.svg?cacheSeconds=172800) - Framework para automatizar o ajuste de algoritmos e hiperparâmetros para sklearn.
* [Ax](https://github.com/facebook/Ax) ![](https://img.shields.io/github/stars/facebook/Ax.svg?cacheSeconds=172800) - Ax é uma plataforma acessível e de uso geral para compreender, gerenciar, implantar e automatizar experimentos adaptativos.
* [BoTorch](https://github.com/meta-pytorch/botorch) ![](https://img.shields.io/github/stars/meta-pytorch/botorch.svg?cacheSeconds=172800) - BoTorch é uma biblioteca de otimização Bayesiana criada sobre o PyTorch.
* [EvalML](https://github.com/alteryx/evalml) ![](https://img.shields.io/github/stars/alteryx/evalml.svg?cacheSeconds=172800) - EvalML é uma biblioteca AutoML que cria, otimiza e avalia pipelines de aprendizado de máquina usando funções objetivo específicas do domínio.
* [Feature Engine](https://github.com/feature-engine/feature_engine) ![](https://img.shields.io/github/stars/feature-engine/feature_engine.svg?cacheSeconds=172800) - Feature-engine é uma biblioteca Python que contém vários transformadores para criar recursos usados em modelos de aprendizado de máquina.
* [Featuretools](https://github.com/alteryx/featuretools) ![](https://img.shields.io/github/stars/alteryx/featuretools.svg?cacheSeconds=172800) - Framework de código aberto para engenharia automatizada de recursos.
* [FLAML](https://github.com/microsoft/FLAML) ![](https://img.shields.io/github/stars/microsoft/FLAML.svg?cacheSeconds=172800) - FLAML é uma biblioteca rápida para aprendizado de máquina automatizado e ajuste.
* [HEBO](https://github.com/huawei-noah/hebo) ![](https://img.shields.io/github/stars/huawei-noah/hebo.svg?cacheSeconds=172800) - Conjunto de frameworks de otimização de hiperparâmetros de código aberto, incluindo a solução vencedora do [NeurIPS 2020 Black-Box Optimisation Challenge](https://bbochallenge.com/leaderboard), testada em tarefas de ajuste de hiperparâmetros. 
* [Katib](https://github.com/kubeflow/katib) ![](https://img.shields.io/github/stars/kubeflow/katib.svg?cacheSeconds=172800) - Sistema baseado em Kubernetes para ajuste de hiperparâmetros e busca de arquiteturas neurais.
* [keras-tuner](https://github.com/keras-team/keras-tuner) ![](https://img.shields.io/github/stars/keras-team/keras-tuner.svg?cacheSeconds=172800) - Keras Tuner é um framework de otimização de hiperparâmetros distribuível e fácil de usar, que resolve os desafios da busca de hiperparâmetros. Ele facilita a definição de um espaço de busca e o uso dos algoritmos incluídos para encontrar os melhores valores.
* [Optuna](https://github.com/optuna/optuna) ![](https://img.shields.io/github/stars/optuna/optuna.svg?cacheSeconds=172800) - Optuna é um framework de software para otimização automática de hiperparâmetros, projetado especialmente para aprendizado de máquina.
* [OSS Vizier](https://github.com/google/vizier) ![](https://img.shields.io/github/stars/google/vizier.svg?cacheSeconds=172800) - OSS Vizier é um serviço baseado em Python para otimização de caixa-preta e pesquisa, um dos primeiros serviços de ajuste de hiperparâmetros projetados para operar em grande escala.
* [Perpetual](https://github.com/perpetual-ml/perpetual) ![](https://img.shields.io/github/stars/perpetual-ml/perpetual.svg?cacheSeconds=172800) - Uma máquina de gradient boosting que dispensa otimização de hiperparâmetros, com um parâmetro de orçamento simples para controlar a complexidade do modelo.
* [TPOT](https://github.com/epistasislab/tpot) ![](https://img.shields.io/github/stars/epistasislab/tpot.svg?cacheSeconds=172800) - Automatiza a criação de pipelines do sklearn (incluindo seleção de recursos, pré-processador etc.).
* [tsfresh](https://github.com/blue-yonder/tsfresh) ![](https://img.shields.io/github/stars/blue-yonder/tsfresh.svg?cacheSeconds=172800) - Extração automática de recursos relevantes de séries temporais.

## Otimização da computação e da comunicação

* [Accelerate](https://github.com/huggingface/accelerate) ![](https://img.shields.io/github/stars/huggingface/accelerate.svg?cacheSeconds=172800) - Accelerate abstrai exatamente — e somente — o código boilerplate relacionado a várias GPUs/TPUs e precisão mista, mantendo inalterado o restante do código.
* [Adapters](https://github.com/adapter-hub/adapters) ![](https://img.shields.io/github/stars/adapter-hub/adapters.svg?cacheSeconds=172800) - Adapters é uma biblioteca unificada para aprendizado por transferência modular e eficiente em parâmetros.
* [Cache-DiT](https://github.com/vipshop/cache-dit) ![](https://img.shields.io/github/stars/vipshop/cache-dit.svg?cacheSeconds=172800) - Cache-DiT é baseado no Diffusers e oferece suporte a quase todos os DiTs, com aceleração híbrida por cache (DBCache, TaylorSeer, SCM etc.) e otimizações abrangentes de paralelismo, incluindo paralelismo de contexto, de tensores e paralelismo híbrido 2D/3D, além de compatibilidade com compilação, descarregamento para CPU e quantização.
* [Colossal-AI](https://github.com/hpcaitech/ColossalAI) ![](https://img.shields.io/github/stars/hpcaitech/ColossalAI.svg?cacheSeconds=172800) - Sistema unificado de aprendizado profundo para a era dos grandes modelos, que ajuda a implantar com eficiência e rapidez o treinamento e a inferência de grandes modelos de IA.
* [Composer](https://github.com/mosaicml/composer) ![](https://img.shields.io/github/stars/mosaicml/composer.svg?cacheSeconds=172800) - Composer é uma biblioteca PyTorch que permite treinar redes neurais com mais rapidez, menor custo e maior precisão.
* [CuDF](https://github.com/NVIDIA/cudf) ![](https://img.shields.io/github/stars/NVIDIA/cudf.svg?cacheSeconds=172800) - Baseada no formato de memória colunar Apache Arrow, cuDF é uma biblioteca GPU de DataFrames para carregar, unir, agregar, filtrar e manipular dados de outras formas.
* [CuML](https://github.com/NVIDIA/cuml) ![](https://img.shields.io/github/stars/NVIDIA/cuml.svg?cacheSeconds=172800) - cuML é um conjunto de bibliotecas que implementam algoritmos de aprendizado de máquina e funções primitivas matemáticas com APIs compatíveis com as de outros projetos RAPIDS.
* [CuPy](https://github.com/cupy/cupy) ![](https://img.shields.io/github/stars/cupy/cupy.svg?cacheSeconds=172800) - Implementação de arrays multidimensionais compatível com NumPy para CUDA. CuPy inclui a classe central de arrays multidimensionais cupy.ndarray e muitas funções para trabalhar com ela.
* [DEAP](https://github.com/DEAP/deap) ![](https://img.shields.io/github/stars/DEAP/deap.svg?cacheSeconds=172800) - Framework inovador de computação evolutiva para prototipagem rápida e teste de ideias. Busca tornar explícitos os algoritmos e transparentes as estruturas de dados. Funciona em perfeita harmonia com mecanismos de paralelização como multiprocessing e SCOOP.
* [DeepEP](https://github.com/deepseek-ai/DeepEP) ![](https://img.shields.io/github/stars/deepseek-ai/DeepEP.svg?cacheSeconds=172800) - DeepEP é uma biblioteca de comunicação desenvolvida para Mixture-of-Experts (MoE) e paralelismo de especialistas (EP). Oferece kernels GPU all-to-all de alta vazão e baixa latência, também conhecidos como dispatch e combine de MoE. A biblioteca também oferece suporte a operações de baixa precisão, incluindo FP8.
* [DGL](https://github.com/dmlc/dgl) ![](https://img.shields.io/github/stars/dmlc/dgl.svg?cacheSeconds=172800) - DGL é um pacote Python escalável, de alto desempenho e fácil de usar para aprendizado profundo em grafos.
* [DLRover](https://github.com/intelligent-machine-learning/dlrover) ![](https://img.shields.io/github/stars/intelligent-machine-learning/dlrover.svg?cacheSeconds=172800) - DLRover torna o treinamento distribuído de grandes modelos de IA fácil, estável, rápido e sustentável.
* [Dask](https://github.com/dask/dask) ![](https://img.shields.io/github/stars/dask/dask.svg?cacheSeconds=172800) - Framework de processamento paralelo distribuído para computações com Pandas e NumPy.
* [DeepSpeed](https://github.com/deepspeedai/DeepSpeed) ![](https://img.shields.io/github/stars/deepspeedai/DeepSpeed.svg?cacheSeconds=172800) - DeepSpeed é uma biblioteca de otimização de aprendizado profundo que torna o treinamento e a inferência distribuídos fáceis, eficientes e eficazes.
* [FlagGems](https://github.com/flagos-ai/FlagGems) ![](https://img.shields.io/github/stars/flagos-ai/FlagGems.svg?cacheSeconds=172800) - FlagGems é uma biblioteca de operadores genéricos de alto desempenho implementada em OpenAI Triton. Ela reúne kernels independentes de backend para acelerar o treinamento e a inferência de LLMs em diversas plataformas de hardware.
* [Flashlight](https://github.com/flashlight/flashlight) ![](https://img.shields.io/github/stars/flashlight/flashlight.svg?cacheSeconds=172800) - Biblioteca de aprendizado de máquina rápida e flexível, escrita inteiramente em C++, criada pelo Facebook AI Research e pelos criadores do Torch, TensorFlow, Eigen e Deep Speech.
* [Flax](https://github.com/google/flax) ![](https://img.shields.io/github/stars/google/flax.svg?cacheSeconds=172800) - Biblioteca e ecossistema de redes neurais para JAX, projetados para oferecer flexibilidade.
* [GPUStack](https://github.com/gpustack/gpustack) ![](https://img.shields.io/github/stars/gpustack/gpustack.svg?cacheSeconds=172800) - GPUStack é um gerenciador de clusters GPU de código aberto para executar modelos de IA.
* [Hivemind](https://github.com/learning-at-home/hivemind) ![](https://img.shields.io/github/stars/learning-at-home/hivemind.svg?cacheSeconds=172800) - Aprendizado profundo descentralizado em PyTorch.
* [Jax](https://github.com/jax-ml/jax) ![](https://img.shields.io/github/stars/jax-ml/jax.svg?cacheSeconds=172800) - Transformações combináveis de programas Python+NumPy: diferenciação automática, vetorização, compilação JIT para GPU/TPU e muito mais.
* [Kompute](https://github.com/KomputeProject/kompute) ![](https://img.shields.io/github/stars/KomputeProject/kompute.svg?cacheSeconds=172800) - Framework de computação Vulkan extremamente rápido, leve e compatível com celulares, otimizado para casos de uso avançados de processamento de dados em GPU.
* [Liger Kernel](https://github.com/linkedin/Liger-Kernel) ![](https://img.shields.io/github/stars/linkedin/Liger-Kernel.svg?cacheSeconds=172800) - Liger Kernel é uma coleção de kernels Triton projetados especificamente para treinamento de LLMs.
* [LightGBM](https://github.com/lightgbm-org/LightGBM) ![](https://img.shields.io/github/stars/lightgbm-org/LightGBM.svg?cacheSeconds=172800) - LightGBM é um framework de gradient boosting que usa algoritmos de aprendizado baseados em árvores.
* [MLX](https://github.com/ml-explore/mlx) ![](https://img.shields.io/github/stars/ml-explore/mlx.svg?cacheSeconds=172800) - MLX é um framework de arrays para aprendizado de máquina em chips Apple silicon.
* [Modin](https://github.com/modin-project/modin) ![](https://img.shields.io/github/stars/modin-project/modin.svg?cacheSeconds=172800) - Acelere seus fluxos de trabalho Pandas alterando uma única linha de código.
* [NVIDIA TensorRT](https://github.com/NVIDIA/TensorRT) ![](https://img.shields.io/github/stars/NVIDIA/TensorRT.svg?cacheSeconds=172800) - TensorRT é uma biblioteca C++ para inferência de alto desempenho em GPUs NVIDIA e aceleradores de aprendizado profundo.
* [Nevergrad](https://github.com/facebookresearch/nevergrad) ![](https://img.shields.io/github/stars/facebookresearch/nevergrad.svg?cacheSeconds=172800) - Nevergrad é uma plataforma de otimização sem gradientes.
* [Norse](https://github.com/norse/norse) ![](https://img.shields.io/github/stars/norse/norse.svg?cacheSeconds=172800) - Norse busca aproveitar as vantagens de componentes neurais bioinspirados, que são esparsos e orientados a eventos — uma diferença fundamental em relação às redes neurais artificiais.
* [Numba](https://github.com/numba/numba) ![](https://img.shields.io/github/stars/numba/numba.svg?cacheSeconds=172800) Compilador para funções numéricas e de arrays em Python.
* [Optimum](https://github.com/huggingface/optimum) ![](https://img.shields.io/github/stars/huggingface/optimum.svg?cacheSeconds=172800) - Optimum é uma extensão do Transformers e do Diffusers que oferece ferramentas de otimização para treinar e executar modelos com máxima eficiência no hardware desejado, sem deixar de ser fácil de usar.
* [PEFT](https://github.com/huggingface/peft) ![](https://img.shields.io/github/stars/huggingface/peft.svg?cacheSeconds=172800) - Os métodos de ajuste fino eficiente em parâmetros (PEFT) permitem adaptar com eficiência modelos de linguagem pré-treinados (PLMs) a diversas aplicações posteriores sem ajustar todos os parâmetros do modelo.
* [PaddlePaddle](https://github.com/PaddlePaddle/Paddle) ![](https://img.shields.io/github/stars/PaddlePaddle/Paddle.svg?cacheSeconds=172800) - PaddlePaddle é um framework para treinamento de redes profundas em grande escala, usando fontes de dados distribuídas por centenas de nós. 
* [PyG](https://github.com/pyg-team/pytorch_geometric) ![](https://img.shields.io/github/stars/pyg-team/pytorch_geometric.svg?cacheSeconds=172800) - PyG (PyTorch Geometric) é uma biblioteca baseada em PyTorch que facilita a criação e o treinamento de redes neurais em grafos (GNNs) para diversas aplicações com dados estruturados.
* [PyTorch Lightning](https://github.com/Lightning-AI/pytorch-lightning) ![](https://img.shields.io/github/stars/Lightning-AI/pytorch-lightning.svg?cacheSeconds=172800) - PyTorch Lightning pré-treina, ajusta e implanta modelos de IA em várias GPUs e TPUs sem alterar o código.
* [PyTorch](https://github.com/pytorch/pytorch) ![](https://img.shields.io/github/stars/pytorch/pytorch.svg?cacheSeconds=172800) - PyTorch é uma biblioteca para desenvolver e treinar modelos de aprendizado profundo baseados em redes neurais.
* [Ray](https://github.com/ray-project/ray) ![](https://img.shields.io/github/stars/ray-project/ray.svg?cacheSeconds=172800) - Ray é um framework flexível e de alto desempenho para execução distribuída de tarefas de aprendizado de máquina.
* [SetFit](https://github.com/huggingface/setfit) ![](https://img.shields.io/github/stars/huggingface/setfit.svg?cacheSeconds=172800) - SetFit é um framework eficiente, sem prompts, para ajuste fino few-shot de Sentence Transformers.
* [Sonnet](https://github.com/google-deepmind/sonnet) ![](https://img.shields.io/github/stars/google-deepmind/sonnet.svg?cacheSeconds=172800) - Sonnet é uma biblioteca baseada no TensorFlow 2 que oferece abstrações simples e combináveis para pesquisa em aprendizado de máquina.
* [Streaming](https://github.com/mosaicml/streaming) ![](https://img.shields.io/github/stars/mosaicml/streaming.svg?cacheSeconds=172800) - Biblioteca de streaming de dados para treinamento eficiente de redes neurais.
* [TensorFlow](https://github.com/tensorflow/tensorflow) ![](https://img.shields.io/github/stars/tensorflow/tensorflow.svg?cacheSeconds=172800) - TensorFlow é uma biblioteca líder para desenvolver e implantar aplicações de aprendizado de máquina de última geração.
* [ThunderKittens](https://github.com/HazyResearch/ThunderKittens) ![](https://img.shields.io/github/stars/HazyResearch/ThunderKittens.svg?cacheSeconds=172800) ThunderKittens é um framework que facilita a criação de kernels rápidos de aprendizado profundo em CUDA.
* [TorchOpt](https://github.com/metaopt/torchopt) ![](https://img.shields.io/github/stars/metaopt/torchopt.svg?cacheSeconds=172800) - TorchOpt é uma biblioteca eficiente para otimização diferenciável baseada em PyTorch.
* [Triton](https://github.com/triton-lang/triton) ![](https://img.shields.io/github/stars/triton-lang/triton.svg?cacheSeconds=172800) - Triton é uma linguagem e um compilador para escrever primitivas personalizadas de aprendizado profundo altamente eficientes. Seu objetivo é oferecer um ambiente de código aberto para escrever código rápido com produtividade superior à do CUDA e mais flexibilidade que outras DSLs existentes.
* [Vaex](https://github.com/vaexio/vaex) ![](https://img.shields.io/github/stars/vaexio/vaex.svg?cacheSeconds=172800) Vaex é uma biblioteca Python de alto desempenho para DataFrames lazy e out-of-core (semelhantes aos do Pandas), usada para visualizar e explorar grandes conjuntos de dados tabulares. Vaex usa mapeamento de memória, política de cópia zero de memória e computações lazy para obter o melhor desempenho (sem desperdício de memória).
* [Vowpal Wabbit](https://github.com/VowpalWabbit/vowpal_wabbit) ![](https://img.shields.io/github/stars/VowpalWabbit/vowpal_wabbit.svg?cacheSeconds=172800) Vowpal Wabbit é um sistema de aprendizado de máquina que amplia as fronteiras da área com técnicas como aprendizado online, hashing, allreduce, reduções, learning2search, aprendizado ativo e interativo.
