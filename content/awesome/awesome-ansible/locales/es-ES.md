Esta lista colaborativa, seleccionada por la comunidad, reúne recursos, herramientas, roles, tutoriales de Ansible y otros contenidos relacionados.

[Ansible](https://www.ansible.com/) es un conjunto de herramientas de código abierto escrito en Python para la gestión de configuración, el despliegue de aplicaciones, la entrega continua, la automatización de infraestructuras TI y la automatización en general.

⚠️ Antes de añadir tu proyecto, consulta los [recursos de desarrollo de proyectos del ecosistema Ansible](https://docs.ansible.com/ansible/devel/community/ecosystem_project_resources.html). ¡Ofrezcamos la mejor experiencia a usuarios, colaboradores y mantenedores!

## Herramientas

> Herramientas para Ansible y que utilizan Ansible.

- [Automation Controller](https://www.ansible.com/products/controller) - Antes Ansible Tower; este producto de Red Hat permite escalar la automatización TI, gestionar despliegues complejos y mejorar la productividad, extendiendo Ansible a todo el equipo.
- [AWX](https://github.com/ansible/awx) - Interfaz web, API REST y motor de tareas basados en Ansible; proyecto upstream de Automation Controller.
- [Ansible Lint](https://github.com/ansible/ansible-lint) - Comprueba las mejores prácticas de los playbooks y los comportamientos mejorables.
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - Analizador estático rápido y sin conexión para playbooks, escrito en Go; aplica un subconjunto de reglas ansible-lint sin Python ni runtime de Ansible.
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - Generador sencillo de documentación anotada para roles de Ansible basado en plantillas Jinja2.
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - Genera documentación de roles a partir de argument_specs.yml para README y archivos de variables predeterminadas.
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - Convierte la salida de recopilación de facts de Ansible en una página HTML estática.
- [ARA](https://github.com/ansible-community/ara) - Registra playbooks de Ansible y facilita su comprensión y diagnóstico mediante API de informes, interfaz y CLI.
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - Muestra jerarquías de herencia del inventario y el nivel donde se definen las variables.
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - Acelera Ansible considerablemente con Mitogen.
- [Molecule](https://docs.ansible.com/projects/molecule/) - Framework para desarrollar y probar roles de Ansible.
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - Provisionador para automatizar con Packer y Ansible la creación de imágenes de VM.
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - Convierte cualquier hoja de cálculo Excel en un inventario de Ansible.
- [terraform.py](https://github.com/mantl/terraform.py) - Script de inventario dinámico de Ansible que analiza archivos de estado de Terraform.
- [Ansible101](https://ansible101.com) - Entorno interactivo sin configuración para diseñar y depurar playbooks con visualización de ejecución en tiempo real.
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - Interfaz de usuario de texto (TUI) para Ansible.
- [squest](https://hewlettpackard.github.io/squest/) - Portal de autoservicio para plantillas de trabajos de Automation Controller.
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - Herramienta que transforma contenedores mediante playbooks de Ansible y los convierte en imágenes de contenedor.
- [ansible-runner](https://github.com/ansible/ansible-runner) - Herramienta y biblioteca Python para conectar directamente con Ansible o integrarlo en otros sistemas, mediante una imagen de contenedor, una herramienta independiente o un módulo Python importable.
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - El contenido de Ansible con dependencias no predeterminadas puede ser difícil de gestionar: hay que instalar paquetes en cada nodo, convivir con el software anfitrión y mantenerlos sincronizados.
- [kics](https://github.com/Checkmarx/kics) - Herramienta SAST que analiza playbooks de infraestructura como código Ansible para detectar vulnerabilidades, incumplimientos y errores de configuración.
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - Analizador estático de playbooks, roles y colecciones que detecta credenciales codificadas, RCE y riesgos de cadena de suministro; genera SARIF, SBOM CycloneDX y GitLab SAST.
- [php-ansible Library](https://github.com/maschmann/php-ansible) - Wrapper orientado a objetos para usar Ansible desde PHP.
- [TD4A](https://github.com/cidrblock/td4a) - Ayuda de diseño para crear y probar plantillas Jinja2: combina datos YAML con una plantilla y genera el resultado.
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - Herramienta CLI que crea un grafo de plays, tareas y roles de playbooks Ansible.
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - Extrae documentación de módulos Ansible en formato HTML.
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - Interfaz moderna para administrar y ejecutar playbooks Ansible.
- [Steampunk Spotter](https://steampunk.si/spotter/) - Herramienta asistida de escritura de automatización que analiza playbooks y ofrece recomendaciones.
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - Plugin de inventario Roster que genera inventario desde YAML organizado por host; admite rangos, nombres regex, inclusiones de archivos y combinación de variables.
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - Plugin callback para pruebas de extremo a extremo de playbooks con pruebas Python y CI/CD, a fin de detectar regresiones.
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - Genera automáticamente documentación a partir de metadatos de roles Ansible.
- [antsichaut](https://github.com/ansible-community/antsichaut) - Automatiza el relleno de changelog.yaml usado por antsibull-changelog.
- [ansibledb](https://github.com/nbentoumi/ansibledb) - Servidor web API Flask con MongoDB para guardar informes y facts Ansible; permite consultar hosts y facts gestionados y buscar registros de Ansible.
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - Entorno online para ejecutar, probar y compartir plantillas Ansible.
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - Validador y formateador YAML online con esquema JSON de Ansible; la extensión de Chrome también pliega código YAML en GitHub.

## Integraciones con editores e IDE

> Integraciones con editores de texto e IDE para facilitar el desarrollo con Ansible.

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - Servidor de lenguaje que incorpora compatibilidad con Ansible a editores compatibles.
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - Añade soporte de lenguaje a Visual Studio Code y editores OpenVSX mediante ansible-language-server.
<!--lint disable -->
- [Vim](https://www.vim.org/) - Editor de texto CLI gratuito y de código abierto. Plugins útiles de Vim:
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Plugin de sintaxis Vim para Ansible 2.x; admite playbooks YAML, plantillas Jinja2 y archivos de hosts.
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Plugin Vim (cliente LSP) para Ansible con autocompletado, resaltado, ayuda al pasar el cursor, diagnósticos y navegación.
- [Emacs](https://www.gnu.org/software/emacs/) - Editor e IDE gratis y de código abierto con sangría automática, resaltado y shell de terminal integrado, entre otras funciones:
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Compatibilidad con Ansible Language Server Protocol en Emacs: resaltado, autocompletado y diagnósticos.
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - Resaltado y comprobación de sintaxis YAML.
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Resaltado y comprobación de sintaxis Jinja2.
  - [magit-mode](https://github.com/magit/magit) - Interfaz Git porcelain en Emacs.
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - Integración Ansible Lint con anotaciones automáticas/continuas de errores, advertencias e información al editar.
- [PyCharm](https://www.jetbrains.com/pycharm/) - IDE completo para desarrollo de software Python. Plugins útiles:
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - Integración Ansible Lint con anotaciones automáticas/continuas de errores, advertencias e información al editar.
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - Integración de Ansible Vault con IntelliJ IDEA y acciones contextuales para cifrar y descifrar secretos.
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - Compatibilidad completa con [Ansible](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support) en IDE basados en IntelliJ: autocompletado, resaltado, inspecciones, documentación rápida, navegación entre playbooks, roles e inventarios e integración de Ansible Vault.
