Это совместно составленный сообществом список отличных ресурсов, инструментов, ролей, руководств по Ansible и других материалов.

[Ansible](https://www.ansible.com/) — написанный на Python набор инструментов с открытым исходным кодом для управления конфигурацией, развертывания приложений, непрерывной доставки и автоматизации IT-инфраструктуры и других задач.

## Инструменты

> Инструменты для Ansible и инструменты, использующие Ansible.

- [Automation Controller](https://www.ansible.com/products/controller) - Ранее продукт назывался Ansible Tower. Решение Red Hat масштабирует IT-автоматизацию, управляет сложными развёртываниями и повышает продуктивность всей команды.
- [AWX](https://github.com/ansible/awx) - Веб-интерфейс, REST API и движок задач на базе Ansible; upstream-проект Automation Controller.
- [Ansible Lint](https://github.com/ansible/ansible-lint) - Проверяет playbook на соответствие лучшим практикам и выявляет возможности улучшения.
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - Быстрый автономный статический анализатор playbook на Go; реализует часть правил ansible-lint без Python и среды Ansible.
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - Простой генератор документации ролей Ansible с аннотациями на основе шаблонов Jinja2.
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - Создаёт документацию ролей из argument_specs.yml для README и файлов переменных по умолчанию.
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - Преобразует сбор фактов Ansible в статическую HTML-страницу.
- [ARA](https://github.com/ansible-community/ara) - Записывает playbook и помогает понять их и устранить проблемы через API отчётов, UI и CLI.
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - Показывает иерархию наследования inventory и уровень определения переменных.
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - Значительно ускоряет Ansible с помощью Mitogen.
- [Molecule](https://docs.ansible.com/projects/molecule/) - Среда разработки и тестирования ролей Ansible.
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - Provisioner для автоматизации создания образов VM с Packer и Ansible.
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - Преобразует любую таблицу Excel в inventory Ansible.
- [terraform.py](https://github.com/mantl/terraform.py) - Скрипт динамического inventory Ansible для разбора файлов состояния Terraform.
- [Ansible101](https://ansible101.com) - Интерактивная песочница без настройки: проектирование и отладка playbook с визуализацией выполнения в реальном времени.
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - Текстовый пользовательский интерфейс (TUI) для Ansible.
- [squest](https://hewlettpackard.github.io/squest/) - Портал самообслуживания для шаблонов заданий Automation Controller.
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - Инструмент преобразует контейнеры с помощью playbook Ansible в образы контейнеров.
- [ansible-runner](https://github.com/ansible/ansible-runner) - Инструмент и библиотека Python для прямого взаимодействия с Ansible или интеграции в другие системы: через образ контейнера, отдельную утилиту или импортируемый модуль Python.
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - Работа с контентом Ansible, зависящим от нестандартных зависимостей, непроста: пакеты нужно ставить на каждый узел, согласовывать с ПО хоста и синхронизировать.
- [kics](https://github.com/Checkmarx/kics) - SAST-инструмент для поиска уязвимостей, проблем соответствия и ошибок конфигурации в playbook инфраструктуры Ansible как кода.
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - Статический анализатор playbook, ролей и коллекций: ищет жёстко заданные учётные данные, риски RCE и цепочки поставок; выдаёт SARIF, CycloneDX SBOM и GitLab SAST.
- [php-ansible Library](https://github.com/maschmann/php-ansible) - Объектно-ориентированная оболочка, позволяющая использовать Ansible в PHP.
- [TD4A](https://github.com/cidrblock/td4a) - Инструмент для создания и тестирования шаблонов Jinja2: объединяет данные YAML с шаблоном и формирует результат.
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - CLI для построения графа plays, задач и ролей playbook Ansible.
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - Извлекает документацию модулей Ansible в формате HTML.
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - Современный интерфейс управления и запуска playbook Ansible.
- [Steampunk Spotter](https://steampunk.si/spotter/) - Помощник по написанию автоматизации анализирует playbook и предлагает рекомендации.
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - Плагин inventory Ansible Roster создаёт inventory из YAML с описанием хостов; поддерживает диапазоны, имена по regex, включение файлов и объединение переменных.
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - Callback-плагин выполняет сквозные тесты playbook с подходом Python-тестирования и CI/CD для обнаружения регрессий.
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - Автоматически формирует документацию из метаданных роли Ansible.
- [antsichaut](https://github.com/ansible-community/antsichaut) - Автоматизирует заполнение changelog.yaml, используемого antsibull-changelog.
- [ansibledb](https://github.com/nbentoumi/ansibledb) - Flask API-сервер с MongoDB хранит отчёты и факты Ansible; позволяет запрашивать управляемые хосты и факты, а также искать в журналах Ansible.
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - Онлайн-среда для запуска, тестирования и обмена шаблонами Ansible.
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - Онлайн-валидатор и форматтер YAML с проверкой схемы JSON Ansible; расширение Chrome также сворачивает YAML-код на GitHub.

- [redhat-cop](https://github.com/search?q=topic%3Aansible+org%3Aredhat-cop&type=Repositories&s=updated&o=desc) - Репозитории проекта Red Hat Communities of Practice с темой Ansible.
- [Linuxfabrik LFOps](https://github.com/Linuxfabrik/lfops) - Коллекция Ansible: 145+ playbook и 160+ ролей для начальной настройки и управления Linux (RHEL 8/9/10, Debian, Ubuntu); включает укрепление ОС, MariaDB, Icinga2, Nextcloud, FreeIPA, KVM и Bitwarden.

  - [magit-mode](https://github.com/magit/magit) - Интерфейс Git porcelain в Emacs.
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - Интеграция Ansible Lint автоматически и постоянно помечает ошибки, предупреждения и сведения при редактировании.

  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - Интеграция Ansible Vault для IntelliJ IDEA с контекстными действиями шифрования и расшифрования секретов.

- [OrchidE](https://www.orchide.dev) - Полноценная [поддержка языка Ansible](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support) в IDE на IntelliJ: автодополнение, подсветка, инспекции, быстрая документация, переходы между playbook, ролями и inventory, встроенный Ansible Vault.
