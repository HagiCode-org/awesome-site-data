# Awesome Ansible [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)
<!--lint disable double-link-->
[<img src="ansible_logo.svg" align="right" width="90">](https://www.ansible.com/)

コミュニティが共同で厳選した、Ansible の優れたリソース、ツール、ロール、チュートリアルなどの一覧です。

[Ansible](https://www.ansible.com/) は Python で書かれたオープンソースのツールキットで、構成管理、アプリケーションのデプロイ、継続的デリバリー、IT インフラの自動化などに使われます。

⚠️ プロジェクトを追加する前に、[Ansible エコシステムプロジェクトの開発リソース](https://docs.ansible.com/ansible/devel/community/ecosystem_project_resources.html)をご確認ください。ユーザー、貢献者、メンテナーに最高の体験を届けましょう！

## ツール

> Ansible 向け、および Ansible を使うツール。

- [Automation Controller](https://www.ansible.com/products/controller) - 旧Ansible Tower。Red Hat製品としてIT自動化の拡張、複雑なデプロイの管理、生産性向上を支援し、チーム全体にAnsibleの力を提供。
- [AWX](https://github.com/ansible/awx) - Ansibleを基盤とするWeb UI、REST API、タスクエンジン。Automation Controllerの上流プロジェクト。
- [Ansible Lint](https://github.com/ansible/ansible-lint) - Playbookのベストプラクティスと改善可能な動作をチェック。
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - Go製の高速なオフラインplaybook静的リンター。ansible-lintの一部ルールを実装し、PythonやAnsible実行環境は不要。
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - Jinja2テンプレートを使った、Ansibleロール向けの簡易注釈式ドキュメント生成ツール。
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - argument_specs.ymlからREADMEと既定変数ファイル向けのAnsibleロール文書を生成。
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - Ansibleのfact収集結果を静的HTMLページに変換。
- [ARA](https://github.com/ansible-community/ara) - Ansible playbookを記録し、レポートAPI、UI、CLIで理解とトラブル対応を支援。
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - インベントリの継承階層と変数定義レベルを表示。
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - MitogenでAnsibleを大幅に高速化。
- [Molecule](https://docs.ansible.com/projects/molecule/) - Ansibleロールの開発・テスト用フレームワーク。
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - PackerとAnsibleによるVMイメージ作成を自動化するProvisioner。
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - 任意のExcelシートをAnsibleインベントリに変換。
- [terraform.py](https://github.com/mantl/terraform.py) - Terraformの状態ファイルを解析するAnsible動的インベントリスクリプト。
- [Ansible101](https://ansible101.com) - 設定不要の対話型サンドボックス。playbookの設計・デバッグと実行フローのリアルタイム可視化が可能。
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - Ansible向けテキストユーザーインターフェース（TUI）。
- [squest](https://hewlettpackard.github.io/squest/) - Automation Controllerのジョブテンプレート向けセルフサービスポータル。
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - Ansible playbookでコンテナを加工し、コンテナイメージにするツール。
- [ansible-runner](https://github.com/ansible/ansible-runner) - Ansibleとの直接連携や他システムへの統合を支援するツールとPythonライブラリ。コンテナイメージ、単独ツール、インポート可能なPythonモジュールとして利用可能。
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - 標準外の依存関係を持つAnsibleコンテンツは扱いが難しい場合があります。各ノードへのパッケージ導入、ホストソフトとの共存、同期が必要です。
- [kics](https://github.com/Checkmarx/kics) - AnsibleのInfrastructure as Code playbookをスキャンし、脆弱性、コンプライアンス問題、設定ミスを検出するSASTツール。
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - playbook、ロール、コレクションを静的解析し、ハードコードされた認証情報、RCE、サプライチェーンのリスクを検出。SARIF、CycloneDX SBOM、GitLab SASTを出力。
- [php-ansible Library](https://github.com/maschmann/php-ansible) - AnsibleをPHPで利用できるようにするオブジェクト指向ラッパー。
- [TD4A](https://github.com/cidrblock/td4a) - YAMLデータとJinja2テンプレートを組み合わせて出力を生成する、Jinja2テンプレートの設計・テスト支援ツール。
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - Ansible playbookのplays、タスク、ロールのグラフを作成するコマンドラインツール。
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - AnsibleモジュールのドキュメントをHTML形式で抽出。
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - Ansible playbookの管理・実行向けモダンUI。
- [Steampunk Spotter](https://steampunk.si/spotter/) - Ansible Playbookを分析し、推奨事項を提示する自動化作成支援ツール。
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - ホスト中心のYAMLファイルからインベントリを生成するAnsible Rosterプラグイン。範囲、正規表現ホスト名、ファイル取り込み、変数マージに対応。
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - Python形式のテストとCI/CDでplaybookのエンドツーエンドテストを実行し、回帰を検出するコールバックプラグイン。
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - Ansibleロールのメタデータからドキュメントを自動生成。
- [antsichaut](https://github.com/ansible-community/antsichaut) - antsibull-changelogが使うchangelog.yamlの記入を自動化。
- [ansibledb](https://github.com/nbentoumi/ansibledb) - MongoDBにAnsibleレポートとfactsを保存するFlask API Webサーバー。管理対象ホスト/factsの照会やAnsibleログの検索が可能。
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - Ansibleテンプレートをオンラインで実行、テスト、共有する環境。
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - Ansible JSON Schema検証対応のオンラインYAML検証・整形ツール。Chrome拡張機能はGitHubでYAMLコードの折りたたみも追加。

## エディターと IDE の統合

> Ansible 開発を容易にするテキストエディターと IDE の統合。

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - 対応エディターにAnsibleサポートを追加するLanguage Server。
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - ansible-language-serverを利用し、Visual Studio CodeとOpenVSX対応エディターに言語機能を追加。
<!--lint disable -->
- [Vim](https://www.vim.org/) - 無料のオープンソースCLIテキストエディター。便利なVimプラグイン：
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Ansible 2.x用Vim構文プラグイン。YAML playbook、Jinja2テンプレート、Ansible hostsファイルに対応。
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Ansible用Vimプラグイン（LSPクライアント）。補完、構文強調、ホバー、診断、定義ジャンプに対応。
- [Emacs](https://www.gnu.org/software/emacs/) - 自動インデント、構文強調、内蔵ターミナルシェルなどを備えた無料のオープンソースエディター兼IDE：
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Emacs向けAnsible Language Server Protocol。構文強調、補完、診断を提供。
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - YAMLの強調表示と構文チェック。
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Jinja2の強調表示と構文チェック。
  - [magit-mode](https://github.com/magit/magit) - Emacs内のGit porcelainインターフェース。
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - 編集中にエラー、警告、情報を自動/継続的に注釈するAnsible Lint統合。
- [PyCharm](https://www.jetbrains.com/pycharm/) - Pythonソフトウェア開発向けの高機能IDE。便利なプラグイン：
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - 編集中にエラー、警告、情報を自動/継続的に注釈するAnsible Lint統合。
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - IntelliJ IDEA向けAnsible Vault統合。秘密情報の暗号化・復号化をコンテキスト操作で実行。
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - [IntelliJ系IDE向けのAnsible言語サポート](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support)。コード補完、構文強調、検査、クイックドキュメント、playbook/ロール/インベントリ間の移動、Ansible Vault統合に対応。
