这是由社区共同策划的 Ansible 优秀资源、工具、角色、教程及其他相关内容列表。

[Ansible](https://www.ansible.com/) 是以 Python 编写的开源工具集，可用于配置管理、应用部署、持续交付、IT 基础设施自动化及一般自动化。

## 工具

> 面向 Ansible 和使用 Ansible 的工具。

- [Automation Controller](https://www.ansible.com/products/controller) - 该 Red Hat 产品前身为 Ansible Tower，可扩展 IT 自动化、管理复杂部署、提升效率，并将 Ansible 能力扩展到整个团队。
- [AWX](https://github.com/ansible/awx) - 基于 Ansible 的 Web 用户界面、REST API 和任务引擎，是 Automation Controller 的上游项目。
- [Ansible Lint](https://github.com/ansible/ansible-lint) - 检查 Playbook 的最佳实践和可改进行为。
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - 快速离线的 Go playbook 静态检查器，实现部分 ansible-lint 规则，无需 Python 或 Ansible 运行时。
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - 基于 Jinja2 模板为 Ansible 角色生成简单的注释式文档。
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - 根据 argument_specs.yml 为 README 和默认变量文件生成 Ansible 角色文档。
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - 将 Ansible facts 收集结果转换为静态 HTML 页面。
- [ARA](https://github.com/ansible-community/ara) - 记录 Ansible playbook，通过报告 API、UI 和 CLI 帮助理解和排错。
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - 显示清单继承层级及变量定义所在层级。
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - 借助 Mitogen 大幅提升 Ansible 速度。
- [Molecule](https://docs.ansible.com/projects/molecule/) - 用于开发和测试 Ansible 角色的框架。
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - 使用 Packer 和 Ansible 自动创建 VM 镜像的配置器。
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - 将任意 Excel 电子表格转换为 Ansible 清单。
- [terraform.py](https://github.com/mantl/terraform.py) - 解析 Terraform 状态文件的 Ansible 动态清单脚本。
- [Ansible101](https://ansible101.com) - 交互式免配置沙盒，用于设计、调试 playbook 并实时可视化执行流程。
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - 面向 Ansible 的文本用户界面（TUI）。
- [squest](https://hewlettpackard.github.io/squest/) - Automation Controller 作业模板的自助服务门户。
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - 使用 Ansible playbook 改造容器并将其制作成容器镜像的工具。
- [ansible-runner](https://github.com/ansible/ansible-runner) - 用于直接与 Ansible 交互或集成到其他系统的工具和 Python 库，可通过容器镜像、独立工具或可导入的 Python 模块使用。
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - 使用非默认依赖项的 Ansible 内容可能较棘手：软件包须安装到每个节点，与主机软件协同并保持同步。
- [kics](https://github.com/Checkmarx/kics) - SAST 工具，扫描 Ansible 基础设施即代码 playbook 的安全漏洞、合规问题和配置错误。
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - playbook、角色和集合静态分析器，检测硬编码凭据、RCE 和供应链风险；输出 SARIF、CycloneDX SBOM 和 GitLab SAST。
- [php-ansible Library](https://github.com/maschmann/php-ansible) - Ansible 的面向对象包装器，让 PHP 能够使用 Ansible。
- [TD4A](https://github.com/cidrblock/td4a) - 用于构建和测试 Jinja2 模板的设计工具，可将 YAML 数据与模板结合并渲染输出。
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - 命令行工具，为 Ansible playbook 的 plays、任务和角色绘制图表。
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - 以 HTML 形式提取 Ansible 模块文档的工具。
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - 用于管理和运行 Ansible playbook 的现代界面。
- [Steampunk Spotter](https://steampunk.si/spotter/) - 辅助自动化编写工具，可分析 Ansible Playbook 并提出建议。
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - Ansible Roster 清单插件，可从以主机为中心的 YAML 文件生成清单；支持范围、正则主机名、文件包含和变量合并。
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - 回调插件，可通过 Pythonic 测试和 CI/CD 方法执行 playbook 端到端测试以检测回归。
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - 根据 Ansible 角色元数据自动生成文档。
- [antsichaut](https://github.com/ansible-community/antsichaut) - 自动填写 antsibull-changelog 使用的 changelog.yaml。
- [ansibledb](https://github.com/nbentoumi/ansibledb) - Flask API Web 服务器，使用 MongoDB 存储 Ansible 报告和 facts；可查询 Ansible 管理的主机和 facts，也可搜索日志。
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - 在线运行、测试和分享 Ansible 模板的游乐场。
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - 在线 YAML 验证器和格式化工具，支持 Ansible JSON Schema；Chrome 扩展还为 GitHub 添加 YAML 代码折叠。

## 编辑器与 IDE 集成

> 出色的文本编辑器和 IDE 集成，让 Ansible 开发更轻松。

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - 为兼容编辑器添加 Ansible 支持的语言服务器。
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - 借助 ansible-language-server 为 Visual Studio Code 和兼容 OpenVSX 的编辑器添加语言支持。
<!--lint disable -->
- [Vim](https://www.vim.org/) - 开源免费的命令行文本编辑器。实用 Vim 插件包括：
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Ansible 2.x 的 Vim 语法插件，支持 YAML playbook、Jinja2 模板和 Ansible 主机文件。
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Ansible 的 Vim 插件（LSP 客户端），支持自动补全、语法高亮、悬停、诊断和跳转。
- [Emacs](https://www.gnu.org/software/emacs/) - 免费开源的文本编辑器和 IDE，支持自动缩进、语法高亮和内置终端 shell 等功能：
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Emacs 的 Ansible Language Server Protocol 支持：提供语法高亮、自动补全和诊断。
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - YAML 高亮与语法检查。
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Jinja2 高亮与语法检查。
  - [magit-mode](https://github.com/magit/magit) - Emacs 中的 Git porcelain 操作界面。
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - Ansible Lint 集成，可在编辑时自动/持续标注错误、警告和提示。
- [PyCharm](https://www.jetbrains.com/pycharm/) - 功能完整的 Python 软件开发 IDE。实用插件包括：
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - Ansible Lint 集成，可在编辑时自动/持续标注错误、警告和提示。
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - 适用于 IntelliJ IDEA 的 Ansible Vault 集成，提供加密和解密密钥的上下文操作。
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - 功能齐全的 [Ansible 语言支持](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support)，适用于 IntelliJ IDE，提供代码补全、语法高亮、检查、快速文档、跨 playbook/角色/清单导航及 Ansible Vault 集成。
