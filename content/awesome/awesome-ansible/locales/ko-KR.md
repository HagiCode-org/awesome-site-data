커뮤니티가 함께 선별한 훌륭한 Ansible 리소스, 도구, 역할, 튜토리얼 및 관련 자료 목록입니다.

## 도구

> Ansible용 도구 및 Ansible을 사용하는 도구입니다.

- [Automation Controller](https://www.ansible.com/products/controller) - 이전 이름은 Ansible Tower입니다. Red Hat 제품으로 IT 자동화 확장, 복잡한 배포 관리, 생산성 향상을 지원하고 팀 전체에 Ansible을 제공합니다.
- [AWX](https://github.com/ansible/awx) - Ansible 기반 웹 UI, REST API 및 작업 엔진으로 Automation Controller의 업스트림 프로젝트입니다.
- [Ansible Lint](https://github.com/ansible/ansible-lint) - 플레이북의 모범 사례와 개선 가능한 동작을 검사합니다.
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - Go로 작성된 빠르고 오프라인인 플레이북 정적 린터로, Python이나 Ansible 런타임 없이 ansible-lint 규칙 일부를 구현합니다.
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - Jinja2 템플릿 기반의 간단한 주석형 Ansible 역할 문서 생성기.
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - argument_specs.yml에서 README 및 기본 변수 파일용 역할 문서를 생성합니다.
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - Ansible 팩트 수집 결과를 정적 HTML 페이지로 변환합니다.
- [ARA](https://github.com/ansible-community/ara) - Ansible 플레이북을 기록하고 보고 API, UI, CLI로 이해와 문제 해결을 돕습니다.
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - 인벤토리 상속 계층과 변수가 정의된 수준을 보여줍니다.
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - Mitogen으로 Ansible 속도를 크게 높입니다.
- [Molecule](https://docs.ansible.com/projects/molecule/) - Ansible 역할 개발 및 테스트 프레임워크.
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - Packer와 Ansible로 VM 이미지 생성을 자동화하는 프로비저너.
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - 모든 Excel 스프레드시트를 Ansible 인벤토리로 변환합니다.
- [terraform.py](https://github.com/mantl/terraform.py) - Terraform 상태 파일을 분석하는 Ansible 동적 인벤토리 스크립트.
- [Ansible101](https://ansible101.com) - 설정 없이 플레이북을 설계·디버그하고 실행 흐름을 실시간 시각화하는 대화형 샌드박스.
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - Ansible용 텍스트 사용자 인터페이스(TUI).
- [squest](https://hewlettpackard.github.io/squest/) - Automation Controller 작업 템플릿용 셀프서비스 포털.
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - Ansible 플레이북으로 컨테이너를 변환해 컨테이너 이미지로 만드는 도구.
- [ansible-runner](https://github.com/ansible/ansible-runner) - Ansible과 직접 연동하거나 다른 시스템에 통합하는 도구 및 Python 라이브러리. 컨테이너 이미지, 독립 도구, 가져올 수 있는 Python 모듈로 사용 가능.
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - 기본값이 아닌 종속성을 사용하는 Ansible 콘텐츠는 까다로울 수 있습니다. 각 노드에 패키지를 설치하고 호스트 소프트웨어와 조화시키며 동기화해야 합니다.
- [kics](https://github.com/Checkmarx/kics) - Ansible 인프라 코드 플레이북의 취약점, 규정 준수 문제, 잘못된 구성을 찾는 SAST 도구.
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - 플레이북, 역할, 컬렉션 정적 분석기. 하드코딩 자격 증명, RCE, 공급망 위험을 검사하고 SARIF, CycloneDX SBOM, GitLab SAST를 출력합니다.
- [php-ansible Library](https://github.com/maschmann/php-ansible) - PHP에서 Ansible을 사용할 수 있게 하는 객체 지향 래퍼.
- [TD4A](https://github.com/cidrblock/td4a) - YAML 데이터와 Jinja2 템플릿을 결합해 결과를 렌더링하는 템플릿 설계·테스트 도구.
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - Ansible 플레이북의 plays, 작업, 역할 그래프를 만드는 CLI 도구.
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - Ansible 모듈 문서를 HTML로 추출합니다.
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - Ansible 플레이북 관리 및 실행을 위한 현대적 UI.
- [Steampunk Spotter](https://steampunk.si/spotter/) - 플레이북을 분석하고 권장 사항을 제시하는 자동화 작성 지원 도구.
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - 호스트 중심 YAML에서 인벤토리를 생성하는 Roster 플러그인. 범위, 정규식 호스트명, 파일 포함, 변수 병합을 지원합니다.
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - Python 방식의 테스트 및 CI/CD로 플레이북 종단 간 테스트를 실행해 회귀를 찾는 콜백 플러그인.
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - Ansible 역할 메타데이터에서 문서를 자동 생성합니다.
- [antsichaut](https://github.com/ansible-community/antsichaut) - antsibull-changelog에서 사용하는 changelog.yaml 작성을 자동화합니다.
- [ansibledb](https://github.com/nbentoumi/ansibledb) - MongoDB에 Ansible 보고서와 팩트를 저장하는 Flask API 웹 서버입니다. 관리 호스트와 팩트를 조회하고 로그를 검색할 수 있습니다.
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - Ansible 템플릿 실행, 테스트, 공유를 위한 온라인 플레이그라운드.

## 플레이북, 역할 및 컬렉션

> 바로 시작할 수 있는 훌륭한 프로덕션 준비 플레이북, 역할 및 컬렉션입니다.

- [Ansible Vagrant Examples by geerlingguy](https://github.com/geerlingguy/ansible-vagrant-examples) - Vagrant를 사용해 로컬 VM에 배포하는 Ansible 예제.
- [Ansible playbook for Linux machine setup](https://github.com/olivomarco/my-ansible-linux-setup) - Docker 데몬을 포함한 강화되고 자동 업데이트되는 Debian/Ubuntu 시스템 설정 플레이북.
- [Ansible Lockdown](https://github.com/ansible-lockdown) - OS와 애플리케이션의 [CIS](https://www.cisecurity.org/#/) 또는 [STIG](https://public.cyber.mil/stigs/) 기준 준수를 감사하고 수정하는 Ansible 콘텐츠.
- [DevSec Hardening Framework](https://dev-sec.io/) - DevSec 컬렉션은 Linux OS, MySQL, NGINX, SSH 서버/서비스를 강화합니다.
- [T.A.D.S. boilerplate](https://github.com/Thomvaill/tads-boilerplate) - Infrastructure as Code 및 DevOps 모범 사례에 따라 개발·프로덕션 환경에 Docker Swarm 클러스터를 프로비저닝하고 배포합니다.
- [Openstack Ansible](https://github.com/openstack/openstack-ansible) - [OpenStack](https://www.openstack.org/) 배포용 Ansible 플레이북.
- [Robert de Bock](https://robertdebock.nl) - 다양한 Ansible 역할 모음.
- [DebOps](https://docs.debops.org/en/master/) - Debian 기반 Ansible 플레이북 모음.
- [ansible-ssm](https://github.com/HQarroum/ansible-ssm) - AWS SSM 에이전트로 물리 및 가상 호스트를 프로비저닝하는 Ansible 역할.

## 편집기 및 IDE 통합

> Ansible 개발을 쉽게 해 주는 텍스트 편집기와 IDE 통합입니다.

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - 호환 편집기에 Ansible 지원을 추가하는 언어 서버.
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - ansible-language-server를 활용해 Visual Studio Code와 OpenVSX 호환 편집기에 언어 지원을 추가합니다.
<!--lint disable -->
- [Vim](https://www.vim.org/) - 무료 오픈 소스 명령줄 텍스트 편집기. 유용한 Vim 플러그인:
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Ansible 2.x용 Vim 구문 플러그인으로 YAML 플레이북, Jinja2 템플릿, Ansible 호스트 파일을 지원합니다.
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Ansible용 Vim 플러그인(LSP 클라이언트)으로 자동 완성, 구문 강조, 호버, 진단, 이동 기능을 지원합니다.
- [Emacs](https://www.gnu.org/software/emacs/) - 자동 들여쓰기, 구문 강조, 내장 터미널 셸 등을 지원하는 무료 오픈 소스 편집기 및 IDE:
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Emacs용 Ansible Language Server Protocol 지원으로 구문 강조, 자동 완성, 진단을 제공합니다.
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - YAML 구문 강조 및 검사.
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Jinja2 구문 강조 및 검사.
  - [magit-mode](https://github.com/magit/magit) - Emacs 내 Git porcelain 인터페이스.
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - 편집 중 오류, 경고, 정보를 자동/지속적으로 표시하는 Ansible Lint 통합.
- [PyCharm](https://www.jetbrains.com/pycharm/) - Python 개발을 위한 완전한 IDE. 유용한 플러그인:
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - 편집 중 오류, 경고, 정보를 자동/지속적으로 표시하는 Ansible Lint 통합.
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - IntelliJ IDEA용 Ansible Vault 통합으로 비밀 정보를 암호화·복호화하는 컨텍스트 작업을 제공합니다.
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - IntelliJ 기반 IDE용 [완전한 Ansible 언어 지원](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support). 코드 완성, 구문 강조, 검사, 빠른 문서, 플레이북/역할/인벤토리 탐색, Ansible Vault 통합을 제공합니다.
