這是一份由社群共同策劃的 Ansible 優質資源、工具、角色、教學及其他相關內容清單。

[Ansible](https://www.ansible.com/) 是以 Python 撰寫的開源工具集，可用於組態管理、應用程式部署、持續交付、IT 基礎架構自動化及一般自動化。

⚠️ 新增專案之前，請先參閱 [Ansible 生態系專案開發資源](https://docs.ansible.com/ansible/devel/community/ecosystem_project_resources.html)。讓我們共同為使用者、貢獻者和維護者提供最佳體驗！

## 工具

> 面向 Ansible 和使用 Ansible 的工具。

- [Automation Controller](https://www.ansible.com/products/controller) - 該 Red Hat 產品前身為 Ansible Tower，可擴展 IT 自動化、管理复雜部署、提升效率，並將 Ansible 能力擴展到整個團隊。
- [AWX](https://github.com/ansible/awx) - 基於 Ansible 的 Web 使用者介面、REST API 和任務引擎，是 Automation Controller 的上游專案。
- [Ansible Lint](https://github.com/ansible/ansible-lint) - 檢查 Playbook 的最佳實踐和可改進行為。
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - 快速離線的 Go playbook 靜態檢查器，實現部分 ansible-lint 規则，無需 Python 或 Ansible 執行時。
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - 基於 Jinja2 模板為 Ansible 角色生成簡單的注釋式文件。
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - 根據 argument_specs.yml 為 README 和默認變量文件生成 Ansible 角色文件。
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - 將 Ansible facts 收集結果轉換為靜態 HTML 頁面。
- [ARA](https://github.com/ansible-community/ara) - 記錄 Ansible playbook，通過報告 API、UI 和 CLI 幫助理解和疑難排解。
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - 顯示清單繼承層級及變量定義所在層級。
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - 借助 Mitogen 大幅提升 Ansible 速度。
- [Molecule](https://docs.ansible.com/projects/molecule/) - 用於開發和測試 Ansible 角色的框架。
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - 使用 Packer 和 Ansible 自動創建 VM 鏡像的設定器。
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - 將任意 Excel 電子表格轉換為 Ansible 清單。
- [terraform.py](https://github.com/mantl/terraform.py) - 解析 Terraform 狀態文件的 Ansible 動態清單腳本。
- [Ansible101](https://ansible101.com) - 交互式免設定沙盒，用於設計、調試 playbook 並實時可視化執行流程。
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - 面向 Ansible 的文本使用者介面（TUI）。
- [squest](https://hewlettpackard.github.io/squest/) - Automation Controller 作业模板的自助服務門戶。
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - 使用 Ansible playbook 改造容器並將其制作成容器鏡像的工具。
- [ansible-runner](https://github.com/ansible/ansible-runner) - 用於直接與 Ansible 交互或集成到其他系統的工具與 Python 庫，可通過容器鏡像、獨立工具或可導入的 Python 模組使用。
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - 使用非默認依賴項的 Ansible 內容可能較棘手：軟件包須安裝到每個節點，與主機軟件协同並保持同步。
- [kics](https://github.com/Checkmarx/kics) - SAST 工具，掃描 Ansible 基礎設施即代碼 playbook 的安全漏洞、合規問題和設定錯誤。
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - playbook、角色和集合靜態分析器，檢測硬編碼凭據、RCE 和供應鏈風險；輸出 SARIF、CycloneDX SBOM 和 GitLab SAST。
- [php-ansible Library](https://github.com/maschmann/php-ansible) - Ansible 的面向對象包裝器，讓 PHP 能够使用 Ansible。
- [TD4A](https://github.com/cidrblock/td4a) - 用於構建和測試 Jinja2 模板的設計工具，可將 YAML 數據與模板結合並渲染輸出。
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - 命令行工具，為 Ansible playbook 的 plays、任務和角色繪制圖表。
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - 以 HTML 形式提取 Ansible 模組文件的工具。
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - 用於管理和執行 Ansible playbook 的現代介面。
- [Steampunk Spotter](https://steampunk.si/spotter/) - 辅助自動化編寫工具，可分析 Ansible Playbook 並提出建議。
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - Ansible Roster 清單插件，可從以主機為中心的 YAML 文件生成清單；支持範围、正则主機名、檔案包含和變量合並。
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - 回調插件，可通過 Pythonic 測試和 CI/CD 方法執行 playbook 端到端測試以檢測回歸。
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - 根據 Ansible 角色元數據自動生成文件。
- [antsichaut](https://github.com/ansible-community/antsichaut) - 自動填寫 antsibull-changelog 使用的 changelog.yaml。
- [ansibledb](https://github.com/nbentoumi/ansibledb) - Flask API Web 伺服器，使用 MongoDB 存储 Ansible 報告和 facts；可查詢 Ansible 管理的主機和 facts，也可搜索日志。
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - 在線執行、測試和分享 Ansible 模板的游乐場。
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - 在線 YAML 驗證器和格式化工具，支持 Ansible JSON Schema；Chrome 擴展還為 GitHub 新增 YAML 代碼折叠。

## Playbook、角色與集合

> 優秀且可用於正式環境环境的 Playbook、角色與集合，助你快速上手。

- [Ansible Vagrant Examples by geerlingguy](https://github.com/geerlingguy/ansible-vagrant-examples) - 使用 Vagrant 將 Ansible 範例部署到本地 VM。
- [Ansible playbook for Linux machine setup](https://github.com/olivomarco/my-ansible-linux-setup) - 設定可自動更新、已加固且帶 Docker daemon 的 Debian/Ubuntu 機器的 playbook。
- [Ansible Lockdown](https://github.com/ansible-lockdown) - Ansible 內容可协助審計並修复操作系統和應用程式的 [CIS](https://www.cisecurity.org/#/) 或 [STIG](https://public.cyber.mil/stigs/) 基線合規問題。
- [DevSec Hardening Framework](https://dev-sec.io/) - DevSec 集合可加固 Linux 系統以及 MySQL、NGINX 和 SSH 伺服器/服務。
- [T.A.D.S. boilerplate](https://github.com/Thomvaill/tads-boilerplate) - 在開發和正式環境环境設定部署 Docker Swarm 集群，遵循基礎設施即代碼和 DevOps 最佳實踐。
- [Openstack Ansible](https://github.com/openstack/openstack-ansible) - 用於部署 [OpenStack](https://www.openstack.org/) 的 Ansible Playbook。
- [Robert de Bock](https://robertdebock.nl) - 大量 Ansible 角色的集合。
- [DebOps](https://docs.debops.org/en/master/) - 大量基於 Debian 的 Ansible Playbook 集合。
- [ansible-ssm](https://github.com/HQarroum/ansible-ssm) - 用於通過 AWS SSM agent 設定物理主機和虛擬主機的 Ansible 角色。
- [BlueBanquise](https://github.com/bluebanquise/bluebanquise) - 用於部署集群的一組协調一致的 Ansible 角色。
- [redhat-cop](https://github.com/search?q=topic%3Aansible+org%3Aredhat-cop&type=Repositories&s=updated&o=desc) - Red Hat Communities of Practice 專案中帶有 Ansible 主題的儲存庫。
- [Linuxfabrik LFOps](https://github.com/Linuxfabrik/lfops) - Ansible 集合，包含 145+ 個 playbook 和 160+ 個角色，用於引導和管理 Linux 基礎設施（RHEL 8/9/10、Debian、Ubuntu）；涵蓋系統加固、MariaDB、Icinga2、Nextcloud、FreeIPA、KVM 和 Bitwarden 集成。

## 編輯器與 IDE 集成

> 出色的文本編輯器和 IDE 集成，讓 Ansible 開發更輕松。

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - 為兼容編輯器新增 Ansible 支持的語言伺服器。
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - 借助 ansible-language-server 為 Visual Studio Code 和兼容 OpenVSX 的編輯器新增語言支持。
<!--lint disable -->
- [Vim](https://www.vim.org/) - 開源免費的命令行文本編輯器。實用 Vim 插件包括：
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Ansible 2.x 的 Vim 語法插件，支持 YAML playbook、Jinja2 模板和 Ansible 主機文件。
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Ansible 的 Vim 插件（LSP 客戶端），支持自動補全、語法醒目提示、悬停、診斷和跳轉。
- [Emacs](https://www.gnu.org/software/emacs/) - 免費開源的文本編輯器和 IDE，支持自動縮進、語法醒目提示和内置終端 shell 等功能：
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Emacs 的 Ansible Language Server Protocol 支持：提供語法醒目提示、自動補全和診斷。
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - YAML 醒目提示與語法檢查。
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Jinja2 醒目提示與語法檢查。
  - [magit-mode](https://github.com/magit/magit) - Emacs 中的 Git porcelain 操作介面。
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - Ansible Lint 集成，可在編輯時自動/持續標注錯誤、警告和提示。
- [PyCharm](https://www.jetbrains.com/pycharm/) - 功能完整的 Python 軟件開發 IDE。實用插件包括：
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - Ansible Lint 集成，可在編輯時自動/持續標注錯誤、警告和提示。
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - 適用於 IntelliJ IDEA 的 Ansible Vault 集成，提供加密和解密密鑰的上下文操作。
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - 功能齊全的 [Ansible 語言支持](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support)，適用於 IntelliJ IDE，提供代碼補全、語法醒目提示、檢查、快速文件、跨 playbook/角色/清單導航及 Ansible Vault 集成。
