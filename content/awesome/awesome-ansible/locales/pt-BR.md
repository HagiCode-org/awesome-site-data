Esta lista colaborativa, selecionada pela comunidade, reúne recursos, ferramentas, funções, tutoriais de Ansible e outros conteúdos relacionados.

[Ansible](https://www.ansible.com/) é um conjunto de ferramentas de código aberto escrito em Python para gerenciamento de configuração, implantação de aplicações, entrega contínua, automação de infraestrutura de TI e automação em geral.

⚠️ Antes de adicionar seu projeto, consulte os [recursos de desenvolvimento de projetos do ecossistema Ansible](https://docs.ansible.com/ansible/devel/community/ecosystem_project_resources.html). Vamos oferecer a melhor experiência a usuários, colaboradores e mantenedores!

## Ferramentas

> Ferramentas para Ansible e que usam Ansible.

- [Automation Controller](https://www.ansible.com/products/controller) - Antigo Ansible Tower, este produto da Red Hat escala a automação de TI, gerencia implantações complexas e aumenta a produtividade; estende o Ansible a toda a equipe.
- [AWX](https://github.com/ansible/awx) - Interface Web, API REST e mecanismo de tarefas baseados em Ansible; projeto upstream do Automation Controller.
- [Ansible Lint](https://github.com/ansible/ansible-lint) - Verifica boas práticas nos playbooks e comportamentos que podem ser aprimorados.
- [ansible-static-lint](https://github.com/arhuman/ansible-static-lint) - Linter estático rápido e offline para playbooks em Go, com parte das regras do ansible-lint e sem Python ou runtime Ansible.
- [Ansible Doctor](https://github.com/thegeeklab/ansible-doctor) - Gerador simples de documentação anotada para funções Ansible baseado em modelos Jinja2.
- [Ansible DocSmith](https://github.com/foundata/ansible-docsmith) - Gera documentação de funções a partir de argument_specs.yml para READMEs e arquivos de variáveis padrão.
- [Ansible cmdb](https://github.com/fboender/ansible-cmdb) - Converte a coleta de facts do Ansible em uma página HTML estática.
- [ARA](https://github.com/ansible-community/ara) - Registra playbooks Ansible e facilita entendê-los e solucionar problemas via API de relatórios, interface e CLI.
- [Ansible Inventory Grapher](https://github.com/willthames/ansible-inventory-grapher) - Exibe hierarquias de herança do inventário e o nível em que as variáveis são definidas.
- [Mitogen for Ansible](https://mitogen.networkgenomics.com/ansible_detailed.html) - Acelere bastante o Ansible com Mitogen.
- [Molecule](https://docs.ansible.com/projects/molecule/) - Framework para desenvolver e testar funções Ansible.
- [Packer Ansible Provisioner](https://www.packer.io/plugins/provisioners/ansible/ansible-local) - Provisionador para automatizar a criação de imagens de VM com Packer e Ansible.
- [Excel Ansible Inventory](https://github.com/KeyboardInterrupt/ansible_xlsx_inventory) - Transforme qualquer planilha Excel em inventário Ansible.
- [terraform.py](https://github.com/mantl/terraform.py) - Script de inventário dinâmico do Ansible que analisa arquivos de estado do Terraform.
- [Ansible101](https://ansible101.com) - Sandbox interativo sem configuração para projetar e depurar playbooks com visualização da execução em tempo real.
- [ansible-navigator](https://github.com/ansible/ansible-navigator) - Interface de usuário baseada em texto (TUI) para Ansible.
- [squest](https://hewlettpackard.github.io/squest/) - Portal de autosserviço para modelos de tarefas do Automation Controller.
- [ansible-bender](https://ansible-community.github.io/ansible-bender/build/html/index.html) - Ferramenta que transforma contêineres com playbooks Ansible em imagens de contêiner.
- [ansible-runner](https://github.com/ansible/ansible-runner) - Ferramenta e biblioteca Python para conectar-se diretamente ao Ansible ou integrá-lo a outro sistema, por imagem de contêiner, ferramenta independente ou módulo Python importável.
- [ansible-builder](https://ansible-builder.readthedocs.io/en/latest/) - Conteúdo Ansible com dependências não padrão exige cuidado: instale pacotes em cada nó, compatibilize-os com o host e mantenha-os sincronizados.
- [kics](https://github.com/Checkmarx/kics) - Ferramenta SAST que verifica playbooks de infraestrutura como código Ansible em busca de vulnerabilidades, problemas de conformidade e erros de configuração.
- [ansible-security-scanner](https://github.com/cpeoples/ansible-security-scanner) - Analisador estático de playbooks, funções e coleções: credenciais codificadas, riscos de RCE e cadeia de suprimentos; gera SARIF, SBOM CycloneDX e GitLab SAST.
- [php-ansible Library](https://github.com/maschmann/php-ansible) - Wrapper orientado a objetos que disponibiliza Ansible em PHP.
- [TD4A](https://github.com/cidrblock/td4a) - Auxílio para criar e testar modelos Jinja2, combinando dados YAML e modelo para renderizar a saída.
- [Ansible Playbook Grapher](https://github.com/haidaraM/ansible-playbook-grapher) - Ferramenta CLI que cria um grafo de plays, tarefas e funções de playbooks Ansible.
- [ansible-doc-extractor](https://github.com/xlab-steampunk/ansible-doc-extractor) - Extrai documentação de módulos Ansible em HTML.
- [Ansible Semaphore](https://github.com/ansible-semaphore/semaphore) - Interface moderna para gerenciar e executar playbooks Ansible.
- [Steampunk Spotter](https://steampunk.si/spotter/) - Ferramenta assistida de escrita de automação que analisa playbooks e recomenda melhorias.
- [ansible-roster](https://gitlab.com/jlecomte/ansible/ansible-roster) - Plugin de inventário Roster que gera inventário de YAML por host; aceita intervalos, nomes regex, inclusão de arquivos e mesclagem de variáveis.
- [Monkeyble](https://hewlettpackard.github.io/monkeyble/) - Plugin callback para testes completos de playbooks com abordagem Python e CI/CD para detectar regressões.
- [aar-doc - Automated Ansible Role Documentation](https://github.com/telekom-mms/Automated-Ansible-Role-Documentation) - Gera documentação automaticamente a partir dos metadados de funções Ansible.
- [antsichaut](https://github.com/ansible-community/antsichaut) - Automatiza o preenchimento do changelog.yaml usado pelo antsibull-changelog.
- [ansibledb](https://github.com/nbentoumi/ansibledb) - Servidor Web API Flask com MongoDB para armazenar relatórios e facts Ansible; consulta hosts e facts gerenciados e pesquisa logs.
- [Ansible Template Playground](https://tech-playground.com/playgrounds/ansible-template/) - Ambiente online para executar, testar e compartilhar modelos Ansible.
- [YAML Validator](https://yamlvalidator.dev), [(chrome extension)](https://chromewebstore.google.com/detail/yaml-validator/gjgbohnlhijomhfiflapnlnmcpckgigg) - Validador e formatador YAML online com esquema JSON Ansible; a extensão do Chrome também dobra código YAML no GitHub.

## Integrações com editores e IDEs

> Integrações com editores de texto e IDEs para facilitar o desenvolvimento com Ansible.

- [Ansible Language Server](https://github.com/ansible/ansible-language-server) - Servidor de linguagem que adiciona suporte a Ansible em editores compatíveis.
- [VS Code - official Ansible Extension](https://marketplace.visualstudio.com/items?itemName=redhat.ansible) - Adiciona suporte de linguagem ao Visual Studio Code e editores OpenVSX por meio do ansible-language-server.
<!--lint disable -->
- [Vim](https://www.vim.org/) - Editor de texto CLI gratuito e de código aberto. Plugins úteis do Vim:
  - [Ansible vim](https://github.com/pearofducks/ansible-vim) - Plugin de sintaxe Vim para Ansible 2.x com suporte a playbooks YAML, modelos Jinja2 e arquivos de hosts.
  - [Ansible vim and neovim plugin](https://www.npmjs.com/package/@yaegassy/coc-ansible) - Plugin Vim (cliente LSP) para Ansible com autocompletar, realce, dicas ao passar o cursor, diagnósticos e navegação.
- [Emacs](https://www.gnu.org/software/emacs/) - Editor e IDE gratuitos e de código aberto com indentação automática, realce de sintaxe e shell integrado:
  - [lsp-mode](https://emacs-lsp.github.io/lsp-mode/page/lsp-ansible/) - Suporte ao protocolo Ansible Language Server no Emacs: realce, autocompletar e diagnósticos.
  - [yaml-mode](https://github.com/yoshiki/yaml-mode) - Realce e verificação de sintaxe YAML.
  - [jinja2-mode](https://github.com/paradoxxxzero/jinja2-mode) - Realce e verificação de sintaxe Jinja2.
  - [magit-mode](https://github.com/magit/magit) - Interface Git porcelain no Emacs.
  - [flymake-ansible-lint](https://github.com/jamescherti/flymake-ansible-lint.el) - Integração Ansible Lint com anotações automáticas/contínuas de erros, avisos e informações durante a edição.
- [PyCharm](https://www.jetbrains.com/pycharm/) - IDE completa para desenvolvimento de software Python. Plugins úteis:
  - [Ansible Lint](https://plugins.jetbrains.com/plugin/20905-ansible-lint) - Integração Ansible Lint com anotações automáticas/contínuas de erros, avisos e informações durante a edição.
  - [Ansible Vault Integration](https://plugins.jetbrains.com/plugin/14353-ansible-vault-integration) - Integração Ansible Vault para IntelliJ IDEA com ações contextuais para criptografar e descriptografar segredos.
<!--lint enable -->
- [OrchidE](https://www.orchide.dev) - Suporte completo à [linguagem Ansible](https://plugins.jetbrains.com/plugin/12626-orchide--ansible-language-support) em IDEs IntelliJ: conclusão, realce, inspeções, documentação rápida, navegação entre playbooks/funções/inventários e Ansible Vault integrado.
