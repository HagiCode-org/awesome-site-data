## What is TensorFlow?

O TensorFlow é uma biblioteca de software de código aberto para computação numérica usando grafos de fluxo de dados. Em outras palavras, a melhor maneira de construir modelos de deep learning.

Mais informações [aqui](http://tensorflow.org).

## Papers

* [TensorFlow: Large-Scale Machine Learning on Heterogeneous Distributed Systems](http://download.tensorflow.org/paper/whitepaper2015.pdf) - Este artigo descreve a interface do TensorFlow e uma implementação dessa interface que construímos no Google
* [TensorFlow Estimators: Managing Simplicity vs. Flexibility in High-Level Machine Learning Frameworks](https://arxiv.org/pdf/1708.02637.pdf)
* [TF.Learn: TensorFlow's High-level Module for Distributed Machine Learning](https://arxiv.org/abs/1612.04251)
* [Comparative Study of Deep Learning Software Frameworks](http://arxiv.org/abs/1511.06435) - O estudo é realizado em vários tipos de arquiteturas de deep learning e avaliamos o desempenho dos frameworks acima quando empregados em uma única máquina para configurações de CPU (multithreaded) e GPU (Nvidia Titan X)
* [Distributed TensorFlow with MPI](http://arxiv.org/abs/1603.02339) - Neste artigo, estendemos o TensorFlow, recentemente proposto pelo Google, para execução em clusters de grande escala usando Message Passing Interface (MPI)
* [Globally Normalized Transition-Based Neural Networks](http://arxiv.org/abs/1603.06042) - Este artigo descreve os modelos por trás do [SyntaxNet](https://github.com/tensorflow/models/tree/master/syntaxnet).
* [TensorFlow: A system for large-scale machine learning](https://arxiv.org/abs/1605.08695) - Este artigo descreve o modelo de fluxo de dados do TensorFlow em contraste com sistemas existentes e demonstra o desempenho convincente
* [TensorLayer: A Versatile Library for Efficient Deep Learning Development](https://arxiv.org/abs/1707.08551) - Este artigo descreve uma biblioteca Python versátil que visa ajudar pesquisadores e engenheiros a desenvolver sistemas de deep learning com eficiência. (Vencedor do Prêmio de Melhor Software de Código Aberto do ACM MM 2017)

## Books

* [Machine Learning with TensorFlow 2nd edition]([http://tensorflowbook.com](https://github.com/chrismattmann/MLwithTensorFlow2ed)) por [Dr. Chris A. Mattmann](http://github.com/chrismattmann/), Chief Data and Artificial Intelligence Officer na UCLA e também autor de [Tika in Action](https://www.manning.com/books/tika-in-action). Este livro torna o tema pesado em matemática de IA e ML acessível e prático para um iniciante. Atualizado para Tensorflow2 e a versão mais recente deste livro.
* [First Contact with TensorFlow](http://www.jorditorres.org/first-contact-with-tensorflow/) por Jordi Torres, professor na UPC Barcelona Tech e gerente de pesquisa e consultor sênior no Barcelona Supercomputing Center
* [Deep Learning with Python](https://machinelearningmastery.com/deep-learning-with-python/) - Desenvolva Modelos de Deep Learning no Theano e TensorFlow Usando Keras por Jason Brownlee
* [TensorFlow for Machine Intelligence](https://bleedingedgepress.com/tensor-flow-for-machine-intelligence/) - Guia completo para usar o TensorFlow desde o básico de computação em grafos, passando por modelos de deep learning até seu uso em ambientes de produção - Bleeding Edge Press
* [Getting Started with TensorFlow](https://www.packtpub.com/big-data-and-business-intelligence/getting-started-tensorflow) - Comece a usar a mais recente biblioteca de computação numérica do Google e aprofunde-se em seus dados, por Giancarlo Zaccone
* [Hands-On Machine Learning with Scikit-Learn and TensorFlow](http://shop.oreilly.com/product/0636920052289.do) – por Aurélien Geron, ex-líder da equipe de classificação de vídeos do YouTube. Cobre fundamentos de ML, treinamento e implantação de redes profundas em vários servidores e GPUs usando TensorFlow, as mais recentes arquiteturas CNN, RNN e Autoencoder, e Aprendizado por Reforço (Deep Q).
* [Building Machine Learning Projects with Tensorflow](https://www.packtpub.com/big-data-and-business-intelligence/building-machine-learning-projects-tensorflow) – por Rodolfo Bonnin. Este livro aborda vários projetos no TensorFlow que expõem o que pode ser feito com o TensorFlow em diferentes cenários. O livro fornece projetos sobre treinamento de modelos, machine learning, deep learning e trabalho com várias redes neurais. Cada projeto é um exercício envolvente e perspicaz que ensinará como usar o TensorFlow e mostrará como camadas de dados podem ser exploradas trabalhando com Tensores.
* [Deep Learning using TensorLayer](http://www.broadview.com.cn/book/5059) - por Hao Dong et al. Este livro aborda tanto o deep learning quanto a implementação usando TensorFlow e TensorLayer.
* [TensorFlow 2.0 in Action](https://www.manning.com/books/tensorflow-in-action) - por Thushan Ganegedara. Este guia prático para construir modelos de deep learning com os novos recursos do TensorFlow 2.0 é repleto de projetos envolventes, linguagem simples e cobertura dos algoritmos mais recentes.
* [Probabilistic Programming and Bayesian Methods for Hackers](https://github.com/CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers) - por Cameron Davidson-Pilon. Introdução a métodos bayesianos e modelos gráficos probabilísticos usando tensorflow-probability (e, alternativamente, PyMC2/3).
