Una lista seleccionada de experimentos, bibliotecas y proyectos increíbles de TensorFlow. Inspirada por awesome-machine-learning.

## What is TensorFlow?

TensorFlow es una biblioteca de software de código abierto para computación numérica mediante grafos de flujo de datos. En otras palabras, la mejor forma de construir modelos de aprendizaje profundo.

Más información [aquí](http://tensorflow.org).

## Papers

* [TensorFlow: Large-Scale Machine Learning on Heterogeneous Distributed Systems](http://download.tensorflow.org/paper/whitepaper2015.pdf) - Este paper describe la interfaz de TensorFlow y una implementación de dicha interfaz que hemos construido en Google
* [TensorFlow Estimators: Managing Simplicity vs. Flexibility in High-Level Machine Learning Frameworks](https://arxiv.org/pdf/1708.02637.pdf)
* [TF.Learn: TensorFlow's High-level Module for Distributed Machine Learning](https://arxiv.org/abs/1612.04251)
* [Comparative Study of Deep Learning Software Frameworks](http://arxiv.org/abs/1511.06435) - El estudio se realiza sobre varios tipos de arquitecturas de aprendizaje profundo y evaluamos el rendimiento de los frameworks mencionados cuando se emplean en una sola máquina tanto en configuraciones de CPU (multi-hilo) como de GPU (Nvidia Titan X)
* [Distributed TensorFlow with MPI](http://arxiv.org/abs/1603.02339) - En este paper, extendemos Google TensorFlow, propuesto recientemente, para su ejecución en clústeres a gran escala usando Message Passing Interface (MPI)
* [Globally Normalized Transition-Based Neural Networks](http://arxiv.org/abs/1603.06042) - Este paper describe los modelos detrás de [SyntaxNet](https://github.com/tensorflow/models/tree/master/syntaxnet).
* [TensorFlow: A system for large-scale machine learning](https://arxiv.org/abs/1605.08695) - Este paper describe el modelo de flujo de datos de TensorFlow en contraste con los sistemas existentes y demuestra el rendimiento convincente
* [TensorLayer: A Versatile Library for Efficient Deep Learning Development](https://arxiv.org/abs/1707.08551) - Este paper describe una biblioteca versátil de Python que tiene como objetivo ayudar a investigadores e ingenieros a desarrollar sistemas de aprendizaje profundo de forma eficiente. (Ganador del Premio al Mejor Software de Código Abierto de ACM MM 2017)

## Books

* [Machine Learning with TensorFlow 2nd edition]([http://tensorflowbook.com](https://github.com/chrismattmann/MLwithTensorFlow2ed)) por [Dr. Chris A. Mattmann](http://github.com/chrismattmann/), Chief Data and Artificial Intelligence Officer en UCLA y también autor de [Tika in Action](https://www.manning.com/books/tika-in-action). Este libro hace que el tema cargado de matemáticas de la IA y el ML sea accesible y práctico para un principiante. Actualizado a Tensorflow2 y a la última versión de este libro.
* [First Contact with TensorFlow](http://www.jorditorres.org/first-contact-with-tensorflow/) por Jordi Torres, profesor en UPC Barcelona Tech y gerente de investigación y asesor senior en Barcelona Supercomputing Center
* [Deep Learning with Python](https://machinelearningmastery.com/deep-learning-with-python/) - Desarrollar Modelos de Deep Learning en Theano y TensorFlow Usando Keras por Jason Brownlee
* [TensorFlow for Machine Intelligence](https://bleedingedgepress.com/tensor-flow-for-machine-intelligence/) - Guía completa para usar TensorFlow desde los conceptos básicos del cálculo con grafos, hasta modelos de aprendizaje profundo hasta su uso en entornos de producción - Bleeding Edge Press
* [Getting Started with TensorFlow](https://www.packtpub.com/big-data-and-business-intelligence/getting-started-tensorflow) - Ponte en marcha con la última biblioteca de computación numérica de Google y profundiza en tus datos, por Giancarlo Zaccone
* [Hands-On Machine Learning with Scikit-Learn and TensorFlow](http://shop.oreilly.com/product/0636920052289.do) – por Aurélien Geron, ex líder del equipo de clasificación de videos de YouTube. Cubre fundamentos de ML, entrenamiento y despliegue de redes profundas en múltiples servidores y GPUs usando TensorFlow, las últimas arquitecturas CNN, RNN y Autoencoder, y Aprendizaje por Refuerzo (Deep Q).
* [Building Machine Learning Projects with Tensorflow](https://www.packtpub.com/big-data-and-business-intelligence/building-machine-learning-projects-tensorflow) – por Rodolfo Bonnin. Este libro cubre varios proyectos en TensorFlow que muestran qué se puede hacer con TensorFlow en diferentes escenarios. El libro proporciona proyectos sobre entrenamiento de modelos, aprendizaje automático, aprendizaje profundo y trabajo con varias redes neuronales. Cada proyecto es un ejercicio atractivo e ilustrativo que te enseñará cómo usar TensorFlow y te mostrará cómo se pueden explorar las capas de datos trabajando con Tensores.
* [Deep Learning using TensorLayer](http://www.broadview.com.cn/book/5059) - por Hao Dong et al. Este libro cubre tanto el aprendizaje profundo como la implementación usando TensorFlow y TensorLayer.
* [TensorFlow 2.0 in Action](https://www.manning.com/books/tensorflow-in-action) - por Thushan Ganegedara. Esta guía práctica para construir modelos de aprendizaje profundo con las nuevas características de TensorFlow 2.0 está llena de proyectos atractivos, lenguaje simple y cobertura de los últimos algoritmos.
* [Probabilistic Programming and Bayesian Methods for Hackers](https://github.com/CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers) - por Cameron Davidson-Pilon. Introducción a métodos bayesianos y modelos gráficos probabilísticos usando tensorflow-probability (y, alternativamente, PyMC2/3).
