## What is TensorFlow?

TensorFlow is an open source software library for numerical computation using data flow graphs. In other words, the best way to build deep learning models.

More info [here](http://tensorflow.org).

* [CS20 SI: TensorFlow for DeepLearning Research](http://web.stanford.edu/class/cs20si/syllabus.html) - 史丹佛大學 2017 年關於 Tensorflow 的課程 - [Syllabus](http://web.stanford.edu/class/cs20si/syllabus.html) - [Unofficial Videos](https://youtu.be/g-EvyKpZjmQ?list=PLSPPwKHXGS2110rEaNH7amFGmaD5hsObs)
* [TensorFlow World](https://github.com/astorfi/TensorFlow-World) - 提供簡潔且即取即用的 TensorFlow 教學，並附有詳細文件。
* [Effective Tensorflow](https://github.com/vahidk/EffectiveTensorflow) - TensorFlow 的使用說明與最佳實踐。涵蓋基礎以及進階主題。
* [TensorLayer](http://tensorlayer.readthedocs.io/en/latest/user/tutorial.html) - TensorFlow 官方教學的模組化實作。([CN](https://tensorlayercn.readthedocs.io/zh/latest/user/tutorial.html))。
* [Understanding The Tensorflow Estimator API](https://www.lighttag.io/blog/tensorflow-estimator-api/) Estimator API 的概念性概覽，說明何時使用它以及為什麼。 
* [Introduction to TensorFlow for Artificial Intelligence, Machine Learning, and Deep Learning](https://www.coursera.org/learn/introduction-tensorflow) - Coursera 提供的 TensorFlow 入門
* [Convolutional Neural Networks in TensorFlow](https://www.coursera.org/learn/convolutional-neural-networks-tensorflow) - Tensorflow 中的卷積神經網路，由 Coursera 提供
* [TensorLayerX](https://tensorlayerx.readthedocs.io/en/latest/index.html#user-guide) - 像使用 PyTorch 一樣使用 TensorFlow。([Api docs](https://tensorlayerx.readthedocs.io/en/latest/index.html#))

## Libraries

* [TensorFlow Estimators](https://www.tensorflow.org/guide/estimators) - 大幅簡化機器學習程式設計的高階 TensorFlow API（原本為 [tensorflow/skflow](https://github.com/tensorflow/skflow)）
* [R Interface to TensorFlow](https://tensorflow.rstudio.com/) - TensorFlow API 的 R 語言介面，包含 Estimators、Keras、Datasets 等。
* [Lattice](https://github.com/tensorflow/lattice) - 在 TensorFlow 中單調校準插值查找表的實作
* [tensorflow.rb](https://github.com/somaticio/tensorflow.rb) - 使用 SWIG 的 ruby 原生 TensorFlow 介面
* [tflearn](https://github.com/tflearn/tflearn) - 具備高階 API 的深度學習函式庫
* [TensorLayer](https://github.com/tensorlayer/tensorlayer) - 面向研究人員與工程師的深度學習與強化學習函式庫
* [TensorFlow-Slim](https://github.com/tensorflow/models/tree/master/inception/inception/slim) - 定義模型的高階函式庫
* [TensorFrames](https://github.com/tjhunter/tensorframes) - Apache Spark 的 TensorFlow 綁定
* [TensorForce](https://github.com/reinforceio/tensorforce) - TensorForce：用於應用強化學習的 TensorFlow 函式庫
* [TensorFlowOnSpark](https://github.com/yahoo/TensorFlowOnSpark) - Yahoo! 發起的計畫，用於透過 Apache Spark 實現分散式 TensorFlow。
* [caffe-tensorflow](https://github.com/ethereon/caffe-tensorflow) - 將 Caffe 模型轉換為 TensorFlow 格式
* [keras](http://keras.io) - 針對 TensorFlow 與 Theano 的極簡、模組化深度學習函式庫
* [SyntaxNet: Neural Models of Syntax](https://github.com/tensorflow/models/tree/master/syntaxnet) - 對 [Globally Normalized Transition-Based Neural Networks, Andor et al. (2016)](http://arxiv.org/pdf/1603.06042.pdf) 中描述模型的 TensorFlow 實作
* [keras-js](https://github.com/transcranial/keras-js) - 在瀏覽器中執行 Keras 模型（tensorflow 後端），並支援 GPU
* [NNFlow](https://github.com/welschma/NNFlow) - 簡單的框架，可將 ROOT NTuples 轉換為 Numpy 陣列後再於 Google Tensorflow 中使用。
* [Sonnet](https://github.com/deepmind/sonnet) - Sonnet 是 DeepMind 建立在 TensorFlow 之上用於建構複雜神經網路的函式庫。
* [tensorpack](https://github.com/ppwwyyxx/tensorpack) - 建立在 TensorFlow 上、專注於訓練速度與大型資料集的神經網路工具箱。
* [tf-encrypted](https://github.com/mortendahl/tf-encrypted) - 建立在 TensorFlow 之上、用於對加密資料進行機器學習的層
* [pytorch2keras](https://github.com/nerox8664/pytorch2keras) - 將 PyTorch 模型轉換為 Keras（使用 TensorFlow 後端）格式
* [gluon2keras](https://github.com/stjordanis/gluon2keras) - 將 Gluon 模型轉換為 Keras（使用 TensorFlow 後端）格式
* [TensorIO](https://doc-ai.github.io/tensorio/) - 輕量、跨平台的函式庫，用於將 TensorFlow Lite 模型部署到行動裝置。 
* [StellarGraph](https://github.com/stellargraph/stellargraph) - 圖上的機器學習，一個用於圖結構（網絡結構）資料的機器學習 Python 函式庫。
* [DeepBay](https://github.com/ElPapi42/DeepBay) - 高階 Keras 補充，用於實作常見架構堆疊，作為易於使用的即插即用模組
* [Tensorflow-Probability](https://www.tensorflow.org/probability) - 建立在 TensorFlow 之上的機率程式設計，讓在現代硬體上結合機率模型與深度學習變得容易。
* [TensorLayerX](https://github.com/tensorlayer/TensorLayerX) - TensorLayerX：一個包含所有硬體、後端與作業系統（含 TensorFlow）的統一深度學習框架。
* [Txeo](https://github.com/rdabra/txeo) - 一個現代化的 C++ TensorFlow 封裝。

## Papers

## Books

* [Machine Learning with TensorFlow 2nd edition]([http://tensorflowbook.com](https://github.com/chrismattmann/MLwithTensorFlow2ed)) by [Dr. Chris A. Mattmann](http://github.com/chrismattmann/)，UCLA 首席資料與人工智慧長，亦為 [Tika in Action](https://www.manning.com/books/tika-in-action) 的作者。本書讓數學繁重的 AI 與 ML 主題對新手來說平易近人且實用。已更新至 Tensorflow2 及本書最新版本。
* [First Contact with TensorFlow](http://www.jorditorres.org/first-contact-with-tensorflow/) by Jordi Torres，UPC Barcelona Tech 教授，同時也是 Barcelona Supercomputing Center 的研究經理與資深顧問
* [Deep Learning with Python](https://machinelearningmastery.com/deep-learning-with-python/) - Jason Brownlee 使用 Keras 在 Theano 與 TensorFlow 上開發深度學習模型
* [TensorFlow for Machine Intelligence](https://bleedingedgepress.com/tensor-flow-for-machine-intelligence/) - 從圖計算基礎、深度學習模型到在生產環境中使用 TensorFlow 的完整指南 - Bleeding Edge Press
* [Getting Started with TensorFlow](https://www.packtpub.com/big-data-and-business-intelligence/getting-started-tensorflow) - 開始使用 Google 最新的數值計算函式庫並深入探索你的資料，by Giancarlo Zaccone
* [Hands-On Machine Learning with Scikit-Learn and TensorFlow](http://shop.oreilly.com/product/0636920052289.do) – by Aurélien Geron，前 YouTube 影片分類團隊負責人。涵蓋 ML 基礎、使用 TensorFlow 跨多台伺服器與 GPU 訓練與部署深度網路、最新的 CNN、RNN 與 Autoencoder 架構，以及強化學習（Deep Q）。
* [Building Machine Learning Projects with Tensorflow](https://www.packtpub.com/big-data-and-business-intelligence/building-machine-learning-projects-tensorflow) – by Rodolfo Bonnin。本書涵蓋 TensorFlow 中各種專案，展示在不同情境下能用 TensorFlow 做什麼。書中提供關於訓練模型、機器學習、深度學習以及使用各種神經網路的專案。每個專案都是一個引人入勝且具啟發性的練習，將教你如何使用 TensorFlow，並透過處理張量來展示資料各層如何被探索。
* [Deep Learning using TensorLayer](http://www.broadview.com.cn/book/5059) - by Hao Dong 等人。本書涵蓋深度學習以及使用 TensorFlow 與 TensorLayer 的實作。
* [TensorFlow 2.0 in Action](https://www.manning.com/books/tensorflow-in-action) - by Thushan Ganegedara。這本使用 TensorFlow 2.0 新功能建構深度學習模型的實用指南充滿引人入勝的專案、簡單的語言，並涵蓋最新演算法。
* [Probabilistic Programming and Bayesian Methods for Hackers](https://github.com/CamDavidsonPilon/Probabilistic-Programming-and-Bayesian-Methods-for-Hackers) - by Cameron Davidson-Pilon。使用 tensorflow-probability（亦可選用 PyMC2/3）介紹貝氏方法與機率圖模型。
