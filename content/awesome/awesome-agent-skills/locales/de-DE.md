# Großartige Agent Skills

Im Gegensatz zu vielen massenhaft generierten Skill-Sammlungen konzentriert sich diese Sammlung auf praxiserprobte Agent Skills, die von echten Entwicklungsteams erstellt und eingesetzt werden – nicht auf massenhaft KI-generierte Inhalte.


Kompatibel mit Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf und mehr. Pfade und Dokumentation finden Sie in der Tabelle unten.

Das Agent-Skills-Repository mit den meisten Beiträgen, gemeinsam mit der Community aufgebaut und gepflegt.

## Qualitätsstandards für Skills

Mit dem Wachstum des Ökosystems hilft gleichbleibende Qualität Agenten dabei, Skills zuverlässig zu finden und zu verwenden. Die folgenden Referenzen und Kriterien sichern einen hohen Standard.


### Qualitätskriterien

| Bereich | Richtlinie |
|------|-----------|
| **Beschreibung** | In der dritten Person schreiben. Angeben, *was* der Skill tut und *wann* er verwendet werden soll. Konkrete Schlüsselwörter verwenden, nach denen Agenten suchen können (z. B. „PostgreSQL-Migration“ statt „Datenbankkram“). |
| **Progressive Offenlegung** | Metadaten der obersten Ebene auf etwa 100 Tokens begrenzen. Der Skill-Text sollte unter 500 Zeilen bleiben. Ressourcen (umfangreiche Dokumente, Schemas) bei Bedarf laden, nicht inline. |
| **Keine absoluten Pfade** | Niemals maschinenspezifische Pfade wie `/Users/alice/` fest kodieren. Relative Pfade oder bekannte Variablen (`$HOME`, `$PROJECT_ROOT`) verwenden. |
| **Begrenzte Tools** | Nur die Tools anfordern, die der Skill tatsächlich benötigt. Pauschale Angaben wie `"tools": ["*"]` vermeiden. Tool-Abhängigkeiten explizit deklarieren. |
