# Compétences Agent remarquables

Contrairement à de nombreux dépôts de compétences générées en masse, cette collection met l’accent sur les vraies compétences Agent créées et utilisées par de véritables équipes d’ingénierie, et non sur du contenu produit en série par l’IA.


Compatible avec Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf et bien d’autres. Consultez le tableau ci-dessous pour connaître les chemins et la documentation.

Le dépôt de compétences Agent qui reçoit le plus de contributions, créé et maintenu avec la communauté.

<summary><h3 style="display:inline">Compétences SerpApi</h3></summary>

Compétences officielles de l’équipe [SerpApi](https://serpapi.com/awesome-agent-skills), l’API de recherche Web pour les applications d’IA. - **[serpapi/serpapi-web-search](https://officialskills.sh/serpapi/skills/serpapi-web-search)** - Données de recherche structurées via plus de 130 moteurs : choisir le bon moteur, extraire les bonnes clés et récupérer après les erreurs
- **[serpapi/agent-usability-test](https://officialskills.sh/serpapi/skills/agent-usability-test)** - Vérifier si les agents peuvent découvrir et utiliser votre outil — le sujet du test est l’interface, pas l’agent

Autres ressources SerpApi (pas des compétences, mais elles les complètent) :

- **[serpapi/serpapi-search-tools-python](https://github.com/serpapi/serpapi-search-tools-python)** - Outils de recherche en temps réel pour agents Python avec prise en charge native des SDK d’agents populaires
- **[serpapi/serpapi-cli](https://github.com/serpapi/serpapi-cli)** - Client SerpApi pour la ligne de commande, couvrant plus de 130 moteurs

</details>

- **[crawlbase/storage-bulk-delete](https://officialskills.sh/crawlbase/skills/storage-bulk-delete)** - Supprimer jusqu’à 100 pages stockées en un appel

## 🔒 Avis de sécurité

Les compétences de cette liste sont sélectionnées, mais non auditées. Leurs mainteneurs d’origine peuvent les mettre à jour, les modifier ou les remplacer à tout moment après leur ajout.

Avant d’installer ou d’utiliser une compétence Agent, examinez les risques de sécurité potentiels et validez vous-même la source.

Outils recommandés :

- [Scanner de sécurité des compétences Snyk](https://github.com/snyk/agent-scan)

## Normes de qualité des compétences

À mesure que l’écosystème grandit, une qualité cohérente aide les agents à découvrir et utiliser les compétences de façon fiable. Les références et critères suivants maintiennent un niveau élevé.


### Critères de qualité

| Domaine | Consigne |
|------|-----------|
| **Description** | Rédigez à la troisième personne. Indiquez *ce que* fait la compétence et *quand* l’utiliser. Utilisez des mots-clés précis que les agents peuvent reconnaître (p. ex. « migration PostgreSQL » plutôt que « trucs de base de données »). |
| **Divulgation progressive** | Gardez les métadonnées de premier niveau sous environ 100 jetons. Le corps de la compétence doit rester sous 500 lignes. Chargez les ressources (gros documents, schémas) à la demande plutôt qu’en ligne. |
| **Aucun chemin absolu** | Ne codez jamais en dur des chemins propres à une machine comme `/Users/alice/`. Utilisez des chemins relatifs ou des variables bien connues (`$HOME`, `$PROJECT_ROOT`). |
| **Outils délimités** | Ne demandez que les outils dont la compétence a réellement besoin. Évitez les configurations globales `"tools": ["*"]`. Déclarez explicitement les dépendances aux outils. |
