# Awesome Agent Skills

大量生成された多くのスキルリポジトリとは異なり、このコレクションは、AIが大量生成したものではなく、実際のエンジニアリングチームが作成・使用している実践的なAgent Skillsに重点を置いています。


Claude Code、Codex、Antigravity、Gemini CLI、Cursor、GitHub Copilot、OpenCode、Windsurfなどに対応しています。パスとドキュメントについては、以下の表をご覧ください。

コミュニティと共に構築・保守されている、最も多くのコントリビューションを集めたAgent Skillsリポジトリです。

- **[serpapi/serpapi-search-tools-python](https://github.com/serpapi/serpapi-search-tools-python)** - 人気のエージェントSDKをネイティブサポートする、Pythonエージェント向けリアルタイム検索ツール

- **[crawlbase/storage-count](https://officialskills.sh/crawlbase/skills/storage-count)** - トークンに紐づくCrawlbase Cloud Storage内のドキュメント数をカウント

## スキル品質基準

エコシステムが成長する中、一貫した品質はエージェントがスキルを確実に見つけて利用する助けとなります。以下の参考資料と基準によって、高い水準を維持します。


### 品質基準

| 項目 | ガイドライン |
|------|-----------|
| **説明** | 三人称で記述します。スキルが*何を*行い、*いつ*使うかを明示します。エージェントが照合できる具体的なキーワード（例：「データベース関連」ではなく「PostgreSQL移行」）を使います。 |
| **段階的な情報開示** | トップレベルのメタデータは約100トークン未満に保ちます。スキル本文は500行未満にします。大きな文書やスキーマなどのリソースはインラインではなく、必要に応じて読み込みます。 |
| **絶対パスを使わない** | `/Users/alice/`のようなマシン固有のパスをハードコードしないでください。相対パスまたは既知の変数（`$HOME`、`$PROJECT_ROOT`）を使います。 |
| **ツールの範囲を限定** | スキルに本当に必要なツールだけを要求します。`"tools": ["*"]`のような包括指定を避け、ツール依存関係を明示します。 |
