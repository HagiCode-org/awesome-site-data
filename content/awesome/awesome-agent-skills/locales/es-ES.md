# Agent Skills destacadas

A diferencia de muchos repositorios de skills generados en masa, esta colección se centra en Agent Skills reales, creadas y utilizadas por equipos de ingeniería, y no en contenido generado en serie por IA.


Compatible con Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf y más. Consulta la tabla siguiente para ver las rutas y la documentación.

El repositorio de Agent Skills con más contribuciones, creado y mantenido junto con la comunidad.

- **[serpapi/serpapi-search-tools-python](https://github.com/serpapi/serpapi-search-tools-python)** - Herramientas de búsqueda en tiempo real para agentes de Python con compatibilidad nativa con los SDK de agentes más populares

## Estándares de calidad de las skills

A medida que crece el ecosistema, una calidad coherente ayuda a los agentes a descubrir y utilizar skills de forma fiable. Las siguientes referencias y criterios mantienen alto el listón.

### Criterios de calidad

| Área | Directriz |
|------|-----------|
| **Descripción** | Redacta en tercera persona. Indica *qué* hace la skill y *cuándo* se debe usar. Emplea palabras clave específicas que los agentes puedan reconocer (por ejemplo, «migración de PostgreSQL» en lugar de «cosas de bases de datos»). |
| **Revelación progresiva** | Mantén los metadatos de nivel superior por debajo de unos 100 tokens. El cuerpo de la skill debe tener menos de 500 líneas. Carga recursos (documentos extensos, esquemas) cuando sea necesario, no los incluyas en línea. |
| **Sin rutas absolutas** | Nunca codifiques rutas específicas de una máquina como `/Users/alice/`. Usa rutas relativas o variables conocidas (`$HOME`, `$PROJECT_ROOT`). |
| **Herramientas acotadas** | Solicita únicamente las herramientas que la skill necesita. Evita comodines generales como `"tools": ["*"]`. Declara explícitamente las dependencias de herramientas. |
