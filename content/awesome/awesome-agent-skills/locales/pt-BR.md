# Agent Skills incríveis

Ao contrário de muitos repositórios de skills gerados em massa, esta coleção se concentra em Agent Skills do mundo real, criadas e usadas por equipes de engenharia de verdade, e não em conteúdo produzido em massa por IA.


Compatível com Claude Code, Codex, Antigravity, Gemini CLI, Cursor, GitHub Copilot, OpenCode, Windsurf e muito mais. Consulte a tabela abaixo para ver caminhos e documentação.

O repositório de Agent Skills com mais contribuições, criado e mantido junto com a comunidade.

## 🔒 Aviso de segurança

As skills desta lista são selecionadas, não auditadas. Seus mantenedores originais podem atualizá-las, modificá-las ou substituí-las a qualquer momento após sua inclusão aqui.

Antes de instalar ou usar qualquer Agent Skill, analise os possíveis riscos de segurança e valide a fonte por conta própria.

Ferramentas recomendadas:

- [Synk Skill Security Scanner](https://github.com/snyk/agent-scan)
- [Agent Trust Hub](https://ai.gendigital.com/agent-trust-hub)

Skills de agente podem conter injeções de prompt, envenenamento de ferramentas, cargas ocultas de malware ou padrões inseguros de tratamento de dados. Sempre revise o código e use as skills por sua conta e risco.

## Padrões de qualidade das skills

À medida que o ecossistema cresce, a qualidade consistente ajuda os agentes a encontrar e usar skills com confiança. As referências e os critérios a seguir mantêm o nível elevado.


### Critérios de qualidade

| Área | Diretriz |
|------|-----------|
| **Descrição** | Escreva na terceira pessoa. Indique *o que* a skill faz e *quando* usá-la. Use palavras-chave específicas que os agentes possam reconhecer (por exemplo, "migração do PostgreSQL", não "coisas de banco de dados"). |
| **Divulgação progressiva** | Mantenha os metadados de nível superior abaixo de ~100 tokens. O corpo da skill deve ter menos de 500 linhas. Carregue recursos (documentos grandes, esquemas) sob demanda, não em linha. |
| **Sem caminhos absolutos** | Nunca codifique caminhos específicos de uma máquina, como `/Users/alice/`. Use caminhos relativos ou variáveis conhecidas (`$HOME`, `$PROJECT_ROOT`). |
| **Ferramentas com escopo definido** | Solicite apenas as ferramentas de que a skill realmente precisa. Evite o curinga `"tools": ["*"]`. Declare explicitamente as dependências de ferramentas. |
