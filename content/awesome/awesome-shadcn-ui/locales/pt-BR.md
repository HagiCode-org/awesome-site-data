## Desenvolvimento e Contribuição

### Para o Site

- **Guia de Desenvolvimento**: Veja [DEVELOPMENT.md](DEVELOPMENT.md) para configuração, arquitetura e configuração
- **Contribuindo**: Faça um fork do repositório, crie uma branch de feature e envie um PR

### Para a Lista Awesome

Leia [CONTRIBUTING.md](CONTRIBUTING.md) primeiro — ele contém o formato de linha, as regras de nomenclatura e o que um recurso precisa atender para ser aceito.

- **Via Site**: Use o formulário de envio integrado em [awesomeshadcn.dev](https://awesomeshadcn.dev/)
- **Via GitHub**: Siga o [modelo de PR](.github/pull_request_template.md) ao criar pull requests
