## Desarrollo y Contribución

### Para el sitio web

- **Guía de desarrollo**: consulta [DEVELOPMENT.md](DEVELOPMENT.md) para configuración, arquitectura y configuración.
- **Contribuir**: haz fork del repositorio, crea una rama de funcionalidad y envía un PR.

### Para la lista Awesome

Lee [CONTRIBUTING.md](CONTRIBUTING.md) primero — tiene el formato de fila, las reglas de nombrado y lo que un recurso debe cumplir para ser aceptado.

- **Vía sitio web**: usa el formulario de envío integrado en [awesomeshadcn.dev](https://awesomeshadcn.dev/).
- **Vía GitHub**: sigue la [plantilla de PR](.github/pull_request_template.md) al crear pull requests.
